# T14 右の面（地図・ハザード・雨雲・震度）。余裕があれば

## 目的

担当一覧の右の面。平時は今週の見直しと未確認の多い人。発災時は利用者の住所にピンを立てた地図（ピンの色は緊急度）、ハザードマップの浸水と土砂の層、雨雲、震度の速報。右端の便利さまでで、売りにしない（docs/SPEC.md の「危ないと思う所」）。

## 読む物

docs/SPEC.md の「画面 1」の右の面、「範囲外」（複数市町村の司令室・地図）、「GitHub と提出物で守ること」（地図の出典表示、デモの警報の印）。

## 作る物

- 地図: 国土地理院のタイル（出典表示）。ピンは架空の町の中の架空の位置（台帳に緯度経度を持つ。町名からの変換はしない）。ピンの色は lib/triage の色
- ハザード: ハザードマップポータルの重ね合わせの層（浸水・土砂。出典表示）。切替できる
- 雨雲・震度: デモでは筋書き（T17）か災害の情報（T09）から作った「デモ」と明記した表示。気象庁の本物の情報を引くのは本運用で、ここでは引かない
- 平時の右の面: 今週の見直し（計画が「下書き」で未確認のある人）、未確認の多い人（今の app/page.tsx の右の面を整える）
- 幅が足りないときは右の面を畳む
- 依存を足すなら MIT（Leaflet など）で THIRD_PARTY_NOTICES.md
- テスト: ピンの色が lib/triage と一致、出典表示が出る

## 終わりの形

- 発災時に右に地図が出て、10 本のピンが緊急度の色で立ち、浸水の層を重ねられる。「デモ」の印が見える

## 触るファイル

components/list/SidePane、components/map/、lib/db/types.ts（緯度経度）、seed、THIRD_PARTY_NOTICES.md、docs/PROGRESS.md

## 守ること

本物の警報と見間違えさせない。司令室の見た目にしない（右端の 1 列まで）。
