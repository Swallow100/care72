# T156 使う側の模擬（AI が使う人を演じて実際の画面を歩き、どこで迷ったかを記録する評価の台）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。評価の台の作り（tools/eval/drill の run.ts・record.ts・prices.ts、tools/eval/forms の render.ts、tools/eval/talk）、印刷の道具の Chrome の探し方（tools/print/chrome.ts）、README の「触り方」、画面の言葉（lib/*/labels.ts）を読む。

## 意図（なぜこの作業か）

今の評価の台が模しているのは「電話の向こうの本人・家族」（訓練・声の聞き取り）と「書類の紙」だけで、PC の前でアプリを触る人の模擬が無い。審査員は PC でアプリを初めて触る。どこで迷うか・どの言葉を読み違えるかを、作者が自分で触る前に数で見たい。そこで、AI が使う人を演じて手元のアプリの本物の画面を歩き、迷った所を記録する台を作る。

## 作る物（tools/eval/persona/）

1. **使う人と筋**（personas.ts）: 初めて触るケアマネ・慣れたケアマネ・事業所の管理者・医療班（受け入れ側）の 4 人と、審査員の「初めての 10 分」の筋。各人に目標の並び（今の画面に実在する流れだけ）と、目標ごとの達成の印（URL・見出し・文・印刷の画面を開いた旗）と最短の手数（コードを読んで数えた物）
2. **画面を読む・押す**（surface.ts・dom.ts）: 手元の localhost のアプリを puppeteer で PC の幅（1536 か 1280）で開く。毎手、押せる物（番号・役・名前）・見出し・今の URL・警告の文を読み、押す・書く・選ぶ・戻るの手を打つ。手ごとの画面の写真。偽の画面（表で遷移する小さな状態機械）も同じ口で
3. **使う人の AI**（actor.ts）: 安い型（Haiku）。頁の木・目標・手持ちの情報・今までの手を渡し、次の 1 手と「その時に思ったこと」・押した後に思う結果・前の手の結果が思ったのと違ったかを JSON で返す。パスワードは `{{password}}` の印で書かせ、台が差し替える（AI に値を渡さない）
4. **迷いの記録**（lost.ts）: 見つからない（同じ所を回る）・読み違い（思った結果と違う）・行き止まり（押しても変わらない・押せる物が無い）・戻り・エラーの表示（警告の文・HTTP 4xx/5xx・頁の例外）・時間切れ（1 筋の手の上限、既定 40）を台が機械で数える
5. **審査役**（judge.ts）: 強い型（Opus）。筋ごとに 1 回、目標の達成（台の印）・最短の手との差・迷いの数を材料に、分かりにくかった言葉の一覧と直す候補（疑うファイル）を出す。達成の真偽は台が持ち、審査役は変えない
6. **費用**: 見積もりは drill の prices.ts の表、記録は drill の record.ts（recordClaude・runLog）。`--max-usd` を超えたら次の筋を始めない
7. **報告**（report.ts・finding.ts）: 筋ごとの達成・手数・迷い、迷った所の一覧（画面・押した物・思ったこと）、直す候補。指摘は「場所・重さ・再現の手順・疑うファイル・受け入れの確かめ」の形で JSON にも（T157 が 3 つの台の指摘と点を 1 つの表にまとめる）
8. **偽の client とテスト**: 偽の使う人は決まった手を返し、偽の審査役は決まった形を返す。偽の画面で少なくとも 1 筋が最後まで行く。Chrome があれば、手元の小さな HTTP の頁で本物の puppeteer の口も通す
9. `package.json` に `eval:persona`、進みと本物の回のコマンドは docs/progress/t156.md

## どこに Claude を使い、どこに使わないか

使う人の役（次の 1 手と思ったこと）は Haiku、審査役（分かりにくい言葉と直す候補）は Opus。達成・手数・迷いの数・HTTP の失敗は台のコードが数え、AI は決めない。

## 分担・前提

- 手元の next dev（手元の D1 と種の 10 人）だけを開く。台は localhost・127.0.0.1 のほかの host を断る。本番の care72.app に触らない
- 手元のログインは種の山本（確認用の事業所）。パスワードは使い捨ての値を `CAREMANAGER_DEMO_PASSWORD_HASH=<ハッシュ> npm run db:reset` で種に入れ、台には環境変数 `CARE72_PASSWORD` で渡す
- 筋の前に「最初に戻す」（/office/reset）で種に戻す
- 頁の文には手元の種の架空の人の名前が出る。台は種の事業所（デモ事業所・確認用）でない頁、架空の形（090-0000-00NN）でない電話を見たら AI に渡さず止まる
