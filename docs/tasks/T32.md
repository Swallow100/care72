# T32 「Claude の活用」の 3 軸を作品の中で強くする（サブエージェント・MCP・記録）

## 目的

Claude の使い方を、この作品では 3 つの面で示す。Claude を創造的に使い新しい可能性を見せているか、Claude Code を開発の中心に据えて何が可能になったかを示せているか、モデルや機能（Skills・サブエージェント・MCP・フック）を目的に応じて選び使い分けているか。T31 でフック・Skill 2 つ・docs/CLAUDE_CODE.md は入った。残るサブエージェント（リポジトリの .claude/agents）と MCP を、本当に使う形で足し、3 軸のそれぞれを「これ」と指せる形で記録する。開発の道具の側の作業なので、品質に関わらない所は理にかなえば足してよい。使っていない物を「使った」と書かない。

## 読む物

CLAUDE.md、docs/tasks/README.md、docs/CLAUDE_CODE.md、docs/DECISIONS.md、.claude/settings.json、.claude/skills/、tools/hooks/、lib/pseudonym/index.ts、lib/claude/call.ts、lib/triage/index.ts。Claude Code の公式の文書（サブエージェント https://code.claude.com/docs/en/sub-agents 、MCP https://code.claude.com/docs/en/mcp ）で形を確かめる。推測で書かない。

## 作る物

- **リポジトリのサブエージェント**（.claude/agents/*.md）を 3 つ。何を読み何を返すかを具体的に
  - `medical-reviewer`（opus）: ルールの表・講評の文・要約の項目を、診断・用量・助言になっていないか、出典があるかの目で見直す
  - `screen-checker`（sonnet）: 画面を CLAUDE.md の「画面の決まり」と意味色の決まり（状態 4 色を CSS 変数、色＋2 字、面は塗らない）に照らして見直す
  - `persona-tester`（haiku）: 訓練のペルソナの出力が JSON の形を守り、仮名のままで本名・住所が漏れていないかを確かめる
- **MCP を 1 つ**: 手元の D1 の種と訓練記録を Claude Code から読む小さなサーバー tools/mcp/care72-local（読むだけ、stdio、.mcp.json に登録、@modelcontextprotocol/sdk は MIT）。ペルソナのテストと採点の確かめに使う
- **docs/CLAUDE_CODE.md** に「創造的な使い方の芯」を 1 段ずつ、裏の取れる形（ファイルと commit の hash）で。3 軸それぞれに「これ」と指せる見出し。まだ作っていない物（10 体の Haiku と Opus の監督の訓練）は「作る物」として書く
- **README の「使った資料と方法」**を、資料（Claude Code ベストプラクティス、Building Effective Agents、Effective Context Engineering、Cookbook）ごとに「この作りがこの文書のこの形」の 1 行に。README の他の段は触らない
- 面白い追加があれば（Skill など）。入れるなら理由と使い方を docs に
- 進みの記録は docs/PROGRESS.md でなく docs/progress/t32.md（main と同時に進むので衝突を避ける）

## 終わりの形

- `npm test` と `npm run typecheck` が通る
- .claude/agents の 3 つが公式の頭の項目だけで書かれ、名前・モデル・中に書いたファイルがテストで確かめられる
- MCP のサーバーを子の処理として起こし、道具の一覧と、仮名の本人・漏れの確かめが返ることをテストで確かめる。Claude に返す物は lib/pseudonym を通る
- docs/CLAUDE_CODE.md の「使っていない物」が今の事実に合う
- branch task/t32 を push し、PR を作る（merge はしない）

## 触るファイル

## 守ること

- 公開リポジトリ。実名・秘密・他のプロジェクトの名前を書かない
- ネットに出る wrangler、Cloudflare の MCP ツール、鍵、本物の Claude API の呼び出し、配信をしない。手元の D1 は --local だけ
- docs/SPEC.md・docs/DECISIONS.md・CLAUDE.md を書き換えない。止める物（フック）を増やすなら CLAUDE.md も直す決まりなので、この作業では増やさない
- Managed Agents の枠は 11/3 のあとに決める（この作業では触らない）
- MCP は読むだけ。人のデータは仮名化の層を通してから Claude に返す
