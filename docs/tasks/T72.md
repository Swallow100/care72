# T72 気象庁の実データ（防災情報 XML を Cron で取って D1 に、警報を市町村のまま事業所に出して「該当の利用者」と「切替」、雨雲は加工せず重ねる、デモの絵はデモ事業所だけ。migration 0020）（Opus、分岐）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md`（何を作っているか・越えない線・地図・進め方）→ `CLAUDE.md` → `docs/tasks/README.md` → **docs/progress/jma-terms-20261104.md（気象庁の利用条件。やってよい形・やってはいけない形）** を読む。元は docs/DECISIONS.md「地図と災害の情報」（雨雲・震度の絵も本物の情報にし、気象庁の警報・地震の情報も読む。利用条件を先に読み、だめな物は作らない。災害モードは自動で切り替えず、人に押させる）と real-use-audit の 1。この文書は、それ以外に何も知らなくても作業できるように書いてある。

## 意図（なぜこの作業か）

今の雨雲・震度は筋書きの絵と数字（lib/map/demo.ts。「デモ」の印付き）で、災害モードにすると本物の事業所にも松山の雨雲と「南海トラフ 震度6強」が出る（lib/map/side.ts の sideDisasterOf は事業所の種類を見ない）。本物の事業所が使うには、気象庁の情報を**利用条件の「やってよい形」だけで**出す:

- 警報・注意報と地震の情報は、防災情報 XML の PULL 型フィード（登録不要。`extra.xml`〔警報など、毎分更新・直近 10 分〕・`eqvol.xml`〔地震〕）を **Workers が 1 か所で数分おきに取り、D1 に写して各事業所に配る**（各ブラウザから気象庁を頻繁に読まない）。
- 警報は **発表された市町村・正式な名前・発表時刻のまま**出し、利用者の住所の市町村と突き合わせて「該当の利用者」を並べる。**災害モードは自動で切り替えず「切替」を勧めるだけ。**
- 雨雲（ナウキャスト）の画像は **加工せず重ね、凡例も気象庁のまま、出典を出す**。
- やってはいけない形（特定の地点への読み替え「○○さんの家は危険」、推計震度を「利用者の家の震度」と断定、時刻の補間・延長、独自の危険度、警報の名前や色を借りた独自の警報、各ブラウザから直接・頻繁に読む、土砂・洪水・高潮の予報）は作らない。

線: この作業は Claude を呼ばない。色と連絡順（lib/triage）に触れない（警報は表の入力にしない。表の入力は今までどおり人が /office で入れる災害の状態だけ）。**作業中は本物の気象庁に繋がない**（テストと手元の確かめは fixtures の XML。本物のフィードの写しは作者が道具で取る）。

## 作る物

1. **取る・写す（先に 1 commit。画面無し）**: `lib/jma/`（新しい）。
   - `feed.ts`: Atom のフィード（extra.xml・eqvol.xml）を読み、entry ごとの id・title・updated・link（電文の URL）を出す。前に取った id は飛ばす（D1 の jma_entries）。取るときは `If-Modified-Since`（前回の Last-Modified）を付け、304 なら何もしない。fetch は `redirect: "follow"`（`"error"` は Workers で毎回投げる）。1 回の取得で新しい entry は 50 件まで（それ以上は次の回に）。
   - `xml.ts`: XML を読む。依存は MIT の物（例 fast-xml-parser）を 1 つ足して THIRD_PARTY_NOTICES.md に書く（Workers で動く物。DOMParser は無い）。名前空間の接頭辞（jmx・jmx_ib など）に寄らない読み方。
   - `warning.ts`: 気象警報・注意報の電文（VPWW53・54〔経過措置〕と VPWW55〜61〔2026-05-29 からの体系〕）から、市町村（Area の Code と Name）ごとの 種類（Kind の Name。「レベル3大雨警報」「大雨注意報」など正式な名前のまま）・状態（発表・継続・解除）・発表時刻・発表官署 を出す。読めない電文は捨てて次へ（記録に 1 行）。
   - `quake.ts`: 地震の電文（VXSE51 震度速報・VXSE52 震源・VXSE53 震源・震度）から、発生時刻・震源の名前・規模・最大震度と、観測点ごと（Name・Code・震度）を出す。観測点の緯度経度は公式の資料が分からないので持たない（地図の点にはしない。一覧だけ）。推計震度分布は仕様が非公開なので **作らない**。
   - `store.ts`: migration 0020 の表に写す。`jma_entries`（id・feed・title・updated_at・fetched_at）、`jma_warnings`（entry_id・area_code・area_name・kind・status・issued_at・office_name。市町村ごと 1 行。同じ area_code の新しい発表で前の行を置き換えず、全部残して「今の状態」は最新の issued_at で引く）、`jma_quakes`（entry_id・origin_at・hypocenter・magnitude・max_intensity）、`jma_quake_points`（entry_id・area_name・point_name・intensity）、`jma_fetch_state`（feed・last_modified・fetched_at・ok・note）。古い行は 7 日で消す（取るたびに DELETE）。seed/sql.ts の CLEAR_ORDER と lib/seed/reset.ts の DEMO_CLEAR に表を足す（事業所ごとでないので DEMO_CLEAR は null。seed.test.ts が抜けを見る。手元の db:reset では消す）。
   - **Cron**: wrangler.jsonc の triggers.crons に `"*/5 * * * *"`（5 分ごと）を足し、worker.ts の scheduled で `controller.cron` で分ける（毎日 4 時は今までどおり lib/seed/cron.ts の scheduledReset。それは cron の文字が違えば null を返すので、新しい `lib/jma/cron.ts` の `scheduledJmaFetch(env, cron, now)` を並べて呼ぶ）。lib/seed/cron.ts のテストが wrangler.jsonc の crons を見ているなら「DAILY_RESET_CRON を含む」に直す。`wrangler deploy` が triggers を一緒に出すので配信の道具（tools/deploy。T73）は変えない。手元の next dev では cron は動かないので、`npm run jma:fetch-local`（fixtures の XML を手元の D1 に写す道具。本物には繋がない）を足して画面を確かめる。
   - **fixtures**: `lib/jma/fixtures/` に extra.xml・eqvol.xml・VPWW55 の電文・VPWW53 の電文・VXSE53 の電文の見本を **文書の形式（XML 一覧表・技術情報。jma-terms の資料の節）から作る**（本物を取ってこない）。作った物には頭に「作った見本。本物の電文ではない」と注。合わせて `tools/jma/fetch-fixtures.mjs`（**作者が手で打つ**道具。本物のフィードと直近の電文を取って fixtures に上書きする。エージェントは打たない。打ち方を progress に）。本物で確かめるのは作者が朝に。
2. **警報を事業所に出す**: `lib/jma/match.ts`: 事業所の市（offices.city）と利用者の市（Ledger.basic.address.city。T68 が画面で入れられるようにする。種の 10 人は「松山市」）を、警報の area_name と文字で突き合わせる（「松山市」= 「松山市」。区のある市は area_name が「○○市○○区」の形なので、前方一致で市に当てる。それ以上の読み替えはしない）。`components/office/JmaAlerts.tsx`（新しい。server）を app/office/page.tsx の ModeSection の中（切替のボタンの上）に 1 行の差し込み: 事業所の市に今出ている警報・注意報を 名前・市町村・発表時刻 のまま並べ、名前ごとに「該当 N 人」（住所の市が同じ利用者の数。名前は出さない。押すと担当一覧の絞込〔area=〕へのリンク）。警報（注意報でない物）があり平時なら「切替」の文字を赤で添える（押すと切替のボタンの所へ送るだけ。**自動では切り替えない**）。下に出典「出典：気象庁ホームページ（https://www.jma.go.jp/bosai/warning/）、気象庁防災情報XML」。取れていない（jma_fetch_state が失敗・古い）ときは「気象庁 未取得 HH:MM」の 1 行。地震: 直近 24 時間の地震で、事業所の市を含む観測点の震度があれば 震源・規模・その市の最大震度 を 1 行（「震度は観測点の値で、利用者の家の震度ではない」の言い切りはしない。観測点の名前を添えるだけ）。デモ事業所にも本物の警報を出す（デモの絵は地図だけ）。
