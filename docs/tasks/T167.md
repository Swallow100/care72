# T167 訓練の呼び出しの数と、人ごとの筋の残り（評価の 8 回目）

意図: 評価の 8 回目（docs/progress/eval-r8.md の「直す所」）で残った訓練の物を、全部の想定・全部の人に効く形で直す。

1. AI の呼び出しを r7（89.6/回、上限 150 との比 74.7%）以下へ。多いのは 8 往復の通話の本人役。会話の質を落とさず、相づち・聞き返しのような返事をコードに
2. 守り drill-left-remain-none の外れと、帳面と本人役の言葉の食い違い 2 の原因を確かめて直す
3. 人ごとの筋: 避難所や病院へ移ったあとに家にいる言い方、機器の電池が切れたまま落ち着いた連絡が続く、停電の戻りと家の電気の食い違い
4. 仮想の回の出来事の無い人（8/10）を減らす
5. 直した所を tools/eval/guards.ts の守りか台の check に

守ること: 人の結末・色・連絡順は AI に決めさせない。医療の助言・診断の言葉を書かせない。仮名化の門（askJson）を外さない。訓練の人は AI が演じる架空の人のまま。

触らない所: 画面（app/drill・components/drill・lib/drill/labels.ts）、lib/forms。

確かめ: lib/drill・tools/eval/drill のテスト、`npm run -s typecheck`、台の偽の回。本物の API は呼ばない。進みは docs/progress/t167.md。
