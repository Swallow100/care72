# T174 訓練の人ごとの筋の残り（評価の 9 回目）

意図: 評価の 9 回目（docs/progress/eval-r9.md の「直す所」）で審査役の人ごとの筋が 2・2・2 のまま。その形を全部の想定・全部の人に効く形で直す。

1. 機器が切れたあとの連絡と家族の反応（down_silent run-03・05 の 360 分、calm_while_down run-05）。down_silent を 1 以下へ。守りを足す
2. 寝たままの本人が電話に出る。台帳の寝たきり・聴覚などの事実と矛盾する応答を直す。出られない人の電話は誰が出るか・出ないかをコードで決める
3. 道の開通と本人役の理由の食い違い
4. 世界の返事で捨てた名前の数を数える口（tools/eval/drill/checks.ts）
5. 呼び出しの数を戻さない（1 回 72.4、上限比 53.3% を大きく超えない。増えるなら理由を書く）
6. 直した所を tools/eval/guards.ts の守りか台の check に

守ること: 人の結末・色・連絡順は AI に決めさせない。医療の助言・診断の言葉を書かせない。仮名化の門（askJson）を外さない。訓練の人は AI が演じる架空の人のまま。

触らない所: 画面（T173）、lib/forms（T175）。

確かめ: lib/drill・tools/eval/drill のテスト（--maxWorkers=2）、`npm run -s typecheck`、台の偽の回。本物の API は呼ばない。進みは docs/progress/t174.md。
