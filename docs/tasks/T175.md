# T175 書類の読み取りの揺れを減らす

評価の 9 回目（docs/progress/eval-r9.md）で書類の守りは全部通ったが、同じ様式でも Opus の読み取りが回ごとに違い、見直しの要確認が大きく揺れた（同じ様式で 55 → 361 など。合計 2,178）。全部の様式に効く形で揺れを減らす。

進みは docs/progress/t175.md。worktree care72-t175、branch task/t175（origin/integrate/t11-t12 から）。

## やること

1. r8 と r9 の読み取りの答えを比べ、何が揺れているか（欄の分け方・名前・位置）を分類する。様式の読み取りの指示と後の決まり（lib/forms/read-post.ts、読み取りの system）で揺れを減らすか、揺れても紙の結果と要確認の数が変わらないようにする
2. 当てたのに紙に出ない選択肢 23（災害診療記録）: lib/forms/mapped-sheet.ts・lib/forms/overlay-sheet.ts
3. 置けなかった欄の上位（吹田市 suita_03・熊本市など）。同じ形の様式全部に効く直しに
4. 直した所を tools/eval/guards.ts の守りか台の check に足す（足し方は docs/progress/t157.md）

## 守ること

- 字を欄の枠の外に出さない。伏字を紙に出さない。違う欄に書くくらいなら空ける
- 医療班の要約は台帳の値の並べ替えだけで、医師が書く欄は空欄のまま。医療の助言をしない
- 今の守り（連絡先の置けず 0、正解に無い印 0、置き間違い ≦ 195、選択肢 ≦ 24、要修正 0）を戻さない
- 触らない所: 画面（T173）、lib/drill（T174）
- 本物の API は呼ばない。確かめは偽の client のテストと、保存された読み取りの答えの数え直し。記録の中身は repo に写さない（数と形だけ）

## 確かめ

関係するテスト（lib/forms・tools/eval/forms、--maxWorkers=2）、`npm run -s typecheck`、`npm run eval:forms` の偽の回と保存した答えの数え直し。
