# T177 訓練の本人役の時刻の言葉・手なしの移動・呼び出しの数（評価の 10 回目）

意図: 評価の 10 回目（docs/progress/eval-r10.md の「直す所」の 3・4）で T174 の形は消えたが、審査役の人ごとの筋は 2・2・2 のまま、理由が別の形に移った。その形を全部の想定・全部の人に効く形で直す。

1. 切れた時刻の言葉。帳面が経過の数で渡すので、本人役の言う時刻がずれる。時計の時刻と今からどれだけ前かで渡し、台に帳面と言葉の時刻を比べる check を足す
2. 本人役が手なしで移る形（3 回とも）。ケアマネの手も世界の出来事も無いのに、本人役の言葉だけで避難所や病院へ移る。移った事はコードの記録だけに持ち、記録に無い移動の言葉は門で落とす。実際に自力で移れる人の扱いを決めて記録に書く
3. 呼び出しの数を増やさない。r10 は 1 回 77、上限比の最大 62.7%（94 回）で T174 の見込み 57% を超えた。増えた所を調べ、会話の質を落とさず減らせるなら減らす
4. 直した所を tools/eval/guards.ts の守りか台の check に（足し方は docs/progress/t157.md）

守ること: 人の結末・色・連絡順は AI に決めさせない。医療の助言・診断の言葉を書かせない。仮名化の門（askJson）を外さない。訓練の人は AI が演じる架空の人のまま。

触らない所: 画面（動画の撮影が進んでいる）、lib/forms（T176）。

確かめ: lib/drill・tools/eval/drill のテスト（--maxWorkers=2）、`npm run -s typecheck`、台の偽の回。r10 の記録に新しい check を当てた数も出す（読むだけ。記録の中身は repo に写さない）。本物の API は呼ばない。進みは docs/progress/t177.md。
