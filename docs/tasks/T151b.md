# T151b 平時の雨雲が地図に出ない時の見え方（町の縮尺の雨雲・「範囲内 雨なし」・広域の案）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。T151 の続き。docs/tasks/T151.md・docs/progress/t151.md、T72（雨雲）・T148（事業所の地域）の進み、docs/DECISIONS.md の「地図と災害の情報」を読む。コードは components/map（NowcastLayer.tsx・RainScaleLegend.tsx・CaseMap.tsx）、lib/jma/nowcast.ts、lib/map（geo.ts の tilesFor・camera.ts・region.ts）。

## 意図（なぜこの作業か）

本番で、気象庁の雨雲レーダーでは東北に雨がかかっているのに、ケア72 の地図の雨雲には何も出なかった。ケア72 の地図は事業所のまわりを町の縮尺で見せるので、ほかの地方の雨はその地図に入らない。雨雲のタイルは段 5〜10 しか無く、町の縮尺（段 11 より寄った所）で重なっているかも分かりにくい。地図に雨が出ない時に「雨が無い」のか「出ていない」のかが分からない。

線: この作業は Claude を呼ばない。気象庁の画像は加工しない（表示の大きさだけ）。雨は色と連絡順に使わない。地点ごとの雨量や危険度は作らない。

## 作る物

1. **町の縮尺でも雨雲を重ねる**: 段 10 より寄った地図では段 10 のタイルを引き伸ばし、段 5 より引いた地図では段 5 のタイルを縮めて重ねる。今の作りで重なっているかを確かめ、テストで残す
2. **「範囲内 雨なし」**: 地図に見えている所に雨が無いとき、凡例の横に短く出す（雨が地図の外にあってもこの地図には出ないことが分かるように）。読めないタイルがあるときは言い切らない
3. **「広域」の案**: 地図の「全体」「地域」とは別に、県全体〜地方が見える「広域」を足すかを docs/DECISIONS.md に案として（地理院の淡色地図の段 5〜8 の出典の決まりも）
4. **テスト**: 段の引き伸ばしと縮め、見えている画素の範囲、雨の有無、知らせの出し方
5. 手元で確かめるとき、気象庁のタイルを取りに行くのは数回まで
