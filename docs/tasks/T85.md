# T85 書類の紙面を元の様式の書体・大きさ・太さに合わせる

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。指摘の元は docs/progress/screens-20261104.md の「11/4 14:0x の追記」と問い 8。

## 意図（なぜこの作業か）

作者（作者、11/4 14:0x）が「文書関係は、書類自体に書体や大きさ、太さを合わせるべきでは」と言った。ケア72 の紙面は市・国の様式を写す物なので、欄の名前と順（T47）だけでなく、字の見た目も元の様式に合わせる。太さは T47 で合わせ済み。書体と大きさはまだケア72 の共通の決まり（BIZ UDPゴシック、10.5pt など）のまま。

**問い 8 の答えが来てから始める**（11/3 の「明朝にしない」「余白を詰める」を改めるため）。

## 作る物

1. **元の様式を読み直す**: T47 と同じく、リポジトリの外の一時フォルダで読む（松山市の様式【2026.9.10】の PDF、災害診療記録2018 の PDF、BCP ひな形の Excel の様式 9）。PDF は pdf.js で字の塊ごとに書体の名前・大きさ（pt）・位置、Excel はセルの書体・大きさ・太字と列幅・余白。PDF・Excel・抜き出した字はリポジトリに入れない
2. **照合の表に足す**: lib/forms/form-audit.ts の様式ごとの bold と同じ形で、書体と大きさ（題・段の名前・欄の名前・値・注）と頁の余白を持ち、form-audit.test.ts で固定する。docs/progress/t47.md の照合の表にも出る（auditMarkdown）
3. **紙面に当てる**: components/forms/paper.css の様式ごとの変数（.paper.form などの --fs-*）と form9-paper.css を、元の大きさ・余白に。書体は置き換えの表で:
   - BIZ UDゴシック・MS ゴシック・MS P ゴシック → BIZ UDPゴシック（今のまま）
   - MS 明朝・明朝の題 → BIZ UDP明朝（OFL。app/layout.tsx で next/font の Google Fonts から読む。紙面のページだけ）
   - 本人の 1 枚・QR の紙・訓練の記録は元の様式が無いので変えない
4. **頁割り**: 元の大きさで、計画書・医療要約・様式 9 の頁数が元の様式と同じになるか lib/forms/print-pages.test.ts で数える。元より増えるなら直す前に止めて記録に書く
5. **テスト**: `npm test`・`npm run typecheck`。画面は `npm run dev` で計画書・医療要約・様式 9 を開き、元の様式と並べて見比べた所を docs/progress/t85.md に書く（PDF の画は入れない）

## 触るファイル

## 守ること

欄の名前・順・選択肢（T47）は変えない。画面の書体（Inter ＋ 端末の日本語書体）は変えない。MS の書体を配信に入れない。様式の字を言い換えない。
