# T110 時間を使う手・時間と状況で変わる手・打った文をそのままの手に・細かなログ（Opus、分岐）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。T90〜T94（連続の時計・手の表 v2・本人役の往復・採点）、T104（訓練の世界・訓練する人の身の回り）、T105（経過の 3 つのタブ）を取り込んだあとの物。

## 意図（なぜこの作業か）

訓練するケアマネが、実際の 72 時間のように、時間に応じて細かな手を自由に打てるようにする。訓練は型にはめられないので、決まった手の一覧だけに閉じない。

今の作りでは、手は表（lib/drill/action-catalog.ts）の 18 で、所要時間は表で固定。夜・停電・浸水・通行止め・職員の数・ケアマネ自身の被災で、できる手と所要が変わらない（通行止めの家への訪問も押せて、結果で「通行止」と返る）。自由対応の文は表の手への読み替えに閉じていて、当たらなければ「記録」に落ちる。手の行は打った時刻だけで、ケアマネと職員の時間がどれだけ埋まったか、次にいつ空くかが見えない。

## 作る物

### 1. 時間を使う手

- 手を打つと、その手の所要の分だけケアマネ（と職員）の時間が埋まる。短い手を何本も重ねて打てる（例: 5 分の電話を 3 本、そのあと 40 分の訪問）
- 時計は今の進め方（30 分・1 時間・3 時間・次まで）に加えて、「手の分だけ進む」も選べる
- 埋まった時間・空いている職員・次に空く時刻が見える
- 手の行に、打った時刻と終わる時刻

### 2. 時間と状況で変わる手

- 夜（暗い・電話に出にくい）・停電（携帯の電池・固定電話）・浸水や通行止め（訪問の所要が伸びる・行けない）・職員の数・ケアマネ自身の被災（T104 の自分の出来事）で、手ができる／できないと所要が変わる
- できない手は押せない。理由を短い言葉で出す（常設の長い説明文は置かない）
- 決まりは lib/drill の 1 か所の表に置く。押せる・押せないの元にする事実は、ケアマネに分かっている事実だけ（T105 の公表の線・T94 の knownOf とそろえる）

### 3. 打った文をそのままの手に

- 自由対応の文を、決まった手への読み替えに閉じず、そのままの手として扱う
- 文 → AI（仮名化の門を通す）が「相手・所要・できるか（理由）・起きたこと」を決める。打つ前に読み替えた中身（相手と所要）を見せ、ケアマネが確かめてから打つ。決まった手に当たるならその手を使う
- 所要は上限と下限の中で
- 色と連絡順はルールの表（lib/triage）だけ。自由の手は表を直接動かさない（本人役や世界を通して安否が変わるのは今と同じ）
- 文の長さの上限は今の 120 字から見直してよい（理由を docs に）
- 採点（T94）と講評は自由の手も数えられるように

### 4. 細かなログ

- 1 回の訓練の手と出来事を、打った時刻・終わった時刻・所要・相手・結果・AI の判断の理由（短く）で残す
- 訓練記録の画面と紙と CSV に出す
- サーバー側にも AI の判断の記録（仮名化したあとの入力と出力の要約）を残し、評価の台（T108、同時に作業中）が読めるようにする。読み口と形を docs/progress/t110.md に書く

### 5. テスト

- 重ねた手の時間の計算、夜と停電と通行止めでの可否と所要、自由文の読み替えと確かめ、仮名化、採点に入ること、10 分版の動き
- 画面は 375・1280、ライトとダーク

## 守ること

- 色と連絡順はルールの表だけ。自由の手は表を直接動かさない。Claude の出力は色と順番に触れない
- 本人役の決まり（名前・住所・電話を言わない、診断・判定・重症・病名・薬の量・助言を言わない、「死亡」の語を使わない）は変えない。119 は勧めるまで
- ケアマネの文は仮名化の門（lib/pseudonym → askJson）を通し、伏せきれなければ断る。askJson の外に Claude を呼ぶ道を作らない。文と判断の記録は監督・世界・本人役・講評の入力に流さない（withoutMemo で落とす）
- 10 分版は短く終わる形を保つ（手の時間の計算は効いてよい）。審査員の流れを壊さない
- 本物の API・本番の D1（--remote）に触らない。鍵を探さない。.dev.vars を読まない。履歴を書き換えない。他の worktree に触らない（評価の台 T107・T108 が同時に動く。T108 は engine の公開の入口を使う）
- 画面の言葉は 2〜4 字の漢語。常設の説明文を置かない。見出しに読点・句点を付けない。使わない語: 診断・判定・重症・緊急度・札
- 見た目の避ける型: ピル型、番号ラベル、等幅のラベル、グラデーション・光る影、字間、絵文字、`<details>` の黒い▼、真っ黒の塗りボタン、テーマ色の薄い下地。押したときは灰色だけ。新しい押せる物には focus-visible:outline-solid。375px で押せること
- 文書に作者の発言の引用・作業のやり取り・人の名前を書かない（公開のリポジトリ）。作業者の一時ファイルは scratchpad の `t110/` の下
- PR の前に origin/integrate/t11-t12 を取り込んで衝突を解く（両方を活かす）。merge commit にも Co-Authored-By。migration は要らない見込み
