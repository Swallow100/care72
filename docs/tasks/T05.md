# T05 松山市の様式の紙面（画面と印刷）

## 目的

台帳から松山市「避難行動要支援者名簿登録申込書 兼 個別避難計画」（2026.9.10 版、2 ページ）が埋まる。PDF を開かなくても画面の中でそのまま見え、印刷と提出のときだけ PDF（ブラウザの印刷）にする。

## 読む物

docs/SPEC.md の「出力物 5 つと様式の対応」（松山市の段、様式対応の作り方）。市の PDF は[リンク](https://www.city.matsuyama.ehime.jp/kurashi/fukushi/shogai/hinankodo/kobetsuhinannkeikaku.files/R8.9.10keikaku.pdf)で読む。リポジトリに入れない。文字が画像なので、欄の名前と順は自分で起こす。

## 作る物

- `lib/forms/matsuyama.ts`: 欄の一覧（名前・順・台帳のどの項目から・値の形）。同意 4 つ（名簿登録・計画の共有・実施者ごと・組織。組織は「計画の共有」から出す。docs/DECISIONS.md 7）。避難のタイミングに「レベル 3 高齢者等避難」
- `app/people/[id]/forms/matsuyama`: A4 表裏の紙面を HTML + CSS（`@page`、A4、余白）で描く。画面でそのまま読め、ブラウザの印刷で PDF になる。PDF のライブラリは入れない
- 医療の欄は「かかりつけ医・薬局 医薬品情報」の 1 行だけなので、薬・機器の詳細は特記事項と「別紙 あり」。別紙は T07 の要約
- 空欄は「未確認」と印刷される（計画に残す決まり）
- 本人のページの「書類」から開く。差し込みは氏名・住所を含むのでブラウザで行い、Claude を呼ばない
- テスト: 10 人の台帳から欄が埋まり、同意のない範囲が落ちること（7 加藤・9 渡辺）

## 終わりの形

- 山田 ハナの様式が 2 ページで出て、印刷プレビューが A4 に収まる。未確認 3 か所が「未確認」と出る

## 触るファイル

lib/forms/、app/people/[id]/forms/、components/forms/、docs/PROGRESS.md

## 守ること

市の PDF・画像をリポジトリに入れない。欄の名前と順をコードに持つのはよい。様式の見た目（罫線の位置）を真似しすぎない。読めて提出できる紙面でよい。
