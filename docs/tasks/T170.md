# T170 仮想モードの地理を実の物に

意図: 仮想モードの架空の町と川だと、使う人が地理を知らず対応の仕方が分からない。事業所の実の地理にする。人は「AI が演じる架空の人」のまま。

## 直す所

1. デモ事業所も含め、世界に渡す地理を実の物にする。ピンの座標から実の地域を決め、実の川の名前・標高・ハザード（ハザードマップの層で確かめられる範囲）を渡す。架空の町・川・道の種をやめる。確かめられない物は一般の言い方。データを作らない
2. 種の 10 人の町名は架空のまま変えない。出来事はピンの位置で人に当てる（どの区画に誰がいるかはコードだけが知り、Claude には別名か仮名）
3. 避難所は公的なデータがあれば実の名前を世界の出来事に使う。無ければ一般の言い方。訓練の上の 1 行を、人は架空・地理は実在・出来事は想定と分かる文に。透析先などの施設は種の架空の名前のまま
4. 仮想の訓練の画面に、担当一覧と同じ地図（ハザードの層とピン、全画面と拡大）を出し、世界の出来事を地図の上と一覧に場所が分かる形で出す。雨雲・震度の扱いを決めて注を直す
5. ほかの事業所（台帳の町名から作る形、T70）の動きを壊さない。実の地理は全部の事業所に効く形で
6. 直した所を守りと台の check に足す。架空の町と川の名前が世界の文に出ないこと、町名と仮名の門を通ることをテストで固定する

## 触らない所

人の結末・色・連絡順の決め方（時計の計算とルールの表）。Managed Agents の世界の部屋と 1 回呼びの切り替え。仮名化の門。
