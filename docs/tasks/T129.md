# T129 訓練の自由対応を、分かる・筋の通る形に（状況に沿った結果・扱いの言い方・内部の名前を出さない・打った文のまま）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。訓練の手の作り（docs/tasks/T91・T110・T123 とその進み）を読んでから始める。

## 意図（なぜこの作業か）

地震想定で電話が通話不可の間に、訪問で本人の家に着いたあと、自由対応に「本人の名前 ＋ 危険な状態なので 119」の文を打って実行すると、次のように出た。

- 見出し「自由対応 読替 記録」、結果「記録済 記録した」
- 内容に、打っていない「（氏名）」が付いた文
- 理由（AI の印）に、手の内部の名前（英字の id）と「一覧に 119 の手が無いので電話とした。扱いはケアマネが決める」の形

問題は 4 つ。

1. 「読替」が何の意味か、初めて見て分からない。何として扱ったかが見出しから読めない
2. 画面に出る文に、手の内部の名前（英字）が出た
3. 読み替えの筋が通らない。119 の意図は 119勧奨に当てる決まりなのに、候補の一覧に無いと言い、「電話とした」と言いながら結果は記録で、判断を人に返して終わる。原因は、本人を選ばずに打つと、本人の要る手（119勧奨など）が候補から全部落ち、119 に当たる文が行き場を失って黙って記録に落ちたこと。候補に無い手は Claude に見えず、できない理由も渡っていなかった
4. 内容に伏字の跡（「（氏名）」）が残る。画面の内容が、打った文でなく「伏せた文を氏名に戻した物」だったため。台帳の名前と書き方の違う名前（ひらがな・漢字・半角の名）を打つと、姓だけが仮名になり、名が（氏名）になる

加えて、自由対応は、表の手に当てる「読み替え」を主にせず、シミュレーションしている AI が今の状況を全部見て「この状況でこの文の行動をすると何が起きるか」を決める形にする。訪問先にいる・電話が通じない・夜、などで、現場でできる事が変わるのが現実の 72 時間。コードが持つのは色と連絡順（ルールの表）・事実の制約（手の可否と所要の決まり・職員の数）・世界を変える範囲の上限だけで、AI の答えはその制約で確かめる。

## 作る物

1. **扱いの言い方**: 「読替」を、何として扱ったかが分かる言い方に。見出し・打つ前の確かめ・履歴・訓練記録の紙・CSV・採点の言葉をそろえる（2〜4 字の漢語の方針の中で、初めて見て分かる物。案を 2〜3 出して選んだ理由を進みに書く）。読み替えの待ち・文を直したあとの読み直しのボタンも同じ考えでそろえる
2. **内部の名前を出さない**: 画面に出る文（AI の 1 文・理由・できない理由・起きたこと・代わりの道）に手の id・英字を出さない。手の名前・相手の言い方に置き換え、残れば出さない。指示の文でも禁じる。全部の AI の出力の門（T125）とは別に、自由対応の口で確実に
3. **筋の通る読み替え**:
   - 候補には全部の手を、今できるか・できない理由（手の可否と所要の決まりの結果と、本人を選んでいない・相手の連絡先が無い）と一緒に渡す
   - 意図が今できない手（通話不可の 119勧奨など）に当たったら、その手として「できない」と理由を返し、今できる別の道（その場の職員・訪問中なら現場でできること・近くの人・自由対応のやり方など。医療の助言にしない）を短く示す。黙って記録に落とさない
   - 本人を選ばずに、文に参加者の名前が 1 人だけ書かれていれば、その人を対象にする（伏せた文の仮名から決める）
   - 何もしない文だけを「変化なし」に（「記録」の手は手の一覧から外すので、読み替えの候補にも入れない。前の訓練の再生のために、保存した「記録」は読めるまま）
4. **状況に沿った結果**: AI に今の状況を全部渡す（ケアマネが今いる所〔事業所・訪問先の家・避難先〕、電話・停電、本人の家の電話・家の前の道、警戒・浸水・津波、避難所、職員の空き、対象の人の分かっている様子・頼み事・向かっている人、時刻と夜）。表の手に当たる時は、その手の決まりで動かす（採点のため）。当たらない時もその行動として、所要・結果（事実と確率で決める）・世界の小さな変化（その人に届いた・誰かが向かった。閉じた一覧の中だけ）を返す。左の表（色と連絡順）に届く効き目は持たせない
5. **打った文のまま**: 画面の内容はケアマネが打った文のまま。Claude には伏せた文。名前の書き方で仮名化の当たりが外れる形を確かめ、進みに書く
6. **テスト**（偽の client）: 同じ型の文で全部の手を確かめる（119・薬・電源・移送・避難・家族への連絡・記録だけ・何もしない、を電話が使える時と使えない時で）。内部の名前が出ない、できない手をできないと返す、打った文が内容に出る、名前からの対象の決め
7. **評価の台**（tools/eval/drill）: 自由対応の検査に「画面に内部の名前が出ない」「できない手をできないと返す」、同じ文を状況違い（事業所／訪問先、通話可／不可、昼／夜）で投げて結果が状況に合うかを足す（本物の API は呼ばない。偽の答えで）

- 色と連絡順はルールの表（lib/triage）だけ。自由対応の効き目は左の表に届かない（聞いた安否・時計の頼り先の確認は持たせない）

- 画面の言葉は 2〜4 字の漢語。常設の説明文を置かない。CLAUDE.md の避ける見た目の型
- 文書に作者の発言の引用・作業のやり取り・人の名前を書かない（公開のリポジトリ）。テストの文は架空の 10 人の名前で。作業者の一時ファイルは scratchpad の `t129/` の下
