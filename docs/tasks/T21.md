# T21 着信の画面と声（Gemini TTS）

## 目的

訓練の着信をアプリ内の着信画面と声（Gemini TTS）で再現する。本物の回線は使わない。全員でなく数人分（山田の娘、小林の夫、佐藤本人）。動画の「訓練」の場面で電話が鳴る。

## 読む物

docs/SPEC.md の「訓練」（着信はアプリ内の着信画面と声）、「個人情報」（TTS には名前を入れず「あなた」で読む）。lib/gemini/tts.ts（T00）、T18 のペルソナの speech。

## 作る物

- `components/drill/IncomingCall`: 着信の画面（相手の役割名と本人の仮名でなく、ケアマネの画面なので本人の名前でよい。名前は TTS に渡さない）。出る・出ない。出ると音声が流れ、文字も出る
- `lib/drill/voice.ts`: ペルソナの speech を Gemini TTS で音声にし R2 に置く（訓練ごとにキャッシュ）。役割ごとに声を分ける（娘・夫・本人）。未設定なら文字だけ
- 着信の順と割り込み: 刻みの中で「連絡する」と出た信号のうち、電話の形の物だけ着信に。1 刻みに 1〜2 件まで（多いと鳴りっぱなしになる）
- 本人の録音（赤 → 音声）の再現: ペルソナの speech を TTS で読んだ物を「録音」として左の表の行の詳細に置く（発災時の録音と同じ場所）
- テスト: 着信の数の上限、TTS に名前が渡らない、未設定で文字だけになる

## 終わりの形

- 訓練（大雨）3 時間で小林の夫から着信が鳴り、出ると「呼吸器の電池があと 2 時間しかない」と声と文字で流れ、左の表の小林が黄になる

## 触るファイル

components/drill/IncomingCall、lib/drill/voice.ts、app/api/drill/voice/、docs/PROGRESS.md

## 守ること

TTS に氏名・住所・電話を渡さない。本物の電話をかけない。Gemini は声だけで、考える所に使わない。
