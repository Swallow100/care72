# T52 写真・PDF を Claude に送る前に、写った氏名・住所・電話を塗って隠す（Opus、分岐）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md`（何を作っているか・越えない線・地図・進め方）→ `CLAUDE.md` → `docs/tasks/README.md` を読む。この文書は、それ以外に何も知らなくても作業できるように書いてある。

## 意図（なぜこの作業か）

ケア72 の越えない線の 1 つは「氏名・住所・電話・町名を Claude に渡さない。必ず仮名にしてから」（CONTEXT.md の 2）。文字は lib/pseudonym の門を通るが、T45 で足した本人のページの入れる欄の「写真・PDF を読む」（/api/intake/read）は、写真に写った氏名・住所・電話をそのまま Claude に送っている。今は読む前に確認の窓で伝えるだけ。作者（作者、11/3 17:1x）の判断: 送る前に、写った所を指で塗って隠す道具を足す（様式だけに戻すのではなく、機能を残したまま線を守る）。審査では「深さ」「安心して使える形」に効く。

## 目的

写真・PDF を選んだあと、Claude に送る前に「隠す」の画面を必ず通す。ケアマネが氏名・住所・電話・町名の写った所を四角で塗りつぶし、塗った後の画像だけをサーバーへ送る。元の写真・PDF はブラウザの外へ出さない。

## 読む物

docs/DECISIONS.md の 11/3 17:1x 確定、docs/tasks/T45.md・docs/progress/t45.md（写真の注意の問い 1）、components/person/Intake.tsx ほか入れる欄の部品、app/api/intake/read（写真・PDF を受ける所）、lib/claude/call.ts（attachments）、lib/pseudonym、components/ui（Button・Icon・DialogHost・Loader72）、CLAUDE.md「画面の決まり」。

## 作る物

1. **隠す画面**（入れる欄から開く全画面の窓。components/person/ の新しい部品と lib の純な計算）
   - 写真は 1 枚ずつ、PDF は頁ごとに画像にして（ブラウザの中で。pdf.js 系を足すなら Apache-2.0 か MIT の物だけ、THIRD_PARTY.md に足す。重ければ PDF は 1 頁目〜3 頁目までなど上限を決めて progress に）並べる。
   - 指・マウスで四角を引くと黒く塗る。塗った四角は押して「外す」。取り消し（1 手戻す）・全部外す。拡大して細かく塗れる（ピンチ・ホイール・ボタン）。
   - 送るのは塗った後の画像（canvas から JPEG）だけ。画像の EXIF（位置・端末）も落ちる形にする（canvas を通すので落ちる。テストで確かめる）。元のファイルはサーバーに送らない・保存しない。
   - 決めるボタンは「送信」。塗った所が 1 つも無いときは、押すと確認の窓「隠す所なし」で「隠す所は無い」「戻る」の 2 つ（T51 の appConfirm か appChoice）。
   - 見た目は CLAUDE.md の決まり（アイコン＋文字、2〜4 字の漢語、押したときは灰色だけ、画面の中にスクロールの箱を作らない＝画像は画面の幅に合わせ、拡大中だけ画像の中を動かす）。言葉の一覧を progress に（設計の側が Gemini に通す）。
2. **入れる欄の流れ**: 写真・PDF を選ぶ → 隠す画面 → 送信 → 今までどおり AI が欄に分ける。T45 で足した「読む前の確認の窓」は、この画面に置き換える（同じことを 2 回聞かない）。
3. **サーバー**: /api/intake/read は、隠す画面を通った物だけを受ける（受け取る形に印を付ける。たとえば送る形を画像だけにして、PDF の生のファイルは受けない）。ai_calls と上限は今のまま。
4. **画面の印**: 読んだ結果の欄の AI の印はそのまま。経過に「写真を読んだ（隠した所 N か所）」を残す。
5. **テスト**: 四角の計算（拡大した座標 → 画像の座標）、塗った画像のピクセルが黒いこと、EXIF が残らないこと、塗らずに送るときの確認、サーバーが生の PDF を断ること。既存のテストを壊さない。
6. **絵**: docs/progress/t52/ に、隠す画面（塗る前・塗った後）、1280 と 375。
