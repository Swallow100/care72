# T102 避難経路の地図（家と避難先から経路を引き、紙の欄に）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。

## 意図（なぜこの作業か）

松山市の計画書の 2 頁「避難経路」の欄は、原本の注に「地図上または箇条書き等で避難経路を記入」とある。今は台帳の文字（ledger.evacuation.route。種の 10 人もほとんど未入力）を書くだけで、地図は無い。家の位置と避難先が分かれば、経路を引いた地図を作れる。ケアマネが倍率と上下左右を直して欄に収め、そのまま紙に刷る。

今の事実:

- 家の位置は台帳にある（ledger.basic.location。番地は持たない。地図のピンと同じ。Claude には渡さない）
- 避難先（避難先 1・2）は台帳の文字だけで、位置が無い。避難所の表も無い
- 地図は地理院の淡色地図（lib/map/layers.ts）
- 家の位置を外のサービスに送るのは新しい流れ。今は位置を氏名・住所と同じく Claude に渡さない扱い

## 先に決めること（問い）

経路をどこで引くか。

- (a) Google の Routes API（経路）と Maps Static API（紙に刷る地図の画像）。鍵と課金の口座が要り、作者が Cloudflare の secret に入れる。Google の経路の結果は Google の地図の上に出す決まりがあるか、刷った紙を手元に残してよいかを、作業者が Google Maps Platform の利用規約で確かめる（地理院の地図の上に Google の経路は描けないかもしれない）
- (b) OpenStreetMap の経路（OpenRouteService・Valhalla など、徒歩と車）を地理院の地図の上に描く。出典の表記と、無料の枠の回数を確かめる
- (c) 経路は引かず、家と避難先の 2 点を地図に置き、ケアマネが経由の点を手で足す

どれでも、外に送るのは 2 点の座標と手段だけ（氏名・住所の文字・台帳は送らない）。

**決め（11/4 夜）: (b)。** OpenStreetMap の経路（openrouteservice、徒歩と車）を地理院の地図の上に描く。鍵は作者が作り、Cloudflare の secret の ORS_API_KEY に入れる。鍵が無いときと外の呼び出しが失敗したときは、(c) の手で引く形で動く。外に送るのは 2 点の座標と手段だけ。出典の表記と無料の枠の回数・利用の条件を確かめて docs に書く。地図は雨の層（T103）と別の部品にし、components/map の雨と状態の層は触らない。紙の欄への地図は、T101（元の様式に重ねる紙）の受け口ができてから入れる。

## 作る物

1. **避難先の位置**: 避難先 1・2 に位置を持たせる。地図で置く（components/person/LocationPick.tsx と同じ形）か、指定緊急避難場所の一覧（国土地理院の公開データ。使ってよいかと出典の表記を確かめる）から市の中で選ぶ。位置は台帳に（Claude に渡さない側。lib/pseudonym を通さない）
2. **経路**: 問いの答えの道で。手段は台帳の「手段」（車・徒歩・家族の車）から選び、分からなければ徒歩
3. **地図の直し**: 本人のページの避難の面の「経路」から開く。家・避難先・経路。拡大・縮小・上下左右（T86 の確かめの画面の直しと同じ操作の形と言葉）。決めた中心と倍率を本人の台帳に保存。経路を引き直すのはケアマネが押したときだけ（開くたびに外へ要求しない）
4. **紙**: 計画書の 2 頁の避難経路の欄の枠の中に、決めた範囲の地図の画像と経路。地図の出典は枠の中の下に小さく。枠の大きさは変えない（T101）。台帳の文字の経路があれば地図の下に。本人の 1 枚にも小さく出すかは問い
5. **テスト**: 避難先の位置の保存と読み出し、外に送る物が座標と手段だけ（氏名・住所が入らない）、紙の欄に収まる、経路が無いときは文字だけ。本物の API はテストで呼ばない。375・768・1280、ライトとダーク

## 触るファイル

components/person（避難の面と地図の直し）、components/map、lib/map、lib/forms（計画書の避難経路の欄）、components/forms/MatsuyamaSheet.tsx、lib/db/types.ts の Ledger の避難の欄（位置と地図の範囲）、docs/progress/t102.md。migration は要らない見込み（台帳の JSON の中）。

## 守ること

外のサービスに送る物を増やすのは問いの答えのあとだけ。鍵はリポジトリ・ログ・画面に出さない。地図の色・ピンは今の決まり（状態の色はピンだけ）。
