# T50 仮想モード（Managed Agents の世界の部屋、自由な本人役、結末まで。Opus、分岐）

## 目的

今の訓練は固い: 想定の表（lib/drill/scenarios.ts）が出来事と「誰がいつ赤を押すか」を決め、監督（Opus）が差し込める出来事は 6 種類だけ、監督には「亡くなる・意識がない・火事を作らない」と指示している。作者（11/3 14:4x・15:0x、docs/DECISIONS.md）: 災害はそんなに固定化された事ばかり起きない。事業所の地理の範囲で、架空の人の結末（生き死に）までオブラートに包んで出す「仮想モード」を作る。Managed Agents を使う（世界を持ち続ける部屋）。途中で監視役が口を出す必要は無い。アドバイザー（11/3 14:1x）は「架空の人の病状はシナリオ上の事実で、本物の人への判断ではないので問題になりにくい」と言っている。

10 分版と大雨・地震の固定の筋は審査員とデモ用に残す（変えない）。仮想モードは 3 つ目の種類として足す。

## 作る物

1. **種類「仮想」**: DrillScenario に `virtual` を足す（lib/db/types.ts・labels・drills.scenario の CHECK は migration で。番号は origin を見て空いている物。0002〜0004 は済み、0005 は T47）。開始の画面に「仮想」を足し、見出しの下に 1 行「仮想モード 架空の人と街。結末まで出ます」。10 分版は先頭のまま（11/3 08:0x の確定）
2. **事業所の地理（コードの種）**: lib/drill/area.ts に、デモ事業所の範囲の架空の地理を持つ: 町名（種の 10 人の台帳の町名 ＋ 架空の町を数個）、川、町ごとのハザード（洪水の深さ・土砂・津波）、避難所、頼り先（透析施設・訪問看護・配達）、主な道、停電の送電の区分。全部架空で、実在の地名を使わない（松山市の町名も使わない。台帳の種がすでに架空の町名なら、それに合わせる）。本人のページの住所とこの地理の結び付き（誰がどの町か）はコードだけが知る
3. **世界の部屋（Managed Agents、Opus）**: lib/drill/world-room.ts
   - Agent は 1 回作って ID を残す（`client.beta.agents.create`: model は lib/claude/models.ts の OPUS、system は WORLD_SYSTEM、tools は custom tool `world_step` だけ。砂場の道具（agent_toolset）は付けない）。Environment も 1 回（cloud）。ID は D1 の小さな表 ai_agents（purpose・version・agent_id・environment_id）に持ち、無ければ作る（作るのは 1 回。毎回 create しない）。system を変えたら `agents.update` で版を上げ、新しい訓練から新しい版
   - 訓練を仮想で始めたら session を 1 つ作り（`sessions.create`、agent は ID、budget は `max_list_cost` を "300"（$3）に）、drills に world_session_id を持つ（migration）。session は訓練が終わっても archive・delete しない
   - 刻みごと（engine の step の監督の所）: `sessions.events.send` で user.message を 1 つ送る。中身は仮名化した文だけ（今の sceneText・weaknessText と同じ門。氏名・住所・電話・町名を本人に結び付けて渡さない。地理は「〇〇町は川沿いで洪水 3m の想定」のような地理の事実だけ）。前の刻みの出来事は部屋が覚えているので送り直さない（最初の刻みに地理の全部と 10 人の弱点、以後はその刻みの時刻・ケアマネの手・本人からの連絡の要約だけ）
   - 返事の受け取り: `sessions.events.list` を 1.5 秒ごとに読み、`agent.custom_tool_use`（name が world_step）が来たら input を zod（WorldStepSchema）で検査し、`user.custom_tool_result` を返して session が idle になるまで待つ。60 秒で時間切れ。Workers の 1 要求の中で済ませる（SSE の stream は使わない。長い接続を持てない）。切れた接続の取り直しは events.list で id をそろえる（client-patterns の Reconnecting）
   - 1 刻み 1 回を ai_calls に残す（purpose は director、model は session が答えたモデル。usage.ts の beginCall を通す。上限に達したら呼ばない）
   - **切り替えと戻し**: env `DRILL_WORLD`（`session` 既定・`messages`・`off`）。session が作れない・時間切れ・形が違う・上限・鍵なし、のどれでも、その刻みは lib/drill/world-oneshot.ts（askJson、output_config.format で同じ WorldStepSchema、system は同じ WORLD_SYSTEM、入力は世界の履歴の要約を足す）に自動で落ち、それも失敗なら差し込みなしで進む（今の監督と同じ）。落ちた刻みは docs 用の記録（drill_events）に残す。審査員の 10 分版は今の監督のまま（仮想だけが部屋を使う）
4. **世界の出来事の語彙（6 種類の縛りを外す）**: WorldStepSchema = { narration: 60 字までの世界の 1 文（ケアマネの画面の「状況」に AI の印で出す）, events: [{ kind, town?, target?, name?, value? }] 0〜4 個, farewells: [{ target, text }] 0〜N }。kind は 浸水（町・深さ）・土砂（町）・道路（道の名前か町・通行止か開通）・停電（町の一覧・始まり/復旧）・断水（町）・通信（電話の様子）・避難所（名前・開設/混雑/閉鎖）・施設（名前・休止/再開。透析施設など）・余震（震度）・天候（大雨/止む）。target は本人の仮名（「A さん」）で、「A さんの町が浸水」のように人から町を引ける（コードが仮名 → 本人 → 町に戻す。部屋は町を知らない）。知らない町・仮名・種類は捨てる。人の生き死に・けが・病状は events に無い（本人役が演じる。WORLD_SYSTEM に「人の体の状態を書かない。書くのは街と物の事実だけ」）
5. **出来事を人に当てる**: lib/drill/world-apply.ts。浸水 → その町の人の印（waterDepth）と本人役への状況、土砂・道路 → 通行止（訪問・出向きの手が届かない。今の roads）、停電 → OutageArea に `{ scope: "towns", towns: [...] }` を足し、lib/disaster/state.ts の inOutageArea と lib/triage の時計がその町の人で走る、断水 → 印、通信 → phoneOf、避難所・施設 → 今の shelters・facilities、余震・天候 → 本人役への状況だけ。採点（score.ts の「条件に達した人」の停電の判定）も towns の範囲を読む
6. **本人役を自由に**: 仮想では想定の表の行が無いので、毎刻み Haiku が状況（自分の町の浸水・停電・道・余震）と自分の時計（残り時間）から決める（今の「表の行が無い刻み」の道）。PERSONA_SYSTEM に足す: speech は、いる場所（家のどこ・階）、閉じ込め・挟まれ（何に）、体の訴え（本人の言葉で。「胸が少し痛い」「足を打った」）を含めてよい。決まり 7（診断・判定・重症・病名の言い切り・薬の量・助言を書かない）はそのまま。condition（見て分かる様子）も今のまま。本人役の返事の形は変えない（T49 の聞き取りメモが同じ Haiku の分類で欄を埋める）
7. **結末（AI が決めない）**: lib/drill/outcome.ts。刻みごとに、走り出した時計が切れて、切れる時刻までに届いた手（通話・到着・手配済・受入）が 1 つも無い人を「条件に達した」と**コードが**決める（score.ts の計算をここに切り出して両方から使う）。その刻みの world_step の入力に「A さんは条件に達した（酸素の電池 2 時間を超過）」と伝え、farewells に A さんへのオブラートに包んだ 1 文（60 字まで）を書かせる。禁じる語（死亡・亡くな・死ん・関連死・遺体・息を引き取）があれば捨てて固定の文「A さんには、この時間までに助けが届きませんでした」に。以後その人の本人役は呼ばず、信号を出さず、着信も鳴らない。訓練の画面のその人の行に印「結末」とその 1 文（AI の印、または固定の文）。ルールの表の色は変えない（表に「結末」の行を足さない。lib/triage は触らない）。講評（T22）の「条件に達した人」は同じ計算なので数が一致する
8. **画面**: 開始の種類に「仮想」、訓練の画面の上に「仮想モード 架空の人と街。結末まで出ます」の 1 行、状況の欄に部屋の narration（AI の印）、本人の行に「結末」の印と文、落ちて一回呼びに戻った刻みは「世界 代替」の小さな印（AI の印の横）。10 人の「AI が演じる架空の人」の印（T48）はそのまま
9. **docs/CLAUDE_CODE.md**: 「Managed Agents」の保留の行を書き換える。使う所（仮想モードの世界の部屋。72 時間の街の流れを 1 つの session が持ち続け、返事は custom tool の schema で縛る）、使わない所（分類・色と順・本人役 10 体・講評・固定の筋の監督は Messages API の 1 回呼び）、理由（道具を回すループが要るのは世界だけ。落ちたら 1 回呼びに戻る）。docs/JUDGING.md の「Claude の活用」の行も合わせる
10. **テスト**: WorldStepSchema と捨て方（知らない町・仮名・種類、禁じる語）、town の OutageArea、出来事を人に当てる（町 → 人、target → 町）、結末の判定が score.ts と一致、部屋が落ちたときの一回呼びへの戻り（偽の client）、ai_calls が 1 刻み 1 行、仮想の筋で 10 人が 12 刻み動く（本物の API は呼ばない。偽の部屋と偽の Haiku）。既存の固定の筋のテストが変わらないこと

## 終わりの形

- 「仮想」で始めると、街の出来事が刻みごとに変わり、10 人の本人役が自分の町の状況で動き、助けが届かなかった人には「結末」の 1 文が出る。10 分版と大雨・地震は前と同じ
- env `DRILL_WORLD=messages` で部屋を使わずに同じ形で動く。部屋が落ちても訓練は止まらない
- `npm test`・`npm run typecheck`。docs/progress/t50.md に、作った所、部屋の作り方（agent・environment の ID の持ち方）、落ちたときの道、本番の鍵で最初に確かめること（部屋が作れるか・1 刻みの待ち時間・費用）、問い。PR を integrate/t11-t12 宛に

## 守ること

- AI が決めるのは街の出来事と言葉。人の結末は時計の計算（コード）。診断・薬の量・医療の助言・病状の言い切りは今まで通り書かせない
- 仮名化の門（lib/pseudonym → askJson、部屋への送信も同じ pseudonymizeText）を通る物だけ Claude に渡す。部屋にも氏名・住所・電話・町名と人の結び付きを渡さない
- 本物の API は、docs/progress/t50.md の「本番の鍵で最初に確かめること」に書くだけで、作業の中では呼ばない。偽の client で通す
- 鍵を探さない・置かない。Agent・Environment・Session を archive・delete しない
- T48（components/drill の印、persona.ts の注）・T49（lib/classify、phone）と重なる所は最小の行。PR の前に origin/integrate/t11-t12 を取り込んで衝突を解く。履歴を書き換えない
