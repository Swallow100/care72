# T12 録音と自由文の分類（Haiku）

## 目的

録音の文字起こしと自由文を Haiku が「けが・動けない・水が来た・機器が止まった・不明」の 5 つに分ける。確信が低ければ「不明」。色と順位は lib/triage の表が出し、Claude は決めない。これが発災時の Claude の役の全部。

## 読む物

docs/SPEC.md の「医療の芯」のルールの表の段（Claude の役）、「構成」の Claude の使い所。docs/DECISIONS.md 9。lib/claude（T00）、lib/pseudonym、lib/triage の入力（分類の列）。

## 作る物

- `lib/classify/`: 入力は 文字起こし（無ければ空）・本人の答え（4 問）・音の特徴（無音の割合、MediaRecorder から取れれば）。出力は `{ category, confidence, quote }`。quote は文字起こしからの短い引用（10 字まで）。system に「分類だけ。助言しない。確信が 0.6 未満なら 不明」。JSON は T00 の schema で縛る
- 仮名化: 文字起こしの中の名前・町名は lib/pseudonym の自由文の伏せ方を通す
- 呼ぶ時: 信号が届いたあとサーバーが 1 回。失敗や未設定は「不明」のまま（画面に「分類なし」）
- 行の詳細（T13）に 分類・確信・引用 を出し、ケアマネが分類を直せる（直しは経過に残る）
- テスト: 5 つの分類の固定の応答、低い確信 → 不明、未設定 → 不明、仮名化を通らない入力が型で通らない

## 終わりの形

- 山田の録音の文字起こし「いたい、うごけない」→ 動けない（0.9）→ lib/triage で赤 最上位 → 担当一覧の一番上に「本人が動けない」

## 触るファイル

lib/classify/、app/api/signals/（分類の呼び出し）、components/list/（行の詳細の分類）、docs/PROGRESS.md

## 守ること

分類の結果を「診断」と呼ばない。分類から色を決めるのは lib/triage だけ。うめき声・沈黙は「不明」（docs/DECISIONS.md 9）。
