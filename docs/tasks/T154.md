# T154 事業所の所在地と地域を都道府県 → 市区町村から選ぶ（全国の市区町村の表）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。T148 の頼み文と進み（docs/tasks/T148.md・docs/progress/t148.md）、T72（気象庁の写し）・T134（様式の一覧の地域から選ぶ）の進みを読む。コードは app/office・components/office（事業所の区分・地域）、lib/office（region.ts・place.ts・profile.ts）、lib/jma（alerts.ts・match.ts・store.ts。気象庁の欄がどの地域の発表を読むか）、lib/map（center.ts・region.ts）、lib/disaster、components/AppHeader.tsx・components/disaster/DisasterBadge.tsx、lib/forms/municipal-forms.ts。

## 意図（なぜこの作業か）

T148 で事業所の地域を「主な市＋周りの市」にしたが、市は文字で入れる。文字のままだと次の所で結び付きが確かでない。

- 気象庁の警報・注意報は市町村の名前の文字で突き合わせている（lib/jma/match.ts の sameCity）。打ち間違い・表記の揺れ・別の県の同じ名前の市（府中市・伊達市など）を見分けられない
- 地図の中心と広さは事業所の中心の点と km だけで、市を変えても中心は前の市のまま。周りの市から広さを決める表が無い（T148 の問い 3）
- 様式の一覧の初めの市は名前だけで当てていて、同じ名前の市が 2 つあると決まらない
- 利用者の住所の市が地域の中か外かも、名前の一致だけで見ている

場所を変えたら、気象庁の欄・地図・雨雲・上の帯・様式の一覧の初めの地域がそろって変わることを、表と 1 つの関数で確かにする。

線: この作業は Claude を呼ばない。色と連絡順はルールの表（lib/triage）のまま触らない。気象庁の警報・注意報は見せるだけで、災害モードは切り替えない（押すのは人）。

## 作る物

1. **全国の市区町村の表**: 都道府県・市区町村名・よみ・全国地方公共団体コード（6 桁）・代表の緯度経度と範囲・気象庁の警報・注意報の地域のコード（市町村等〔class20〕と、市町村等をまとめた地域〔class15〕・一次細分区域〔class10〕・府県予報区）を 1 つの表に。元は公的な表（総務省の全国地方公共団体コード、気象庁の予報区等の表と予報区等 GIS データ）。取りに行くのは公式のドメインだけ。作る道具は tools/ に置き、表は lib のデータとして repo に（元のファイルそのものは入れず、要る列だけ）。出典・取った日・利用条件・行数は docs/sources と THIRD_PARTY_NOTICES.md に
2. **選ぶ形**: 事業所の地域（主な市・周りの市）を、文字でなく都道府県 → 市区町村の選択（検索つき）で選ぶ。T148 の文字の値は、表に当たる物は選んだ形に写し、当たらない物は「未選択」で選び直しを促す。列を足すなら migration 0038 以降（ほかと重なったら取り込みで付け直す）
3. **1 つの関数**: 選んだ市区町村のコードから、気象庁の欄（どの市町村等の警報・注意報を読むか）・地図の中心と広さ・雨雲・上の帯の警報の数・様式の一覧の初めの地域が決まる。場所を変えたら全部がそろって変わることをテストで確かめる（大雨の発表の地域、地図の中心、様式の初めの市）
4. **利用者の住所**: 利用者の住所の市も同じ表で当て、地域の外なら「地域に追加」を勧める（T148 の今の動きを表に寄せる）。表に当たらない住所は分けて出す
5. **テストと絵**: 表の形（コードの重なり・都道府県の数・政令指定都市と区・分かれた市）、選ぶ形の保存と写し、場所を変えたときのそろった変わり方。PC の幅の絵。気象庁の本物の電文を何度も取りに行かない（手元の見本 lib/jma/fixtures で）

## 終わりの形

- 事業所の管理者が、事業所の画面で主な市と周りの市を都道府県 → 市区町村から選べる。選んだコードから気象庁の欄・地図・上の帯・様式の一覧の初めの市がそろって決まる
- T148 の文字の地域は、表に当たれば選んだ形で開き、当たらなければ「未選択」で選び直しを促す
- デモ事業所の 10 人の地図・色・並び・審査員の流れは前と同じ。`npx vitest run --maxWorkers=3`・`npm run typecheck` が通る。PR を integrate/t11-t12 宛に

## 守ること

- 色と連絡順はルールの表（lib/triage）だけで決める。気象庁の警報は表示だけで、色・順・災害モードに使わない。この作業は Claude を呼ばない
- 審査員の流れ（ログイン → 役 → デモ事業所の 10 人）を壊さない。デモ事業所の地域は審査員が書けない（T148 の placeEdit のまま）
- 同時の作業: T153（デモの最初を平時に、seed と災害の切り替え）。種の事業所の値はぶつかるので、種はデモ事業所の所在地のコードを足すだけ
- 依存を足すなら MIT・Apache-2.0 だけ。元のファイル（Excel・GIS）はリポジトリに入れない
- 画面の言葉は 2〜4 字の漢語（都道府県・市区町村・主な市・周りの市・未選択・未照合・地域に追加など）。常設の説明文を置かない。見出しに読点・句点を付けない。使わない語: 診断・判定・重症・緊急度・札
- 見た目の避ける型（CLAUDE.md）。選んだ印にテーマ色の薄い下地を敷かない。新しい押せる物には focus-visible:outline-solid
