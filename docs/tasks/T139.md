# T139 評価の 4 回目で残った訓練の AI の問題を直す（本人役の言葉の切れ・人ごとの筋・赤 → 緑の抜け道・出来事の似通い・講評の数・つながりにくい間の電話・台の誤検知）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。評価の 4 回目の報告（docs/progress/eval-r4-findings.md の 1〜4・6〜8 と eval-drill-r4.md）と、訓練の作り（docs/tasks/T125・T127・T130 とその進み、lib/drill の persona.ts〔SPEECH_MAX〕・person-facts.ts・gate.ts・fit.ts・comms.ts・director.ts・world*.ts・review.ts・incoming-talk.ts、tools/eval/drill の checks.ts）を読んでから始める。生の記録はリポジトリの外（評価の台の記録の置き場）にあり、読むだけ。中の架空の人の台詞をリポジトリに写さない。

## 意図（なぜこの作業か）

評価の 4 回目（本物の Claude、T124〜T130 の入った木）で、訓練の AI に次の問題が残った（重い順）。

1. 本人役の言葉が 60 字（SPEECH_MAX）で文の途中で切れ、切れたまま画面と審査役に出る。着信の往復の返事ではほとんどが切れた
2. 固定の筋の回の審査役「人ごとの筋」が 2/5 のまま。根拠に挙がった型: 電池の残りを言ったあと何時間も使えている、避難所にいた人がのちに家の外で動けないと言う、移送の車が来ても動かない、家族が避難所へ向かうと言ったあとも本人の家にいる、支援者が家にいると伝える一方で様子が分からないまま
3. 赤（動けない）から手も到着も無いまま緑に変わる形が、地震の 1 回で帳面の門を抜けた
4. 同じ想定の回どうしで出来事の種類が大きく重なる（0.82）。時間帯の目安の外も 23% に戻った（回線の不通・薬局の休止）
5. 講評の指摘がどの回もちょうど 8 件で、種類の内訳もほぼ同じ
6. 電話がつながりにくい間も、電話の形の連絡が通常のときと同じほど出る
7. 評価の台の禁じた中身の検査が、名前でない言葉（「様子」の「様」、業者の呼び名の「さん」、行頭の言葉）を拾う

考え方は T130 と同じ: **筋の事実はコードが持ち、AI はそれに沿って言葉を作る。** 直すのはどれも一般の決まりとして。特定の人・特定の回に合わせない。

## 作る物

1. **本人役の言葉を途中で切らない**
   - 本人役に短く言わせる: 刻み・まとめ呼び・通話・往復・訪問の指示に字数の上限を書く（決まり 6・7 の文は変えない）
   - 切る時は文の切れ目で切る: 上限の中の最後の句点（無ければ読点）までにする。地区の別名を町名に戻したあとに切る。全部の道（刻み・通話・往復・訪問・する事・様子・ケアマネに言われた事）で同じ関数
   - 上限の字数は、画面（担当一覧・着信・経過）と声の長さを見て決め直す
2. **人ごとの筋を帳面で持つ**（lib/drill/person-facts.ts）
   - 電池などの時計: 帳面の時刻から今の残りを計算して本人役に渡す（内蔵・予備・外の電源）。予備の時間が台帳に無い時の扱いを決めて書く（案）
   - いる所: 移送の到着は帳面のいる所を変える（台帳の避難先の種類へ）。家族・支援者が避難先へ向かうと言った時は、計画に手段があれば移り、無ければ「向かえていない」を帳面に書く
   - そばにいる人: 支援者・家族が本人の所にいると伝えたあと（時間の幅を決める）、様子が分からないと言わない
   - 避難所にいる人が家の外（道・屋外）で動けないと言わない
   - 固定の行と帳面が食い違う時は、固定の行の言葉を帳面に合わせる（色・時刻・4 問・いる所は表のまま。動画の筋の行の言葉と時刻は変えない）
3. **赤 → 緑の抜け道を塞ぐ**: 記録で抜けた道を突き止め、帳面と台の両方を同じ決まりにする（台帳でふだんから歩けない人の「動けない」と、けがや閉じ込めの「動けない」を分けるかを含めて決める）
4. **出来事の似通いと時間帯**: 監督・世界に、その回の種から選ぶ出来事の候補を回ごとに変える仕組み（想定の表の範囲の中で）と、時間帯の目安をコードでも効かせる。通信の段（T125）と回線の不通の出来事を二重にしない（停電で固定電話がもう使えない家・固定電話の無い家に回線の不通を差し込まない）
5. **講評の指摘の数を中身に合わせる**: 指示と形の縛りに 8 が残っていないか確かめ、機械で数えた中身（種類ごと）に合わせた数にする（0 件もあり得る）。種類の内訳も中身で変わる形に
6. **つながりにくい間の電話**: comms のつながりにくさ（不安定・規制）が、本人役の電話の形の連絡の数と着信に効くように。決めは再生で同じになる形（種と人と時刻から）。数字の目安は docs/DECISIONS.md に案として
7. **評価の台の誤検知**（tools/eval/drill/checks.ts）: 名前でない言葉を拾わないように（lib/pseudonym の門は変えない）
8. **テスト**（偽の client。本物の API は呼ばない）と、評価の台の偽の回（6 回ほど）で前と後の数を docs/progress/t139.md に
