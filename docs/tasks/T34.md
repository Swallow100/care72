# T34 ケアマネ向けアンケート（現場の声を動画と README に）

## 目的

協力してくれる事業所のケアマネ・職員に短いアンケートを取り、「誰が、どんな場面で、どれくらい困っているか」を現場の言葉と数字で示す（審査基準のインパクト）。結果は動画の経緯の場面と最後の数字、README の「現場の声」に使う。集計と要約に Claude を使い、その使い方も記録する（Claude の活用）。

## 読む物

docs/JUDGING.md のインパクトの段、docs/SPEC.md の「正直な見立て」「利用者と場面」「個人情報」、docs/video/PLAN.md（T33 ができていれば）、docs/DECISIONS.md の「11/3 02:3x 確定」。

## 作る物

- `docs/survey/QUESTIONS.md`: 7 問まで、5 分で答えられる形。案: (1) 担当の利用者のうち個別避難計画ができている人の割合（0・1〜3 割・4〜6 割・7 割以上）、(2) 計画 1 件を作るのにかかる時間（30 分・1 時間・半日・それ以上）、(3) 計画作りで一番大変な所（自由記述）、(4) 発災直後、最初に電話する人をどう決めるか（自由記述）、(5) 利用者の薬・機器の情報を、避難所の医療者にすぐ渡せるか（渡せる・一部・渡せない）、(6) 72 時間の訓練を年 1 回やるなら、どんな形なら続けられるか（自由記述）、(7) この道具で一番役に立ちそうな所と、使えないと思う所（自由記述）。答える人の属性は「ケアマネ／その他の職員」と「経験年数の幅」だけ。名前・事業所名・利用者のことは書かないと先頭に明記
- 取り方: 紙（A4 1 枚、印刷用の紙面を `docs/survey/` に HTML で）か Google フォーム（作者が作る。リンクはリポジトリに入れない）。回答は作者が回収し、名前や利用者の情報が無いことを確かめてから `docs/survey/answers.md`（匿名、項目ごと）に写す
- 集計と要約: `tools/survey/summarize.ts`（Claude の `askJson` で、自由記述を 3 つの型〔時間・情報の受け渡し・訓練〕に分け、動画に使う 1 文ずつの引用候補を出す。固有名詞があれば伏せる）。数は機械で数える。要約には AI の印、採るのは作者
- 動画と README への出し方: 数字は「N 人中 M 人」（母数が小さいことを隠さない）。引用は匿名で 1〜2 文。顔・声は出さない（本人が望めば声は可）

## 終わりの形

- 質問紙が印刷でき、答えの写し方と集計の手順が docs/survey/README.md にある
- 回答が 3 件以上集まれば、動画の最後の数字と README の「現場の声」に 1 段

## 触るファイル

docs/survey/、tools/survey/、docs/progress/t34.md

## 守ること

名前・事業所名・利用者のことを集めない・書かない。回答の原本はリポジトリに入れない（写しだけ）。動画に使う引用は本人の了承を得る。アンケートの文に「診断」「判定」を使わない。
