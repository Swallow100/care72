# T119 市町村の様式の Excel・Word をそのまま取り込む（頁の画像に描いて、読み取りと重ねる紙に渡す）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。書類の取り込みは T52・T83（黒塗りの画面）、T86 の進み（docs/progress/t86.md。頁の画像の上に値を重ねる紙）、T101（枠を動かさない）、T107（書類の AI の評価の台）を読む。

## 意図（なぜこの作業か）

市町村の個別避難計画の様式は、Excel（.xlsx・.xls）や Word（.docx・.doc）で配られていることが多い。評価のために集めた 15 市町村の様式のうち、半分以上が Excel か Word だった。

今の様式の取り込み（様式の読取 → 黒塗りの画面 → 頁の画像 → 対応表 → 元の様式の上に値を重ねる紙）は JPEG・PNG・PDF だけを受ける。ケアマネが市のサイトから落とした Excel・Word を受け取れず、いったん PDF にしてもらう手間がかかる。Excel・Word をそのまま取り込めるようにする。

重ねる紙は頁の画像の上に値を置くので、描いた頁の枠の位置と大きさが元の印刷の見た目に近いことが大事（T101 の「枠を動かさない」と同じ考え）。

## 先に決めること（問い）

1. 描く場所: Workers の上では LibreOffice などは動かない。ブラウザで描く（xlsx はシートの印刷範囲・列の幅・行の高さ・結合・罫線、docx は表と段落を読んで頁に描く）か、ほかの確かな道を調べて選ぶ
2. 複数のシートを持つブック（様式と記入例が同じブックにある物、白紙のシートが後ろにある物）で、どのシートを読むか。読む頁は 3 頁まで（T83 の上限）
3. 対応表の元の形（form_mappings.source_kind は 写真・PDF・手作成 の 3 つ）に Excel・Word をどう残すか

## 作る物

1. **Excel・Word を頁の画像に**: Word・Excel を受け取り、頁の画像（今の T86 の道と同じ形）にして、黒塗りの画面 → 読み取り → 重ねる紙に渡す。黒塗りの画面は迂回しない（記入例のシートには値が入っている）
   - 描いた頁が元の印刷の見た目（枠の位置・大きさ）に近いこと。近づけきれない所は限界として進みに書く
   - Excel・Word を選んだときだけ、ケアマネに「PDF に保存して取り込むと正確」を短い言葉で出す（常設の長い説明文は置かない）
2. **権利と古い形**: 使う部品の権利（ライセンス）を確かめ、足した物は THIRD_PARTY_NOTICES に書く。マクロは動かさない（中身を読むだけ）。.xls・.doc の古い形は、読めなければ断って PDF を勧める
3. **確かめ**: 評価のために集めた様式の束（リポジトリの外。読むだけ）の Excel・Word を描き、同じ市の PDF 版がある物は手元で見比べ、ずれを数で進みに書く（市の名前と数だけ）。原本・原本の写る絵はリポジトリに入れない。テストは架空の小さな xlsx・docx をテストの中で作って行う
4. **評価の台**: 書類の AI の評価の台（T107、tools/eval/forms）が Word・Excel も通せるように、台の入力の形に足す

## 触るファイル

lib に Excel・Word を読んで描く物（新しく）、lib/redact/browser.ts（頁にする所）、lib/forms/shrink-image.ts（形の判定）、lib/intake/read-form.ts（送る形の元の種類）、lib/forms/read-upload.ts・read-post.ts、components/forms/mapping/FormReadPanel.tsx・components/person/RedactSheet.tsx、lib/labels.ts、tools/eval/forms（T107 が入ったあと）、THIRD_PARTY_NOTICES.md、docs/progress/t119.md。

## 守ること

- Claude に渡すのは今と同じく黒塗りの画面を通した頁の画像だけ。Excel・Word の中の字を別の道で Claude に渡さない
- マクロ（vbaProject.bin など）は開かない・動かさない。外の参照（リンクした画像・外部のブック）は取りに行かない
- 原本の Excel・Word・PDF とその絵、原本の写る紙をリポジトリに入れない。進みには市の名前と数だけ
- 依存は MIT・Apache-2.0・OFL の物だけ
- 画面の言葉は 2〜4 字の漢語。常設の説明文を置かない
