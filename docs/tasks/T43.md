# T43 動画の制作（Opus、分岐。仮の声で 3 分を一度通す）

## 目的

T33 で作った絵コンテ・台本・編集の枠（video/、Remotion）を、今ある物だけで 3 分の動画に一度通す。決めたこと: 動画は機能と同時に進める、声は作者の声を録るがそれまで TTS の仮の声でよい、高校の話は使わない。録画は本物の画面だけ。無い物は仮の面（「撮影待ち R07」と書いた青の面）で埋め、何が無いかを一覧にして作者が撮れる状態にする。

## 読む物

docs/video/PLAN.md・SCRIPT.md・MATERIALS.md・SHOOTING.md・REFERENCES.md、docs/progress/t33.md（問いと決めた所）、video/README.md・src/・scripts/、docs/DECISIONS.md「動画」、docs/JUDGING.md、CLAUDE.md。

## 作る物

1. 台本の直し（docs/video/SCRIPT.md と PLAN.md の S3）: N04 の高校の話を消し、経緯は「医学部で学びながら、家族のケアマネの仕事を近くで見て気づいた」の 1 段と、出典のある数字（作成率、能登の関連死、輪島の手書きメモ）で組む。作者について文書（docs/SPEC.md の「立ち位置」）に無いことは言わない。時間割を組み直して 180 秒に収める（`video/scripts/check` が通る）
2. 仮の声: 30 文を Windows の読み上げ（System.Speech、ja-JP の声）で 1 文ずつ WAV に作る。鍵は要らない。ファイル名は N01.wav の形で video/assets/voice-tts/（.gitignore に入れる。生成物は commit しない。作り方の script は commit する）。Gemini TTS は本番の鍵が手元に無いので使わない
3. 本物の画面の録画（手元の dev で、ログインは捨てる値のパスワードを環境変数で渡す。Claude の鍵は手元に無いので、入れる欄・訓練・分類の画面は撮らない）: 担当一覧の平時（R01）、様式・計画書・本人の 1 枚・医療班の要約の紙面（R03〜R06 の紙面の分）、発災時の一覧（R10・R11・R13: 大雨の想定に切り替え、信号は手元の API か MCP で入れ、並び替わり・行の詳細・電話の記録を撮る）、本人のスマホ（R08 の平時と赤緑）、端末の画面のうち鍵の要らない物（R20 フックが wrangler を止める所、R23 MCP の check_leaks）。headless Chrome（puppeteer-core、`Page.screencast` か 1 秒 30 枚の連番）で 1280×720。撮れた物は MATERIALS.md の表に「撮れた」と書く。実名・ID・パスワード・ほかのプロジェクトが映っていないことを 1 本ずつ確かめる
4. 図（MATERIALS.md の図 8 つ）を video/src の部品で描く（アプリの枠の外に、図だと分かる形で）
5. 書き出し: `Care72Ja`（日本語だけ）を mp4 に（-14 LUFS）。video/out/ に置き、commit しない。長さ・各場面の秒・仮の面の数を docs/progress/t43.md に
6. 作者が撮る物の一覧（docs/progress/t43.md）: 本番（care72.app、本物の Claude）で撮る R02 入れる欄・R07 訓練 10 分版・R12 分類・着信の声、と自分の声の録り方（1 文ずつ、ファイル名、置き場、`video/scripts` で差し替える手順）。撮れたら差し替えるだけで完成する形に

## 終わりの形

- `video/out/care72-ja-draft.mp4`（3 分、仮の声、本物の録画と仮の面）が手元で再生できる
- `video/scripts/check` が通る。ルートの `npm test`・`npm run typecheck` は触らない（video は外してある）
- docs/progress/t43.md に、何を作ったか・録画の一覧（撮れた／撮影待ち）・作者がすること・問い

## 触るファイル

docs/video/、video/、docs/progress/t43.md、.gitignore（video/assets/voice-tts と video/out）

## 守ること

アプリのコード（app・components・lib）は触らない。録画は本物の画面だけ、編集で画面を描き直さない。測っていない数字を言わない。実在の人の名前・声・学校名を入れない。Remotion のライセンスは作者の判断待ち（今は使う。THIRD_PARTY_NOTICES.md の節のまま）。ネットに出る wrangler・本番のログインはしない。
