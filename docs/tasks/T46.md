# T46 地図の全画面と拡大（Opus、分岐）

## 目的

作者の指示（11/3 10:2x）: ハザードマップを全画面で見られ、拡大できるようにする。今の地図（T14）は動かさない固定の地図で、担当一覧の右の面の小さな枠だけ。

## 読む物

docs/tasks/T14.md、docs/progress/t14.md（地理院タイルとハザードマップポータルの条件と出典）、components/map/CaseMap.tsx、lib/map/geo.ts（タイルの計算）、lib/map/layers.ts、lib/map/side.ts（ピン）、lib/map/demo.ts、components/list/SidePane.tsx、app/drill/（訓練の地図があれば）、components/person/PersonView.tsx（本人のページに地図があるか）、THIRD_PARTY.md（地図の道具を使わない決まり。Leaflet などは入れない）、CLAUDE.md。

## 作る物

1. CaseMap に「全画面」（アイコンと文字）。押すと画面全体を覆う面（`<dialog>` か固定の層。Escape と「閉じる」で戻る。開いている間は後ろを送らない）。上に層の切替（洪水・土砂・津波）、出典、人数の印はそのまま
2. 全画面では拡大・縮小（＋・−のボタン、ホイール、ピンチ）と動かす（ドラッグ・指）。lib/map/geo.ts のタイルの計算をズームと中心を変えられる形に（今は fitView 固定）。地理院タイルのズームの範囲内で。ピンの名前の印はズームに合わせて重ならないように（近い物はまとめて数で）
3. 本人のページに本人の家と避難先の地図が無ければ、同じ部品で小さく足し、全画面にもできる（余裕があれば）
4. 「動かさない地図」の注（CaseMap・T14 の記録）を今の作りに直す
5. テスト: geo.ts のズームと中心の計算（タイルの番号と位置）、全画面の開閉とキーボード、ピンのまとめ

## 終わりの形

- 担当一覧の右の面の地図に「全画面」があり、押すと画面いっぱいに出て、拡大・縮小・動かすができ、Escape で戻る
- `npm test`・`npm run typecheck` が通る。docs/progress/t46.md に、何を変えたか・確かめた所（1280・375）・言葉の一覧・問い

## 触るファイル

components/map/、lib/map/、components/list/SidePane.tsx（ボタンの置き場だけ）、テスト、docs/progress/t46.md

## 守ること

地図の道具を入れない（タイルの計算は自前のまま）。出典の明示を消さない。タイルの要求を増やしすぎない（ズームごとに見える分だけ）。担当一覧の表・本人のページの中身・訓練の進み方は触らない。
