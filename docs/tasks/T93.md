# T93 本人役の深さ（通話の往復、訪問の様子と頼み事、手のあとの変化、細かい時刻の言い方）（Opus、分岐）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。T90〜T94 は 1 組（訓練の自由度）。**始めるのは T88（lib/pseudonym の漏れと persona.ts の町名）と T90 の準備の PR（persona-types.ts・WorldState の `asks`・`arrivals`・`supplies`・`advised`）が integrate/t11-t12 に入ってから**。T89 が lib/claude/models.ts の本人役の effort を medium にするので、models.ts は触らない。

## 意図（なぜこの作業か）

本人役（Haiku、lib/drill/persona.ts）は刻みごとに 1 回、「連絡するか・赤か緑か・言う事」を返すだけで、ケアマネの電話に出ても 1 文で終わる（personaCallReply）。訪問で着いても「到着」の 1 語で、本人の様子も頼み事も分からない。手を打ったあとの本人の様子が次の刻みで変わる筋（薬が届いた・民生委員が来た・避難所へ移った）も、本人役の入力に手の結果が無いので出ない。訓練で試したいのは「誰から順に連絡するか」に加えて「電話で何を聞き、何を頼まれ、次に何をするか」なので、電話を数回のやり取りに、訪問を様子と頼み事の報告に、手の結果を本人役の入力にする。

線はそのまま: 本人役が返すのは人がボタンを押すのと同じ物（赤か緑・4 問・いる所・言葉）で、色と順はルールの表。名前・住所・電話・病名・薬の量・医療の助言・「死亡」を言わない。ケアマネが打つ言葉が Claude に渡る口は仮名化の門を通す。

## 作る物

### 1. 本人役の入力の言葉（lib/drill/persona.ts の tickText）

- 時刻: `hour` が小数（T90 の連続の時計）になるので「発災から N 時間 M 分」（lib/drill/labels.ts の clockLabel）
- 呼ばれた理由（PersonaInput.reasons、T90）: 「この区切りで起きた事: 〇〇」の 1 行（table は書かない。incident は状況の文、action はケアマネの手の結果、clock は「持ちこたえる時間が半分を過ぎた／切れた」、round は「前の連絡から 6 時間」）
- ケアマネの手（actionWords）: 直前の 1 つでなく、`since` 以後の手を全部、結果の言葉つきで（「3 時間 5 分に本人に電話 → 出なかった」「4 時間に訪問看護に行ってもらうよう頼んだ → 向かってもらえる、5 時間ごろ着く」）。手の言い方は T91 の lib/drill/action-catalog.ts の `words` から引く（T91 が ACTION_WORDS の const を import に替えるので、その行はそのまま使う）
- T90 の準備の欄: 向かっている人（arrivals。「民生委員が 5 時間ごろ来る」「薬局の配達が 6 時間ごろ届く」）、届いた物（supplies）、119 を勧められた（advised）、頼み事（asks の未対応と済んだ物）。T92 の `extraWorldWords` の 1 行は残す
- 決まりに足す: 「8. ケアマネの手が届いたあとの最初の連絡は、その手の結果を受けた様子を言う（来た人がいる・物が届いた・移った）。頼んだ事が済んでいなければ、また頼んでよい」「9. 119 を勧められたら、かけるか・かけないかを言葉で言う（かけたかどうかは本人役が決める。救急が来た先の事は言わない）」
- 決まり 6・7（名前・住所・電話を言わない、診断・判定・重症・病名・薬の量・助言を言わない）はそのまま

### 2. 通話の往復（新しい lib/drill/dialogue.ts、lib/drill/talk.ts、app/api/drill/[id]/talk/route.ts）

- 電話の手（本人電話・連絡先電話・119勧奨・見守依頼）で相手が出たら、最初の言葉（今の personaCallReply）のあと、ケアマネが **3 往復まで**続けられる。1 往復は Haiku 1 回（用途 persona）、時計は 2 分進む
- ケアマネの言葉は 2 つの形: 決まった問い（`TALK_ASKS`、閉じた一覧 `where | injured | device_medicine | can_evacuate | contact_family | advise_119 | will_call_back`。画面は 2〜4 字「所在」「けが」「機器薬」「避難可否」「家族連絡」「119勧奨」「後で連絡」）か、自由の 1 文（60 字まで）。**自由の文は `pseudonymizeText` を通し、伏せきれなければ断る**（400「伏字不可」）。メモ（T59）は今までどおり渡さない
- 本人役の返事（CallSchema を広げる）: `speech`（1〜3 文）と `asks`（頼み事。AskKind の閉じた一覧から 0〜2 つ。無ければ空）。`asks` は world.asks に積む（at は通話の分）。「伝える様子」（tell）との食い違いの決まりは今のまま
- 保存: 往復は手の記録の `result.talk: TalkLine[]`（`{ who: "cm" | "them", text, ai, minute, ask?: TalkAsk }`）。drills.world の actions と drill_events の result の payload を更新する（新しい kind を足さないので **migration なし**）。読んだ刻み・手の数・world の写しで門（db.ts の actDrill と同じ）。db.ts は T90 が触るので、更新の文は **新しい lib/drill/talk.ts** に書く
- API: POST /api/drill/[id]/talk `{ step, actions, action: "a3", ask?: TalkAsk, text?: string }`。断り方は http.ts と同じ（401・403・400・404・409）。終わった訓練・返事の無い手・出なかった電話・4 往復目は 409
- 上限: 往復は counts.call に数える（T90 の 150 の上限）。1 日の上限も同じ

### 3. 訪問の様子と頼み事（persona.ts の新しい VISIT_SYSTEM・VisitSchema、hooks.ts の visit の口）

- ケアマネの訪問が着いた（status arrived）ときだけ、Haiku 1 回: `{ condition: 見て分かる事（30 字まで。体の具合の言い切りは禁じる語で捨てる）, location, asks: AskKind の 0〜3 つ, speech: 本人か家族の 1〜2 文 }`。訪問看護・民生委員の到着（arrivals）は本人役の次の連絡（T90 の理由 action）で言う
- 保存: `result.visit: { condition, asks, speech, ai }`。asks は world.asks に積む。聞いた安否（heard）は今のまま本人役の今の様子から（Claude は決めない）
- 呼び出しは lib/drill/actions.ts の訪問の到着の所に `hooks.visit` を足す（**T91 の取り込みのあと、5 行だけ**。T91 が actions.ts を持つ）

### 4. 画面

- 対応の欄の最新の結果（components/drill/ActionLog.tsx の LatestResult）に通話の往復: 相手の吹き出し（AI の印）と、ケアマネの側の問いのボタン 7 つと自由の 1 文の欄、「切る」。往復ごとに吹き出しが増える。3 往復で問いが消える。新しい部品 components/drill/TalkBox.tsx
- 履歴（ActionLog）と状況には往復を畳んで出す（「通話 3 往復」。開くと全文）
- 訪問の結果: 様子の 1 行（AI の印）と頼み事の印（AskKind の 2〜4 字「薬」「水」「食事」「電源」「移送」「家族」「電池」「便所」「保温」）。未対応の頼み事は左の表の行の詳細（DrillRowDetail）にも印で出す（色の印にしない。灰の文字）
- 声（Gemini TTS）は往復に付けない（文字だけ。費用と上限のため）
- 言葉は lib/drill/dialogue.ts に `TALK_LABELS`・`ASK_LABELS` として置く（labels.ts は触らない）

## 守ること

- 色と連絡順はルールの表（lib/triage）だけ。本人役が返すのは赤か緑・4 問・いる所・言葉・頼み事（閉じた一覧）だけで、聞いた安否（heard）は今までどおりコードが本人役の今の様子から決める。頼み事の効き目は T91 の手（ask_done）で、色には届かない
- 本人役の決まり 6・7 は変えない。訪問の様子の言葉に病名・重さの言い切りを入れない（禁じる語で捨てる）。「死亡」の語を使わない。119 は勧めるまで（本人役が「かけた」と言っても世界は救急を作らない）
- ケアマネの自由の文は仮名化の門（lib/pseudonym → askJson）を通し、伏せきれなければ断る。askJson の外に Claude を呼ぶ道を作らない。架空の人の印（「AI が演じる架空の人」）はそのまま
- 仮想モードの結末はデモ事業所だけ。本物の API は呼ばない（偽の client）。鍵を探さない。履歴を書き換えない。端末は増やさない（API の route は足してよい）。他のプロジェクトの名前を書かない。文書に作者の発言の引用・やり取り・人の名前を書かない
- 画面の言葉: 2〜4 字の漢語。「を・が・の」でつなぐ文にしない。常設の説明文を置かない。使わない語: 診断・判定・重症・緊急度・札
- 見た目の避ける型: ピル型、番号ラベル、等幅のラベル、グラデーション・光る影、字間、絵文字、`<details>` の黒い▼、真っ黒の塗りボタン、テーマ色の薄い下地。吹き出しは面の中の色（panel2）で枠線なし。押したときは灰色だけ。新しい押せる物には focus-visible:outline-solid。375px で押せること
- 並列の衝突: T90・T91・T92・T94 と T88・T89 が同時に動く。persona.ts は T88 のあと、actions.ts の 5 行は T91 のあと。PR の前に origin/integrate/t11-t12 を取り込んで衝突を解く（両方を活かす）。migration は要らない
