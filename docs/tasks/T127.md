# T127 訓練の着信に通話の中で返す・鳴らさなかった連絡を不在着信に（経路の印）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。訓練の着信（docs/tasks/T21.md）、採点と訓練記録（T22）、経過の 3 つのタブ（T105）、時間を使う手（T110）と、その進み（docs/progress/t21.md・t105.md・t110.md）、外へ掛けた電話の往復（T93。lib/drill/talk.ts・dialogue.ts・components/drill/TalkBox.tsx）を読む。

## 意図（なぜこの作業か）

本番の地震想定を通して回したところ、次の 2 つで訓練の着信が実際の電話と離れていた。

- **着信に返せない**: 着信に応答しても、相手の言う事を聞くだけで、こちらから問い返せない（通話中は終話しかない）。外へ掛けた電話（T93）には往復があるのに、掛かってきた電話には無い。実際のケアマネは、掛かってきた電話でこそ安否・けが・薬・移動・避難先を聞き、待機などを伝える
- **鳴らなかった連絡が分からない**: 1 刻みの着信は 2 件まで（lib/drill/calls.ts の CALLS_PER_TICK）で、3 件目からは着信の画面を出さずに経過に入るだけ。家族からの電話の形の連絡が、画面に出ないまま経過に並ぶことがあった。本人の安否ボタンの連絡も、どう届いたか（電話か・ボタンか）が経過から分からない

経過を見落としにくくする並びと新着の帯は T128 に分ける（この作業では作らない。経過の置き場所と帯には触らない）。

## 作る物

### 1. 着信の通話の中で返す

- 着信の画面の通話中に、短い問い・指示の候補（安否・けが・機器と薬・移動・避難先・待機・119 の勧め。2〜4 字の漢語）と、自由に打つ欄を出す
- 外へ掛けた電話の往復（T93）の仕組みを使い回す: 本人役（Haiku）の口・本人役の決まり（名前・住所・電話・病名・薬の量・医療の助言・「死亡」を言わない、想定に合う事だけ）・自由の文の仮名化の門（伏せきれなければ断る）・返事の頼み事を世界に積む所。本人役には「相手から掛けてきた電話の続き」と分かるように渡す
- 返すごとにケアマネの時計を進める（今の通話の往復と同じ 1 往復 2 分。手の分〔T110〕の使用に入る）。1 回の通話で返せるのは 3 回まで
- AI の数え方は外へ掛けた電話の往復と同じ（1 日の上限 AI_DAILY_LIMIT は askJson の数え、1 訓練の上限は counts.call）。上限・鍵なし・失敗は固定の言葉（AI の印なし）
- 返した事と答えを残す: 経過の「対応」（着信の応答と往復）と「把握」（相手の言葉）、訓練記録の紙面（着信の行）、採点が読む記録（着信の記録 CallRecord と往復の数）。講評に渡すのは往復の数だけ（言葉は渡さない）
- 声は今の着信と同じ: 作れれば相手の返事を声で、無ければ文字
- 色と連絡順は動かさない（着信の往復から聞いた安否を足さない。着信の安否は元から表に入っている）

### 2. 鳴らさなかった連絡を不在着信に・経路の印

- 鳴らすのは今までどおり 1 刻み 2 件まで。残りの電話の形の連絡は「不在着信」として対応の欄の上に出し、折返（連絡先電話の手。その時の電話の可否・決まりの表に従う）につなぐ。折返したら一覧から外す
- 経過の把握の各行に、どの経路で届いたかを短い印で（着信・不在・ボタン・発信・訪問・公表）。経過の並び・置き場所は変えない
- 連絡がどの経路で届くか（通信の段と本人のスマホの有無で決め、通話不可の間は着信にしない）は同時に動く T125 が世界の状態の側で持つ。この作業は今の出どころと電話の形（isPhoneTurn）から経路を出す関数を 1 か所に置き、T125 の経路が入ったらその関数だけをそろえる

### 3. テスト

- 応答 → 往復 → 保存の形（着信の記録・世界の頼み事と時計）、上限、応答の前・切った後・刻みが違うと断る、伏せきれない文、偽の client で ai_calls と counts.call、作り直した状態が保存と同じ、着信の記録の往復と採点の数
- 不在の選び方と経路の印、経過の行、不在着信の一覧と折返の解消
- 画面は 1920・1536・1280 を主に、375 は崩れないかだけ。ライトとダーク
