# T26 デモ事業所の種と「最初に戻す」、毎日 4 時に戻す

## 目的

審査員が開くデモ事業所に、架空の 10 人・赤が 1 人（録音つき）・終わった訓練 1 回が種として入っている。毎日 4 時に種へ戻し、「最初に戻す」も置く。Claude の呼び出しは 1 日の上限で守り、超えた訓練は終わった記録の再生になる。動画もデモ事業所で撮る。

## 読む物

docs/SPEC.md の「作り」（審査員用の公開デモの段）。seed/people.ts、T10（信号と録音）、T17（訓練記録）、T00（上限）。

## 作る物

- 種の拡張: デモ事業所に、災害モード（大雨、停電 3 時間）の状態、山田の赤の信号と録音（自分の声か TTS で作った 30 秒の音を `seed/recordings/` に置く。権利が自分にある物だけ）、終わった訓練 1 回（大雨、手の履歴と採点つき。T17〜T22 の形で固定の JSON）
- `npm run db:reset` がこの全部を入れる（何度流しても同じ）
- 「最初に戻す」: 審査員・管理者の画面のボタン。デモ事業所だけ。押すと種に戻る（協力事業所には効かない）
- 毎日 4 時（JST）に戻す: Workers の cron（wrangler.jsonc の triggers）とハンドラ。手元では `--local` で動きを確かめる
- 上限を超えたとき: 訓練の「始める」が「再生」に変わり、終わった記録を刻みごとに見られる。画面に「本日の上限」と出す
- デモの入口の案内（README の先頭の 5 行の下書き。ID とパスワードは書かない）
- テスト: 種の冪等、戻すの範囲（協力事業所に効かない）、上限での再生への切替

## 終わりの形

- 審査員で入ると、担当一覧が災害モードで山田が赤・録音が再生でき、訓練の一覧に終わった 1 回があり、「最初に戻す」で元に戻る

## 触るファイル

seed/、app/api/admin/reset/、wrangler.jsonc（triggers）、app/（cron の入口）、components/（戻すボタン）、README.md（入口の案内の下書き）、docs/PROGRESS.md

## 守ること

協力事業所の記録を消さない。録音の種は自分の声か TTS だけ。審査員の ID とパスワードを書かない。
