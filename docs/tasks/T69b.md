このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md`（何を作っているか・越えない線・地図・進め方）→ `CLAUDE.md` → `docs/tasks/README.md` を読む。元は docs/progress/real-use-audit-20261104.md の 6 と順の 12、docs/progress/screens-20261104.md の「11/4 01:1x の追記」と問い 6・7、docs/DECISIONS.md「本人・家族のスマホと聞き取り」（高齢者の選択の画面）。入口（署名つきのリンク）は T69a で、ここでは触らない。この文書は、それ以外に何も知らなくても作業できるように書いてある。

## 意図（なぜこの作業か）

直す 3 つ:

- 高齢者の選択の画面に、選択肢の枠と、必要に応じて危なそうな選択と大丈夫そうな選択の色分けを付ける。今は選択肢が全部同じ白い面で枠も色も無い（components/phone/PhoneView.tsx の Choice・QuestionBody）。塗るのは最初の緑と赤だけ（CLAUDE.md「本人・家族の画面の赤緑のボタンだけは面で塗る」）。
- 避難所やほかの所を押したときに、場所を取る。場所の問い（lib/signals/questions.ts の place）は 避難所・車・ほかの ところ・わからない を選ぶだけ。
- 危なそうなら話してもらい、それを録音してまとめる。今は問いが全部終わってから定型文を流して 30 秒録り、Claude は分類と本人の言葉の写しだけで要約しない（lib/classify/prompt.ts の 7、CLAUDE.md）。まとめを出すのは今の決まりと違うので、決まりを変える形（この文書の案を DECISIONS に）。

線（この作業で越えない物）: **色分けは見た目の印で、表の入力ではない。** ルールの表（lib/triage）が読む本人の答えは けが（injured）と動けるか（canMove）だけ（lib/triage/index.ts:434-435）で、ここで付ける色はどの答えも表に渡さず、連絡順を変えない。**まとめは色と連絡順に使わない。元の言葉と必ず並べる。重さ・病名・医療の言葉を足さない（言った事の言い換えだけ）。AI の印。人が直せる。仮名化の門を通す。** 119 の 1 行は触らない。位置（緯度経度）と避難先の名前は Claude に渡さない。
