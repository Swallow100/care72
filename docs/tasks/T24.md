# T24 本人のページの同意の範囲と経過の書き足し

## 目的

医療班・行政が本人のページをケアマネと同じ形で開き、見える区分は同意の範囲（医療、避難、人の一部）。住所は既定で見せない。経過に定型と自由文を書き足せ、誰が・いつが自動で付く。医療班には災害診療記録 2018 の順の要約（T07）があり、紙にも印刷できる。

## 読む物

docs/SPEC.md の「画面 6」「画面 2」（経過）、「個人情報」（同意は機能にする。同意のない範囲は出力から落とす）。T02、T07、T23。docs/DECISIONS.md 7（同意 4 つ）。

## 作る物

- `lib/consent/scope.ts`: 役と同意から見える区分を決める 1 か所（ケアマネ: 全部。医療班・行政: 医療班への提供に同意があれば 医療・避難・人の一部〔緊急連絡先と支援者の役割名〕。住所は本人の同意の範囲にあるときだけ。支援者: 支援者への提供に同意があれば 避難・人）。画面と API の両方がこれを通る
- 本人のページ（T02）を役で出し分ける。見えない区分は出さない（「非表示」とも書かない）
- 経過の書き足し: 定型（安否確認した、診た、薬を渡した、搬送した、避難所に着いた）と自由文。誰が・いつ・どの役。医療班の書き足しはケアマネにも見える
- 医療班の画面から要約（T07）を開いて印刷
- テスト: 役 × 同意の組で見える区分、9 渡辺（医療班への提供に同意なし）は医療班に医療が出ない、7 加藤（支援者への提供に同意なし）は支援者に人が出ない、経過の書き足しに誰が・いつが付く

## 終わりの形

- 医療班で山田のページを開くと医療・避難・人の一部だけで、住所が無い。「診た」を押して自由文を足すと、ケアマネの経過にも「医療班 診た 11:40」

## 触るファイル

lib/consent/、app/people/[id]/（役の出し分け）、components/person/Timeline、app/api/timeline/、docs/PROGRESS.md

## 守ること

同意の判定を画面側だけでしない（API も同じ scope を通す）。自由文に Claude を掛けない（医療班の記録はそのまま）。
