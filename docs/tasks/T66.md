3. **右の面の地図（components/map/CaseMap.tsx・lib/map/layers.ts・lib/map/demo.ts）**:
   - 見やすさ: 雨雲の斜線とハザードの層が淡色地図の上で弱い。下の地図を少し薄くするか、重ねる色を強くする。気象庁の色の段は使わない決まりのまま、斜線の濃さ・太さを上げる。ライトとダークの両方で、ピンの印が雨雲に埋もれないこと
