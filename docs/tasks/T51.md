1. **確認・お知らせの窓**（`lib/ui/dialog.ts`・`components/ui/DialogHost.tsx`）

   - 焦点: danger は取消に、ほかは決める方に（Enter だけで消えない）。Escape と外側（暗い所）を押すと取消。Tab は窓の中だけを回る（`<dialog>` の showModal）。閉じたら開く前に焦点のあった物へ戻す。題を窓の名前にする（aria-labelledby）。

2. **押したときの灰色**（`lib/ui/head-scripts.ts` の先頭の script。`app/layout.tsx` の `<head>` に入れる）
   - ねらい: 指を置いた瞬間に灰色、離したら少し残ってふわっと消える。iPhone の `:active` は置いた瞬間に出ず、短く叩くと離した後に一瞬しか出ないので、script で補う。CSS は globals.css の今の物をそのまま使う: `[data-press][data-pressing="on"]` で灰色（塗りのボタンは `[data-press="overlay"]` で上に重ねる）、`"out"` で 0.32 秒かけて元の地へ。印の名前は変えない。
   - script は ES5、import なし、部品が描かれる前に動く。文字のまま `<script>` に入れる。
   - 押す物: button・a[href]・[role=button]・[role=tab]・[role=option]・summary・label・[data-press]。disabled・aria-disabled=true の物と、[data-no-press] の中（連打する面など）は付けない。`data-press-host="<選択子>"` を持つ物は、その祖先（行全体など）に印を付ける。
   - 主ボタン（左・指）だけ。置いた瞬間に `on`。離したら、置いてから 120ms に満たなければ 120ms まで待って `out`、360ms 後に印を外す。
   - すぐ消す: pointercancel、スクロールが始まった、窓の blur。別の物を押したら前の印を外す。同時に印を持つのは 1 つ。
   - 印を付けるだけで、押した回（click）を邪魔しない（preventDefault しない、passive）。壊れた選択子でも落ちない。
   - 広げる所: **指が 8px 以上動いたら消す**（iPhone では scroll より先に動きが来るので、送り始めの灰色が残らない）。
