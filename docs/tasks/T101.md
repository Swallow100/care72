# T101 書類の枠の大きさを元の様式のままに

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。

## 意図（なぜこの作業か）

元の様式のある紙（松山市の計画書・医療要約〔災害診療記録2018〕・様式 9）は、T85 で書体・字の大きさ・太さ・余白・頁数を元の様式に合わせた。けれど欄の並べ方と枠の大きさ（罫線の位置・欄の幅と高さ）はケア72 の並べ方のまま（docs/progress/t85.md の未確認「原本の表の格子は真似ていない」）。さらに頁に収めるために、ケア72 が枠を変えた所がある（同「頁に収めるために詰めた所」）:

- 計画書: 本人・代理人の署名の空き 10mm → 6mm、地域の支援者の欄の名前の列 20 → 25mm
- 医療要約: 段の間 2 → 1mm、医師が書く欄の空き 6 → 4mm
- 様式 9: 列幅を 261mm に配り直した（緊急連絡先 38.5mm・医療と介護 21mm・避難 20mm ほか、平時に空の列を詰めた）

元の様式は市町村・国が決めた枠で、ケアマネや受け取る側は枠の位置で欄を探す。枠の大きさは元の様式のまま変えない。値が収まらないときは、枠でなく字の側で受ける（小さくする → 別紙）。

## 先に決めること（問い）

紙面を元の枠で描く道は 2 つある。

- (a) 原本の寸法で HTML の紙面を組み直す（罫線の位置・欄の幅と高さを mm で固定する。今の components/forms/MatsuyamaSheet.tsx・MedicalSummarySheet.tsx・Form9Paper.tsx を直す）。線が細く刷れ、原本を配信に入れない
- (b) T86 の「元の様式の上に値を置く紙」（components/forms/OverlaySheet.tsx）を同梱の 3 様式にも使う（原本の頁の画像を下に敷き、欄の矩形に値を置く。字の収め方と別紙は T86 のまま）。枠は原本そのものになる。原本の頁の画像を配信に入れてよいか（出典の利用の条件）を先に確かめる。画像は 2000px ほどで、刷ると線がわずかに甘い

答えが来るまでは、どちらでも要る 1（原本の寸法を取る）だけ進める。

## 作る物

1. **原本の枠の寸法**: 原本から罫線の位置・欄の幅と高さを mm で取る。松山市の PDF と災害診療記録2018 の PDF は pdf.js の線（constructPath）の位置、様式 9 の Excel は列幅・行の高さ・印刷の倍率（T85 で読んだ scale=73）。値は lib/forms の表に、出典（catalog のリンク）と取り方を添えて置く（lib/forms/form-audit.ts と同じく人が原本から起こした値）。原本の PDF・Excel・抜き出した字はリポジトリに入れない（T85 と同じ）
2. **紙面を原本の枠で描く**（問いの答えの道で）。T85 で詰めた所（上の 3 つ）は原本の寸法に戻す
3. **値が収まらないとき**: 枠は動かさない。字を小さくする（T86 の fitText と同じ 10.5pt → 6pt）。それでも収まらなければ欄に「別紙」と書き、最後に別紙の頁（欄の名前と値）。頁数は原本どおり、別紙があればその分だけ足す。画面の上の帯に別紙の数と欄の名前（紙には刷らない）
4. **テスト**: 印刷の頁で、罫線の位置と欄の大きさが原本の値の ±0.3mm（lib/forms/print-pages.test.ts と同じく headless Chrome の DOM で測る）。種の 10 人で枠が動かない（人によって欄の高さが変わらない）。収まらない値が別紙に行き、値を落とさない。`npm test`・`npm run typecheck`
5. **確かめ**: 手元の next dev で 10 人の計画書・医療要約と様式 9 を印刷（PDF に保存）し、原本の頁の絵と重ねて罫線がずれないこと。写しを docs/progress/t101/ に（原本の絵はリポジトリに入れない。重ねた絵も原本が写るので入れない。ずれの数だけ書く）

## 触るファイル

components/forms/MatsuyamaSheet.tsx・MedicalSummarySheet.tsx・Form9Paper.tsx と CSS（paper.css・medical-paper.css・form9-paper.css）、lib/forms（寸法の表・収め方）、lib/forms/print-pages.test.ts、docs/progress/t101.md。(b) なら components/forms/OverlaySheet.tsx と lib/forms/overlay-sheet.ts も。

## 守ること

T85 の書体・字の大きさ・太さは変えない。頁に収めるために枠を詰めない。紙に「未確認」を刷らない決まり（T86）はそのまま。本人の 1 枚・QR の紙・訓練の記録は元の様式が無いので対象の外。
