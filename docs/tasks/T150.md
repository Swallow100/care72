# T150 問いの選択に補足の文字、本人のページの上の「医療」と「時計」の重なり、書類の段の畳み

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。lib/intake/ask.ts（次の問い、QuestionAnswer の choice・night）・lib/intake/answer.ts（答えを変更に）・lib/intake/fields.ts（欄の表と書き足しの欄）・components/person/IntakeQuestion.tsx（問いの部品。本人のページの AI 入力と、書類の紙から出す質問 components/forms/PaperFill.tsx の両方が使う）、lib/person.ts（PersonHead・markItems・headClocks・documentBlocks）・components/person/PersonHead.tsx・components/person/PersonView.tsx の書類の行、lib/list/detail.ts・lib/list/full.ts・components/list（担当一覧の行の詳細・右の面）・components/drill/DrillRowDetail.tsx、lib/ledger-words.ts（T132 の時計の言葉）を読んでから始める。

## 意図（なぜこの作業か）

1. 次の問いが選択だけの時（はい／いいえ、介護度、歩行の 問題なし・一部・困難、手段など）、選んだうえで「その他」の中身や補足（「一部（杖で家の中は歩ける）」）を書けない。問いの答えの例にもこの形があるのに、書く所が無い
2. 担当一覧の右の面（行を押すと開く本人のページ）の上の段で、「医療」の欄に「呼吸器 3h」「吸引 4h」の印、その下の「時計」の欄に「人工呼吸器 内蔵電池 停電から 3 時間」「吸引 内蔵電池 停電から 4 時間」と、同じ中身が 2 回出る（右の面は幅が狭く、上の段の欄が縦に積まれる）。1 回にまとめ、空いた所に手を打つのに要る物を出す
3. 本人のページの「書類」の段に、書類ごとの行と、何の書類かの長い説明が全部並ぶ。いつも要る物だけを出し、ほかは開いたら見える形にする

## 作る物

1. **問いの選択に補足の文字**（本人のページの AI 入力の問いと、紙から出す質問の両方。同じ部品）
   - 選択の問い（1 つ選ぶ・いくつでも）と夜間支援の問い（連絡先を選ぶ）に、補足の文字の欄を 1 つ足す
   - 選んだ値と打った文は両方台帳に入る。補足は、その欄に書き足しの欄がある物（手段 → 手段補記、支援内容 → 支援補記、世帯 → 世帯補記）はそこへ、無い物は特記（ledger.notes）へ欄の名前を頭に付けて（「歩行: 杖で家の中は歩ける」）。書き足しの欄がもう埋まっていれば特記へ（上書きしない）
   - 1 つ選ぶ問いは今どおり押すとすぐ保存（そのとき補足の欄に文があれば一緒に）。文だけでは保存しない
   - 台帳の型・保存の形（IntakeChange）・migration は変えない（今ある field と note の変更だけで作る）。補足は Claude を通らない（手の入力）
   - 問いの文は今の決まりどおり定型（Claude に作らせない）
2. **本人のページの上の「医療」と「時計」**
   - 上の段の「医療」の欄に 1 回だけ: 印（「呼吸器 3h」。担当一覧の列と同じ形と色）を並べ、印だけでは分からない物（同じ区分に時計が 2 つ以上・値が未確認・災害モードでまだ走っていない時計・印の区分に入らない時計）だけを小さく添える。時計の 1 行の言葉は lib/ledger-words.ts の clockText
   - 空いた欄に「避難先」（避難先 1・2 と手段）。見る人の範囲（避難の区分）の外なら出さない
   - 同じ型の重なりを担当一覧・訓練の行の詳細でも探し、あれば直す（行の詳細の「残り時間」と、その下の「全部」の医療の面の「時計」）
   - 本人のページの面の中（医療の面の機器・薬の行と「時計」の段）は T143 が直す。ここでは触らない。言い方は T143 にそろえる
3. **書類の段の畳み**
   - 最初に出すのは計画書・本人の 1 枚・医療要約（見る人の範囲にある物）。ほかの書類と、書類ごとの説明の 1 行は「他 N 件」で開いたら見える
   - 本人・家族のスマホ入口は T149 が書類の段の外へ移すので、ここでは触らない
4. **確かめ**: テスト（補足の保存先・特記の頭・選択と補足の両方・文だけは保存しない・上の段の医療の欄・避難先・書類の畳み）、PC（1920・1280）とライト・ダークの絵（人は種の架空の 10 人）を docs/progress/t150/ に
