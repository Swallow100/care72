# T106 避難経路の地図を紙の欄に、一括印刷も原本の枠の紙に（T101・T102 の残り）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。T101 と T102 を取り込んだあとの物。docs/tasks/T101.md・docs/progress/t101.md と docs/tasks/T102.md・docs/progress/t102.md も読む。

## 意図（なぜこの作業か）

T101 は、計画書（松山市）の 2 頁の避難経路の欄に、地図の画像を置く受け口を作った（lib/forms/frame-build.ts の ROUTE_MAP_SLOT・ROUTE_MAP_BOX_MM、components/forms/MatsuyamaSheet.tsx の route-map）。T102 は、台帳の経路地図から地図の SVG を作る lib/map/route-image.ts の routeMapSvg を作った。けれど 2 つはまだつながっていない（app/people/[id]/forms/matsuyama/page.tsx の routeMap は null）。

routeMapSvg の SVG は地理院タイルを外の `<image href>` で読む。`<img src="data:image/svg+xml…">` に入れると、画像として読んだ SVG は中のタイルを読まないので、背景の地図が出ない。

また T101 の記録の未確認に「一括印刷（/forms/batch）は前からの紙面のまま」とある。原本を取り込んだ事業所で、1 人ずつの紙は原本の枠なのに一括で刷ると前からの紙面になる。

## 作る物

1. **避難経路の地図を紙の欄に**: 台帳の経路地図（Ledger.evacuation.routeMap）を routeMapSvg で SVG にし、計画書の 2 頁の避難経路の欄に置く
   - 背景の地図（地理院タイル）が画面と印刷の両方で出る形にする（例えば SVG を欄の中にそのまま置く、またはサーバーでタイルを取って埋め込む）。CSP（lib/security/headers.ts）と印刷で確かめる
   - 原本に重ねる紙（components/forms/OverlaySheet.tsx）と、原本を取り込んでいない時の紙（components/forms/MatsuyamaSheet.tsx）の両方
   - 台帳に経路地図が無い人（と家の位置が無い人）は欄を空ける（文字の経路だけ）
   - 出典（地理院タイルと openrouteservice）の表記は T102 の決めのとおり欄の中
   - ?print=1 の自動の印刷は、地図のタイルを読み終えてから窓を出す（lib/forms/print.ts の autoPrint は今 `<img>` だけを待つ）
2. **一括印刷も原本の枠の紙に**: 原本を取り込んだ事業所では、一括印刷（app/forms/batch/page.tsx）の計画書（松山市の様式）と医療要約（災害診療記録2018）も原本に重ねる紙で刷る。未記入の色付けの切替（components/forms/FillToggle.tsx、?fill=1）も 1 人ずつの紙と同じに。取り込んでいなければ今のまま。一括の計画書にも人ごとの経路地図を置く
3. **テスト**: 地図の欄に SVG が入る（箱の大きさ、文があるときは欄の上を文に）、タイルの参照が刷れる形（`<img>` の data: でない）、経路の無い人は空、一括印刷が原本の紙を使う（原本の有無・色付け）、自動の印刷が地図のタイルを待つ。375・1280、ライトとダーク、印刷（PDF に保存）で地図が欄の枠に収まること。前からの紙面は地図を入れても頁数が変わらないこと

## 触るファイル

lib/forms（frame-sheet.ts・frame-build.ts・overlay-sheet.ts・print.ts、一括の紙の組み方）、components/forms（OverlaySheet.tsx・MatsuyamaSheet.tsx・PaperBatch.tsx と CSS）、app/people/[id]/forms/matsuyama/page.tsx、app/forms/batch/page.tsx、docs/progress/t106.md。lib/map/route-image.ts は読むだけ（足りなければ小さく足す）。

## 守ること

- 枠は 1 本も動かさない（T101）。地図は欄の中に収め、欄の大きさを変えない
- 原本の頁の絵、原本が写る紙の絵はリポジトリに入れない（帯や画面、原本の写らない前からの紙面だけ）
- 地図の色は T102 のまま（操作の色 1 色。状態の 4 色は使わない）
- 外へ送る物を増やさない（経路を引き直すのはケアマネが押したときだけ。紙を開くたびに経路のサービスへ要求しない）。本物の openrouteservice・Claude、本番の D1 には触らない
