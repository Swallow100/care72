# T169 地図の避難所・避難先、名前の読みやすさ、右の面の順、飛んだ先の案内

意図: 審査員が PC で担当一覧の地図を強く拡大しても読め、見直しと未確認から「何をどこへ入れるか」まで迷わず着く。全部の人・全部の未確認の欄に効く形で直す。

## 直す所

1. 地図に避難所・避難先。強く拡大したときだけ、2 種類を分けて出す: (a) 担当の人の計画の避難先（台帳の値。座標があるものだけ。無ければ出さず数を出す）、(b) 地図の避難所（公的なデータ。使えるなら画面で読み込む。リポジトリに入れない）。データを作らない・位置を推し量らない。人のピンと印の形と文字で見分ける
2. 強く拡大したときの人の名前を読めるように。全部のズームで、タイルと層の上でも。赤は「至急」の意味なので平時の名前には使わない
3. 右の面の順: 避難計画 → 地図 → 見直しと未確認をまとめた 1 つの面（1 人 1 行、何を入れるかが読める）。発災時は地図が先のまま
4. 飛んだ先の案内: 見直し・未確認の行と本人のページの未確認の印から飛んだら、対象の欄を紫（--mark-target）で示す。見るだけの画面でも編集でも紫のまま、最初の対象まで送る。保存したら消える。欄の名前から本人のページの欄への対応は 1 か所の表にし、全部の未確認の欄で飛べることをテストで確かめる
5. 直した所を tools/eval/guards.ts の守りか台の check に足す

## 触らない所

lib/drill（T167）、lib/forms（T168）、lib/triage。色と連絡順はルールの表だけ。
