# T137b 声の聞き取りの会話の続き（カードの面・同じ声・自動で送る・聞き続ける・1 段深く聞く）（Opus、分岐）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` → `docs/tasks/T137.md` を読む。T137（声の聞き取りの会話、PR #48）が integrate/t11-t12 に入って配信されたあとの物。

## 意図（なぜこの作業か）

配信した本人のスマホの発災時の画面を触って、次の事が見つかった。

1. 「けがは ありますか」などの問いのカードで、色がカードの端の細い線だけに付いている。高齢の本人には何の色か分かりにくい
2. 最初の「大丈夫ですか」は Gemini TTS の作り置きの声なのに、そのあとの問いが端末の読み上げ（機械の声）になる。声が途中で替わる
3. 会話の画面に「送る」のボタンがある。答えは声でもボタンでも自動で送るので要らない
4. AI が考えている間・話している間は聞いていないので、その間に本人が言った言葉を逃す
5. 問いが浅い。本人が状況を説明できないとき、今の問いだけでは詳しく分からない

## 作る物

1. 問いのカード: 端の色の線をやめ、印のある答え（はい・いいえの側）の面そのものを大きくはっきり塗る（緑・赤の面は今の画面の部品の決まりに合わせる）。印の無い答え（わからない など）は今の灰の枠。CLAUDE.md の避ける型と、端だけの色の線は使わない
2. 声: 決まった問い・決まった文は全部 Gemini TTS で作り置き（R2）して、最初と同じ声で流す。AI の 1 文も Gemini TTS で作る（待ちが長いときは、先に作り置きの短い相づちを流す）。端末の読み上げは作れなかった時だけ
3. 「送る」のボタンを外す。答え（声・ボタン）は自動で送る
4. 聞き続ける: AI が考えている間・話している間も聞くのを止めず、その間に聞こえた言葉も次の 1 文を決める材料に入れる。話している間に本人が話し始めたら AI の声を止めて聞く。録音は会話の全部を 1 本に
5. 1 段深く聞く: 決まった範囲（今いる所・けが・動けるか・そばの人・機器や電気・薬・水や火・連絡してほしい人）の中で、答えに合わせて 1 段深く聞く（けが ある → どこか・血が出ているか・動かせるか、動けない → 何が原因か・誰か呼べるか、機器 → 電池の残り・予備）。はい・いいえで答えられる形を中心に、言葉の出にくい人でも進むように。深く聞く問いも決まった言い方の表に足し（AI は選んで言い換えるだけ）、門で確かめる。医療の助言・診断は今どおりしない
6. テスト（偽の client・偽の TTS）と、狭い幅（375）の絵
