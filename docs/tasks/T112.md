# T112 避難経路の直し（避難先を一覧から選ぶ・家と避難先の印・歩く速さ・手段を選ぶ欄）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。T102・T106 のあとの物。docs/tasks/T102.md・docs/progress/t102.md も読む。

## 意図（なぜこの作業か）

新しい事業所で 1 人を登録し、避難の面の経路地図を初めて作ると:

- 避難先は地図のどこにでも置ける。学校の印から少しずれた所に置くと、家のピン（学校の印のすぐ横）と避難先が逆に見えた。避難の編集の「避難先1」は文字だけで、位置は経路地図の中で置く
- 家は ●、避難先は ■ と「避難先1」の字だけで、小さな地図・刷った紙では見分けにくい
- 徒歩の経路は「822 m 約 10 分」。openrouteservice の時間は大人の歩く速さで、台帳の歩行が「一部」の 85 歳の人の見込みとしては短い
- 台帳の「手段」は自由に書く文字で、経路地図は文字に「車」があれば車、ほかは徒歩で引く（lib/map/route.ts の modeOf）。「家族の車」と書いたので車になったが、書いた人にはそれが分からない
- 経路地図の窓（components/map/RouteMap.tsx）で React の key の警告（一覧の子に key が無い。開発の画面の「1 Issue」）

## 先に決めること（問い）

1. 避難先の選び方:
   - (a) 国土地理院の「指定緊急避難場所データ」（オープンデータ）から事業所の市の中の候補を地図に出し、押すと名前と位置が避難先 1・2 に入る。手で置く道も残す（推し）。使ってよい条件・出典の表記・更新の頻度を作業者が確かめ、データはリポジトリに入れてよい形かも確かめる
   - (b) 手で置くまま、印と字だけ直す
2. 徒歩の見込み時間:
   - (a) 距離だけ出して時間は出さない
   - (b) 台帳の歩行・年齢から遅い速さ（例: 0.5〜0.8 m/s。根拠の資料を添える）で見込み、「目安」と添える（推し）
   - (c) openrouteservice の時間のまま「大人の速さ」と添える
3. 手段:
   - (a) 選ぶ欄（徒歩・車いす・家族の車・送迎・その他）と補記の文字にし、経路の手段は選んだ物から決める（推し）。今の文字の値は modeOf と同じ決まりで読み替えて残す
   - (b) 文字のまま、経路地図に「手段の文字から車」と出す
4. 浸水のハザードがある人で手段が車のとき、何か出すか（出すなら言葉は短く、色と連絡順には使わない）

## 作る物

1. 問い 1〜4 の答えの形で直す
2. 家と避難先を形で見分けられる印に（家の形・避難場所の形。状態の 4 色は使わない。T102 の決まりどおり操作の色 1 色）。画面・小さな絵・紙で同じ印
3. RouteMap.tsx の key の警告を消す
4. テスト: 候補から選んだ避難先の名前と位置の保存と読み出し、外へ送る物が増えない（2 点の座標と手段だけ。候補のデータを外へ取りに行くなら、それも送る物の表に）、徒歩の見込みの計算、手段の読み替え。375・768・1280、ライトとダーク
