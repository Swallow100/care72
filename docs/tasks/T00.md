# T00 Claude と Gemini を呼ぶ層、鍵の置き場、1 日の上限

## 目的

Claude（台帳の入力・分類・ペルソナ・監督・採点）と Gemini TTS を呼ぶ所を 1 か所にし、鍵が無い環境でも画面が壊れず「AI 未設定」と出る形にする。あとの作業（T03・T08・T12・T18・T19・T21・T22）は全部この層を通る。

## 読む物

- CLAUDE.md、docs/SPEC.md の「構成」「個人情報」「作り」
- lib/pseudonym（Claude に渡せる型はここで作る物だけ）
- Claude Code の skill `claude-api`（モデル名・構造化出力・tool use の書き方）。推測で書かず、skill の参照を見る

## 作る物

- `lib/claude/models.ts`: `OPUS = "claude-opus-5-5"`、`SONNET = "claude-sonnet-5-5"`、`HAIKU = "claude-haiku-5-5"`。用途ごとの既定（様式の読み取り・監督・採点は OPUS、台帳の入力・要約は SONNET、ペルソナ・分類は HAIKU）
- `lib/claude/client.ts`: `@anthropic-ai/sdk`（MIT）で client を作る。鍵は Cloudflare の `env.ANTHROPIC_API_KEY`（`getCloudflareContext()`）から。手元は `.dev.vars`。鍵が無ければ `AiNotConfigured` を投げる
- `lib/claude/call.ts`: 1 つの関数 `askJson({ purpose, model, system, input, schema })`。`input` の型は lib/pseudonym が返す印付きの型だけ（素の台帳を渡すと型で通らない）。JSON の形は tool use か構造化出力で縛る。max_tokens・timeout・1 回の再試行。応答の JSON を schema で検査してから返す
- `lib/claude/usage.ts`: 呼び出しごとに D1 の `ai_calls`（事業所・purpose・model・入出力 token・時刻。本文は入れない）へ 1 行。事業所ごとの 1 日の上限（既定 200 回、デモ事業所は環境変数で変えられる）。超えたら `AiLimitReached`
- `lib/gemini/tts.ts`: Gemini TTS を呼び音声（MP3 か WAV）を返す。鍵は `env.GEMINI_API_KEY`。名前を読ませない（「あなた」で読む）
- `app/api/health/route.ts` に `ai: { anthropic: true/false, gemini: true/false }` を足す。値は出さない
- `.dev.vars.example`（`ANTHROPIC_API_KEY=`、`GEMINI_API_KEY=`、`JUDGE_PASSWORD_HASH=`、`SESSION_SECRET=`、`AI_DAILY_LIMIT=200`）。`.gitignore` に `!.dev.vars.example` があることを確かめる（`.dev.vars.*` が先に書いてあるので、無いと git に入らない）。`.env.example` は消して README の「守り」を直す
- テスト: 鍵なしで `AiNotConfigured`、上限で `AiLimitReached`、schema に合わない応答で失敗、仮名でない入力が型で通らないこと（`// @ts-expect-error`）。本物の API は呼ばない（client を差し替える口を持つ）

## 終わりの形

- `npm test`・`npm run typecheck` が通る。`/api/health` が鍵の有無を true/false で返す
- README の「守り」に「鍵は .dev.vars と Cloudflare の secret だけ。1 日の上限」の 2 行
