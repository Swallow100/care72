# T151 地図をドラッグと指で動かす・雨雲の凡例が地図を隠さない形に

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。地図の頼み文と進み（docs/tasks/T116.md・docs/progress/t116.md、docs/progress/t46.md・t66.md・t72.md・t102.md・t112.md）、docs/DECISIONS.md の「地図と災害の情報」を読む。コードは components/map（CaseMap.tsx・NowcastLayer.tsx・RouteMap.tsx・RouteSceneSvg.tsx）、components/person/LocationPick.tsx、lib/map（camera.ts・geo.ts・layers.ts・center.ts・rain-scale.ts・route-edit.ts）、lib/jma/nowcast.ts。

## 意図（なぜこの作業か）

本番の PC で、次の 2 つが見えた。

1. 事業所の画面の地図（地域の中心を置く地図）をドラッグで動かせない。ほかの地図にも、動かせない・指では動かせない物がある。地図を使う画面は、事業所の画面（地域の中心）、本人のページ（位置を置く地図・避難経路の地図の窓）、担当一覧の右の面と全画面、訓練の画面の地図。動かし方が地図ごとに違い、ボタンでしか動かない地図がある
2. 雨雲の層（気象庁の降水ナウキャスト）を付けると、凡例（降水強度の色の画像・「02:20 時点」・出典の長い 1 文）が地図の右下に大きな白い四角で出て、小さな地図の半分ほどを隠す

地図は状況を見るための物で、凡例や操作が地図そのものを隠すと読めない。動かし方はどの地図でも同じにする。

線: この作業は Claude を呼ばない。雨・地図の操作は色と連絡順（lib/triage）に使わない。地図の中心と広さの決め方（事業所の地域・最初の表示）は同時に動いている T148 の物で、ここでは触らない。地図の出典（地理院タイル・気象庁・ハザードマップポータルサイト）は小さくしても消さない。

## 作る物

1. **全部の地図をドラッグと指で動かす**
   - マウスのドラッグと指のなぞりで動かせる（今の縮小・拡大・全体・全画面・上下左右のボタンは残す）
   - 動かし方は 1 か所に（押した・動いた・離したの計算を lib/map の純粋な関数にし、地図の部品はそれを呼ぶだけ）
   - ホイールでの拡大・縮小は、画面を送る時に地図が勝手に拡大しないよう、Ctrl（⌘）＋ホイールか、地図を押した後だけ（画面の送りの中にある地図。全画面は画面を送らないのでいつも効く）。決めを docs/DECISIONS.md に案として
   - ピンを押した時の動き（その人を開く）・地図を押して置く動き（位置・避難先・経由点）は、ドラッグと取り違えない（少し動いたら押したことにしない）
2. **雨雲の凡例を小さく**
   - 凡例は色の帯と数字と時刻だけ（降水量の 8 段の色、段の境の値、mm/h、「02:20 時点」）。地図を隠さない大きさにする
   - 出典は地図の下の出典の行に小さく 1 行で残す
   - 訓練の筋書きの雨の凡例（T116）も同じ形にそろえる（「想定」の印は残す）
   - 雨が無い時（雨雲の絵が空・時刻が取れない時）に地図が白く見えないかを確かめる。ライトとダークの両方
3. **ほかの地図の同じ型の不具合**: 凡例・層の切り替え・全画面で同じ型の物があれば直す
4. **テスト**: ドラッグで中心が動く・少しの動きは押したことになる・ドラッグの後のピンの押しは通さない・ホイールの決まり・凡例の大きさ（色の帯・数字・時刻だけ、出典は地図の下）
5. **絵**: PC（1920・1280）と狭い幅（375）の絵を docs/progress/t151/ に。人は種の架空の 10 人、地図の背景は地理院タイル。雨雲は手元の見本の絵（気象庁の本物の画像・電文は取りに行かない）

## 終わりの形

- どの地図もマウスのドラッグと指で動き、ホイールは Ctrl＋ホイールか地図を押した後だけ地図に効く。ピンの押し・地図を押して置く動きは前のまま
- 雨雲の凡例が小さな地図の隅の小さな帯になり、出典は地図の下に残る。訓練の雨の凡例も同じ形
- `npx vitest run --maxWorkers=3` と `npm run typecheck` が通る。PR を integrate/t11-t12 宛に（merge はしない）
