# T11 家族・支援者のスマホ

## 目的

本人がスマホを持たない前提に答える。家族・支援者のスマホに同じ赤緑の画面が「お母さんは無事ですか」の形で出て、本人の代わりに答える。本人の経過（ケアマネが電話した、迎えが決まった）は支援者への提供の同意の範囲で見える。

## 読む物

docs/SPEC.md の「画面 5」の家族の段、「個人情報」の同意。T10 の作り。docs/DECISIONS.md「色と連絡順」（本人の報告を当てにしない印の人は家族の緑だけ緑）。

## 作る物

- `/family`（ログインの役「家族のスマホ」。山田の娘。連絡先の行に「アカウント」を持てる形）
- 災害モード: 「お母さん（山田 ハナ）は無事ですか」→ 無事です / 無事じゃない / 分からない（連絡がつかない）。答えは信号として保存し、誰が答えたか（役割名）を持つ。「分からない」は未知のまま
- 答えたあと: 本人の経過（同意の範囲）、持ち出す物（T06 の文）、ケアマネに電話（`tel:`）、「最初から」
- 同意の範囲: 支援者への提供に同意していない本人（7 加藤）の家族には経過を出さない
- テスト: 3 つの答えの信号の形、同意の出し分け、lib/triage が家族の緑を本人の緑と区別すること（docs/DECISIONS.md「色と連絡順」）

## 終わりの形

- 家族の役で入ると「お母さんは無事ですか」→「無事じゃない」→ 担当一覧の山田が赤になり、経過に「娘が無事じゃないと答えた」

## 触るファイル

app/family/、components/phone/（T10 と共有）、lib/signals/、docs/PROGRESS.md

## 守ること

家族の画面にも診断・助言を出さない。本人の住所は出さない（持ち物と避難先だけ）。
