# T59 訓練の幅（参加者・職員・早送り・夜の発災、手の取消とメモ）（Opus、分岐）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。この文書は、それ以外に何も知らなくても作業できるように書いてある。

## 意図（なぜこの作業か）


- 参加者が担当全員で固定（lib/drill/db.ts の caseloadPeople と startDrill）。
- 職員の空きが想定の表で固定（lib/drill/scenarios.ts の staff: 大雨 3・地震 2・仮想 3）。
- 早送りの間が 2.5 秒で固定（components/drill/DrillControls.tsx の FAST_MS）。
- 夜の発災が選べない。本人役・監督は「発災から N 時間」しか知らない（lib/drill/persona.ts の時刻の行）。
- 手の取り消しと手のメモが無い（1 回押した手は戻せず、なぜその手を打ったかを残せない）。

線: 固定の筋（大雨・地震・10 分版）の既定の値とテストは変えない（選ばなければ今と同じ）。審査員が回す 10 分版の形を崩さない。

## 作る物

1. **開始の前の選択**（app/drill/page.tsx の開始の欄、components/drill/StartButtons.tsx）: 想定のボタンの上に畳んだ「設定」（押すと開く。既定は閉じていて、閉じたまま想定を押せば今と同じ）。中身: 参加者（担当一覧の人のチェック。既定は全員。0 人は断る）、職員（0〜9 の数。既定は想定の表の値）、夜間発災（チェック。既定なし）。POST /api/drill の body を `{ scenario, options?: { participants?: string[], staff?: number, night?: boolean } }` に広げる（lib/drill/http.ts の startPost）。startDrill の引数に options を任意で足す（今の呼び方は変えない）。参加者は caseloadPeople の結果の中だけ（外の id は断る）。
   - 置き場は drills.world の JSON（DrillState に options: { staff, night }。participants は既にある。lib/drill/db.ts の storeWorld・stateOfRow）。列は足さない。
   - 職員は initialState の world.staff の上書き。夜間発災は options.night。本人役（persona.ts）・監督（director.ts）・世界の部屋（world-room.ts）・1 回呼び（world-oneshot.ts）の入力に「発災は深夜 2 時ごろ。今は N 時ごろ」の 1 行を足す（発災を 2 時として hour から時刻を出す。startedAt はずらさない: simAt の時刻が全部ずれる）。訓練の上の帯（DrillBar）に時刻を添える。ルールの表は時刻を読まないので色・順は変わらない。本人・家族が電話に出る表（persona.ts の decideCallPickup）に夜の行を足すかは任せる。足すなら表に書き、Claude に決めさせない。
2. **早送りの速さ**: DrillControls の早送りの横に 1 / 2.5 / 5 秒の選択（components/ui/Select）。端末の中だけ（保存しない）。既定 2.5。
3. **手の取消（1 手戻す）**: 最後の手 1 つだけ、しかも刻みを越えなかった手（result.crossed が空）だけ。刻みを越えた手は本人役・監督の呼びが済んでいるので戻せない（「取消不可」の印）。手の前の状態の写し（DrillState のうち minute・hour・step・world・people・actions）を drills.world の JSON に undo として 1 つだけ持つ（手を打つたびに上書き、進めると消す）。取消は lib/drill/db.ts に undoAction: 1 つの batch で drills.world を写しに戻し（UPDATE の WHERE に今の world と step。actDrill と同じ競合の門。world_session_id は今のまま保つ: 写しの中の world.session は手の前の物なので、actDrill の COALESCE と同じく空のときだけ使う）、その手の drill_events（`<訓練>-<手>` と `-r`）と聞いた安否の signals（heardSignalId）を消す。ai_calls は消さない（上限の数）。取り消した数は state.undone に数え、訓練記録（DrillPaper）に「取消 N」と出す（採点は変えない）。画面は ActionLog の最後の手に「取消」（赤、アプリ内の確認の窓）。API は POST /api/drill/<id>/undo（lib/drill/http.ts に undoPost、断り方は stepPost と同じ）。
4. **手のメモ**: ActionPanel にメモの欄（100 字まで、任意）。手と一緒に送り、ActionRecord に memo?: string として payload に残す。ActionLog と訓練記録に出す。講評（lib/drill/review.ts）・監督（director.ts）・世界（world-room.ts・world-oneshot.ts）の入力には渡さない（渡す前に memo を落とし、テストで確かめる。渡したくなれば仮名化の門を通す別の作業）。
5. **テスト**: 選ばなければ initialState・startDrill・固定の筋の結果が今と同じ（既存のテストがそのまま通る）、参加者の絞りと外の id の拒否、0 人の拒否、職員の上書き、夜の 1 行がプロンプトに入る（偽の client）、早送りの間、取消（戻る・刻みを越えた手は断る・最後でない手は断る・終わった訓練は断る・競合・信号が消える）、メモの保存と、講評・監督・世界の入力に memo が無い。
6. **docs**: docs/progress/t59.md（Claude を使う所・使わない所を 1 行）。migration 0010 は要らない見込み（world の JSON と payload。DRILL_EVENT_KINDS を増やすと 0002 の CHECK の建て直しが要るので増やさない）。要ったら 0010。

## 終わりの形
