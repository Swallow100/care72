## 読む物

CLAUDE.md の「画面の決まり」、docs/DECISIONS.md、docs/PROGRESS.md の「書体」の段、app/globals.css、app/layout.tsx、components/、.claude/agents/screen-checker.md、docs/progress/wording.md。文の AI 臭さの観点は GitHub の theclaymethod/unslop と woerndl/unsloppify（どちらも MIT。本文は写さず観点だけ）。

## 作る物

- 共通の部品 `components/ui/`: Button（主・無色・赤・文字だけ）、Icon（Heroicons、MIT）、Tag（状態の印・色の文字・色の無い地の印）、Panel・PanelHead・PageHead・BackLink・Page（幅）、表の class（table.ts）、Menu、PrintButton、LinkPending・SubmitButton（押してから次の画面が出るまで灰色）、Tabs、PaperBar、RoleMenu
- 書体: 3 候補（M PLUS 2・Zen Kaku Gothic New・LINE Seed JP）を同じ画面で撮って比べ、選んだ物を app/layout.tsx・globals.css に。THIRD_PARTY.md
- 意味色: 黒を混ぜない澄んだ色（ライト・ダーク）。印は澄んだ色の塗り
- 各画面を部品で直す（担当一覧・本人のページ・入れる欄・右の面・地図・事業所・利用者追加・ログイン・ヘッダー・訓練・受け持ち・紙面の画面の帯）。内側のスクロールを外し、PC の 1280px・1440px で横に送らない
- 印刷: 紙面の画面に「印刷」、本人のページの書類の行に「印刷」（?print=1）
- `docs/progress/t35/before/`・`after/`（同じ 20 枚、1 枚 300KB 以下）、`docs/progress/t35/fonts/`、`docs/progress/t35.md`（棚卸し・直した物・書体の比較・色・unslop の観点・作者への問い）

## 終わりの形

- `npm test` と `npm run typecheck` が通る（next dev を止めてから）
- before と after を同じ画面・同じ幅・同じテーマで並べて見比べられる
- 1024・1280・1440px で横に送る箱が無い（様式 9 の表は T36）
