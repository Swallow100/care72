# T95 見本のケアマネ（山本）でも役を選べるように

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。

## 意図

審査員のアカウント（judge）は、ログインのあとに役（ケアマネ・医療班・行政・本人・家族）を選び、見本の事業所の画面をどの立場からも見られる。見本のケアマネ（山本、種の固定のアカウント）はケアマネの画面しか見られない。山本でも、本人・家族のスマホの画面や医療班の受入一覧を、同じように役を選んで見られるようにする。

## 作る物

1. 山本（種の固定のアカウント。lib/auth/demo.ts の固定の一覧）でログインしたとき、審査員と同じ「役変更」（ヘッダーの役の切替・/login/role）を出す。選べる役は審査員と同じ。
2. 役を替えた山本には、審査員と同じ壁を当てる（T81: 医療班・行政の役の検索・受入はデモ事業所の人だけ、本人・家族の役は見本の 1 人など、審査員と同じ決まり）。ケアマネの役に戻れば今までどおり。
3. 山本のアンケート（本物の共有リンクと答え）は、ケアマネの役の山本からは今までどおり見える。役を替えている間は見えない。
4. 審査員の流れと、毎朝 4 時の戻し・固定のアカウントの守り（T61・T81）は変えない。
5. テスト: 山本が役を替えられる、替えた役で他の事業所の人に届かない、ケアマネに戻るとアンケートが見える、ほかのケアマネ（固定でない）は今までどおり役を替えられない。

## 触るファイル

lib/auth（principal・demo・roles・session）、app/login/role、components/AppHeader.tsx の役の切替、テスト。
