# T04 話して入れる（Web Speech）

## 目的

T03 の入れる欄に「話す」を足す。ブラウザの Web Speech（SpeechRecognition）で日本語を文字にし、同じ経路（T03 の extract）に流す。声は考える所に使わない。

## 読む物

T03 の作り。docs/SPEC.md の「作り」（文字起こしはブラウザの Web Speech）。

## 作る物

- 入れる欄に「話す」ボタン（押している間か、押して始め・押して止め）。認識中は文字が欄に流れ、止めると T03 の「分ける」に送る
- 対応していないブラウザ（Firefox など）はボタンを出さず、文字の入力だけ
- 話した文は保存前に編集できる。本人の言葉を言い換えない
- 音声の録音（R2）はここではしない（発災時の録音は T10）
- テスト: 認識の結果が欄に入り、送る前に編集できること（SpeechRecognition は偽物で差し替える）

## 終わりの形

- Chrome で「話す」→ 日本語が欄に流れる → 止める → 項目に分かれる、が T03 と同じ画面で動く
