# T178 訓練の移る言葉の 2 形・機器が止まったままの間・同じ刻みの食い違い（評価の 11 回目）

意図: 評価の 11 回目（docs/progress/eval-r11.md の「直す所」の 1〜3）で守りの外れは 0 だが、審査役の人ごとの筋は 2・2・2 のまま。残った形を全部の想定・全部の人に効く形で直す。締切の前の最後の直しの回なので、小さく確実に。

1. 移る言葉の 2 形が門をすり抜ける。行き先の語が無い言い方と、読点と「これから」を挟む言い方が MOVE_FUTURE に当たらない。門と台が同じ表を読むので、表を直す。普通の会話を落としすぎない例もテストに入れる
2. 機器が止まったままの間。言葉も世界も動かず、30 時間以上無連絡の形がある。down_silent は最初の 240 分しか見ていない。止まったままの長い間も連絡が途切れないようにし、物差しを伸ばす。呼び出しを増やしすぎない（r11 は 71 回、55.3%。線は 77 回・62.7%）
3. 同じ刻みの出来事と連絡の食い違い（行方不明と在宅、帰宅困難と同伴の形）。原因を確かめ、コードで直せる物だけ直す。AI の言葉の揺れでコードで決められない物は直さず、そう書く
4. 直した所を tools/eval/guards.ts の守りか台の check に（足し方は docs/progress/t157.md）

守ること: 人の結末・色・連絡順は AI に決めさせない。医療の助言・診断の言葉を書かせない。仮名化の門を外さない。訓練の人は AI が演じる架空の人のまま。

触らない所: 画面（動画の撮影が進んでいる）、lib/forms（T179）。

確かめ: lib/drill・tools/eval/drill のテスト（--maxWorkers=2）、`npm run -s typecheck`、台の偽の回、r11 の記録に新しい check を当てた数（読むだけ。記録の中身は repo に写さない）。本物の API は呼ばない。進みは docs/progress/t178.md。
