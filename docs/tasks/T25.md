# T25 出典の登録簿

## 目的

Claude が根拠として引けるのは登録簿にある出典だけ。ルールの表の各行、医療依存の骨格の各段、採点の講評の basis は登録簿の id を指す。「なぜこの行があるか」の 1 行（ケアマネと主治医だけが見る）もここから。

## 読む物

docs/SPEC.md の「医療の芯」（出典の登録簿: 透析医会の災害時対策、糖尿病学会の災害時マニュアル、在宅酸素の災害時対応、認知症の人の避難、車中泊の血栓予防）、「範囲外」（関連死の時刻の表示はしない）。lib/triage の行の id。

## 作る物

- `docs/SOURCES.md`: 出典の一覧（id、発行元、題名、年、URL、どの行・段が引くか）。PDF はリンクだけで、リポジトリに入れない。引用は短く（15 字まで）出典付き
- `lib/sources/index.ts`: 同じ一覧を型で持つ（id と URL と 1 行の要旨）。lib/triage の各行と骨格の各段に `sourceIds` を付ける。登録簿に無い id はテストで落ちる
- 「なぜこの行があるか」の 1 行: 行ごとに 1 文（例: 「酸素濃縮器は停電で止まる → 予備ボンベの本数と電源のある避難先」）。本人・家族の 1 枚には出さない
- Claude への system に「根拠は次の一覧の id だけ。無ければ『根拠なし』と書く」を入れる口（T00 の call に `sources` を渡せる形）
- 出典を作者が確かめる欄（確認済の印と日付）。未確認の出典は画面に「未確認」と出る
- テスト: lib/triage の全行に sourceIds があり登録簿に存在する、docs/SOURCES.md と lib/sources が一致

## 終わりの形

- docs/TRIAGE.md の各行に出典の id が付き、押すと docs/SOURCES.md の行に飛ぶ。本人のページの医療の区分で「なぜ」を開くと 1 行と出典

## 触るファイル

docs/SOURCES.md、lib/sources/、lib/triage/（sourceIds）、docs/TRIAGE.md の生成、docs/PROGRESS.md

## 守ること

出典の本文を長く写さない（権利）。出典の URL が切れていても本文を入れない。関連死の「時刻」を出さない。
