# T189 デモの種の町名を実在の松山市の町名に

作者の指示（11/8 昼）: デモの種の町名が架空（かわなぎ町・みずほし町・くぬぎ谷町・あしなみ町・うみなり町・そらみ台・ほたる坂町）で、松山市のデモを見る審査員から現実離れして見える。町名だけを実在の松山市の町名にする。番地は今どおり持たない。人・家は架空のまま。

進みは docs/progress/t189.md。worktree care72-t189、branch task/t189（origin/integrate/t11-t12 から）。

## やること

1. 種の 10 人の本人の町名（ledger.basic.address.town）を、家のピン（seed/people.ts の SEED_LOCATIONS、T183 のまま変えない）を地理院の逆ジオコーダで引いた町名にする。デモ事業所の所在地も地図の中心の町名まで（番地・電話は入れない）
2. 同じ町に置いていた家族・隣人・施設の住所はその人の実在の町名に。本人以外の住所だけに出る架空の町（ほたる坂町など）は、近くの本人の実在の町名に寄せるか残す。県外・遠方の架空の市区はそのまま
3. 民間の施設（医院・薬局・訪問看護・医療機器・病院・透析）の名前は架空のまま。町名と同じ頭（かわなぎ…）は置き換えるなら町名と無関係な架空の頭に
4. 公の避難先（最寄りの避難場所など）は、T183 と同じやり方でピンの近くの実在の指定避難所の名前に
5. 停電の区域（demoOutageTowns）と訓練の地区の分け方（lib/drill/area-demo.ts の homes）は、前に同じ架空の町にいた人の組をその人たちの実在の町名の組に（誰が当たるかは変えない）
6. ふりがなの表（lib/forms/easy-words.ts の YOMI）に新しい町名の読みを、日本郵便の郵便番号検索か松山市の町名の一覧で確かめて足す（推し量らない）
7. 仮名化の門で実在の町名も伏せられ、Claude への要求に出ないことをテストで確かめる
8. 「町名は架空」のコメント・文書を「町名は実在、番地は持たない、人・家は架空」に。テストの期待・評価の台の町名も合わせる。docs/progress の古い記録は書き換えない
