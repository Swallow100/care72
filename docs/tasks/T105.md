# T105 訓練の経過を 3 つに分ける（起きたこと・分かったこと・した対応）と、電話の言い方

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。T90〜T94・T100 を取り込んだあとの物。

## 意図（なぜこの作業か）

訓練の画面の経過が分かりにくい。今は 3 つの欄に分かれて並ぶ:

- 状況（components/drill/Situation.tsx）: 刻みごとに新しい順で、世界の出来事（停電・道路・電話・避難所…）と本人ごとの安否
- 被害状況（components/drill/DamagePanel.tsx）: 見ている時刻の世界の様子
- 対応の結果と履歴（components/drill/ActionLog.tsx）: ケアマネの手と世界の返事

何分に何が起きたかを追うとき、本当に起きたことと、ケアマネが電話や訪問で知ったことと、ケアマネがしたことが混ざって読める。実際の災害では、ケアマネは起きたことを全部は知らない。分かったことと起きたことの差が、訓練で見たい所でもある。

電話の状態の言い方も、「電話不通」「家の電話 不通」（lib/drill/event-catalog.ts の line_down・mobile_down）より「通話不可」の方が、何ができないかがすぐ分かる。

## 作る物

1. **経過を 3 つのタブに**: 時刻（発災からの時分。T100 の言い方）の順に 1 本の流れで、タブで切り替える
   - 起きたこと: 世界で起きた出来事（監督の差し込み・想定の固定の出来事・本人に起きたこと）。訓練の途中では、ケアマネが知り得ない物をどう扱うか（隠す・終わってから出す・印を付けて出す）を問いにして、答えまでは「終わってから出す」
   - 分かったこと: ケアマネに届いた情報（着信・通話で聞いたこと・訪問で見た様子・家族や医療班からの知らせ・被害状況のうち公表された物）
   - した対応: ケアマネの手と結果（今の ActionLog の履歴）
   - タブの言葉は 2〜4 字の漢語（例: 「発生」「把握」「対応」）。決める前に Gemini で校正して作者に見せる
   - 1 つの行がどのタブに入るかは、記録の種類（incident・signal・action）から決まる表で決める。表は lib/drill に 1 か所
2. **終わったあとの見比べ**: 訓練の記録（訓練記録の頁と印刷）では、起きたことと分かったことを並べ、知るのが遅れた物・知らないままだった物に印（採点 T94 の内訳とそろえる）
3. **電話の言い方**: 不通を「通話不可」に（家の電話・携帯電話・回復の見込み。被害状況・状況・手の返事・監督への言葉。lib/drill/event-catalog.ts・labels.ts）。監督や世界に渡す言葉を変えるなら、返事の形と表の言葉の両方を同じに
4. **テスト**: 行の分け方の表（種類ごと）、途中に起きたことを出さない／終わってから出す、3 つのタブの描き、電話の言い方。375・1280、ライトとダーク
