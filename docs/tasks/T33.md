# T33 動画の構想・台本・素材・撮影の段取り・編集の骨組み

## 目的

提出の 3 分動画（YouTube）を、11/7 午後の撮影と 11/8 の編集でそのまま作れる形にする。最終審査はこの動画だけが流れる。動画が一番の難関なので、構成・台本・素材・撮り方・編集の枠を先にそろえる。売りは管理と情報共有の速さと正確さ。言い過ぎず、2 つの数字（計画 1 件にかかるケアマネの時間、避難所に着いた最初の 72 時間に医療班の手元に情報がある割合）を測った物だけで言う。

## 読む物

CLAUDE.md。docs/SPEC.md の「提出物」「3 分動画の筋」「正直な見立て」「架空の 10 人」「利用者と場面」「評価」「根拠の数字」。docs/DECISIONS.md（「119 の案内と画面の言葉」「AI の使い所」「動画」）。docs/PROGRESS.md と docs/progress/*.md（何ができているか）。docs/HANDOFF.md（残りの作業 T19〜T22）。README.md、docs/CLAUDE_CODE.md、docs/TRIAGE.md。過去の受賞作の動画（Anthropic と Cerebral Valley のハッカソン）。

## 作る物

- `docs/video/PLAN.md`: 3 分を秒で割った絵コンテ（場面ごとに 画面・声・文字・音・秒、右の列に審査）。最初の 10〜20 秒で誰の・どんな課題・どう解決。冒頭 20 秒の案とインパクトの問いへの当たり方。演出。色の決まり
- `docs/video/SCRIPT.md`: ナレーションの台本（日本語、3 分以内、数字は出典つき、「AI が決めない・最後に決めるのは人」の一文）と英語の字幕の案。作者が埋める所
- `docs/video/MATERIALS.md`: 素材の一覧と作り方（録画の画面・役・架空の人・順・秒、声、数字の出典、協力ケアマネの一言、アンケート〔T34〕、図、生成画像、音楽）。権利のある物だけ
- `docs/video/SHOOTING.md`: 撮影の段取り（11/4〜11/8、判断点、撮る順、画面の設定、各場面の操作を 1 行ずつ、失敗しやすい所）
- `docs/video/REFERENCES.md`: 過去の受賞作の動画の長さ・構成・最初の 10 秒
- `video/`: Remotion の編集の枠（場面の順、録画の枠、字幕、数字、最後の URL。素材が無い間は仮の面）と `video/README.md`（作り方、書き出し 1920×1080・30fps・3 分・-14 LUFS、Windows の罠）。ルートの依存に足さない
- `THIRD_PARTY_NOTICES.md` に動画の編集の道具
- `docs/progress/t33.md` に進みと作者への問い

## 終わりの形

- PLAN.md・SCRIPT.md・`video/src/timeline.ts` の文が一致し、`cd video && npm run check` が通る
- `video/` で `npm install` のあと、1 コマの書き出し（`npm run still`）と短い動画の書き出しが通る
- 作者が 11/7 に SHOOTING.md の順で撮り、11/8 に素材を置けば、`npm run render` → `npm run loudnorm` で提出の形になる

## 守ること

- 期間中に作った物だけを映す（キックオフ前の画面の見本、他のアプリ、他のプロジェクトを映さない）。画面の利用者は全員架空
- 審査員の ID とパスワードを映さない・書かない
- 「診断」「判定」「重症」「病気がわかる」を声にも字幕にも出さない。赤は「至急」、灰は「不明」
- 実名・秘密・他のプロジェクトの名前を入れない。作者と家族のケアマネの名前も書かない
- 数字を作らない。測っていない物は枠のまま残し、「未測定」と言う
- ネットに出る wrangler、Cloudflare の MCP、鍵、本物の API、配信、履歴の書き換えをしない。docs/SPEC.md・docs/DECISIONS.md・CLAUDE.md を書き換えない

## 作業の途中で決まった事

- 構成の順: 自己紹介（軽く。医学生、身近にケアマネ）→ 3 本立てを一言ずつ → 経緯（数字と自分と家族のケアマネ）→ 道具の中身（計画 → 訓練 → 発災時、本体）。強調する所は強調し、演出は豪華に、ただし中身を隠さない。生成画像は図・象徴・背景だけ（人の写真風は使わない）で、MATERIALS.md に「生成画像」と権利の確認を書く
- テーマ 1 で出す。動機（医学部 → 家族のケアマネの隣で気づいた足りない物）の段。台本の該当の所は作者が埋める欄に
- 見た目は青と白のコントラスト（白地に濃い青、青地に白。澄んだ青 1〜2 段と白、強調は至急の赤と無事の緑だけ）。PLAN.md に色の決まりを 1 段、雛形の見本を白地と青地の 2 枚
