# T116 地図の雨を降水量の段ごとの色に（訓練の筋書きの雨を本物の雨雲と同じ読み方に）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。T96 と T103 のあとの物。docs/tasks/T96.md・docs/progress/t96.md と docs/tasks/T103.md・docs/progress/t103.md、docs/DECISIONS.md の「地図と災害の情報」も読む。

## 意図（なぜこの作業か）

地図の雨は 2 種類ある。

- 本物の雨雲（気象庁の降水ナウキャスト。旗 JMA_NOWCAST、本番は on）: 気象庁の画像を加工せずに重ね、凡例も気象庁の画像（components/map/NowcastLayer.tsx）。色は 1 時間の降水量の段ごと
- 訓練の筋書きの雨（T103。lib/drill/rain.ts・lib/map/drill-rain.ts）: 淡い青灰の面と短い雨の筋（T96）。強さは弱・強・猛の 3 段の入れ子で、色の濃さと筋の密度で表す

T96 では、本物の警報と見間違えないよう、作り物の雨には気象庁の色の段を使わない決めにした。けれど平時の地図は本物の雨雲（降水量の段ごとの色）になり、訓練の地図だけ別の読み方（淡い面と筋）になった。同じケアマネが平時と訓練で違う読み方を覚えることになるので、訓練の雨も降水量の段ごとの色にそろえる。

## 作る物

1. **本物の雨雲は変えない**: 気象庁の画像と凡例をそのまま重ねていること、訓練の画面には重ねないことを確かめるだけ
2. **訓練の雨を降水量の段ごとの色に**:
   - 段は気象庁の降水ナウキャストと同じ 8 段（1 時間の降水量 1 未満・1〜5・5〜10・10〜20・20〜30・30〜50・50〜80・80 以上 mm/h）。色の値も気象庁の凡例と同じにし、出典を docs に書く
   - 淡い青灰の面と雨の筋はやめる
   - 筋書きの表の強さ（0〜3）を降水量（mm/h）に直す。強まって弱まる流れ、時刻で北東へ動くこと、不規則な縁、種から同じ絵になることは T103 のまま
   - 描く段は見ている時刻の世界の警戒レベルの上限まで（地図の雨が被害状況の欄より強くならない）。上限の決め方は docs に書く
   - 凡例（mm/h の段）を地図に出す。「デモ」「想定値」の印と参考にした過去の雨の出典は残す。地図に「気象庁」「警報」の語は出さない（T103）
3. **ピンを雨の上でも読めるように**: 状態の 4 色の印（赤・黄・灰・緑）が、赤や黄の雨の上でも読める（印の縁取りなど）。ライトとダーク
4. **決めの書き換え**: docs/DECISIONS.md の「気象庁の色の段は使わない」（T96 の案）を今の決めに書き換える。理由は本物の雨雲と同じ読み方にするため
5. **テスト**: 降水量 → 色の段（境の値）、時刻で動く、どの刻みでも警戒レベルの上限を超えない、凡例の 8 段と「想定値」、ピンの縁取り、雨を色と連絡順に使わない（lib/triage が地図と雨の表を読まない）
6. **写し**: 375・1280、ライトとダークで docs/progress/t116/ に
