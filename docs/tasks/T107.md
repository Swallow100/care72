# T107 書類の AI の評価の台（同じ命令で何度も回し、前の回との差を数で見る）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。書類の AI の所は docs/tasks/T08.md・T45.md・T52.md・T86 の進み（docs/progress/t86.md）・T101.md も読む。

## 意図（なぜこの作業か）

書類の AI（入れる欄の分け方・写真と PDF の読み取り・様式の読み取り）は、1 つの例で通っても足りない。自治体ごとに様式が違い、ケアマネが入れる物も PDF・スマホの写真・手書きのメモの写真・自由文・声の書き起こしと形が違う。直すたびに同じ束で回し、前の回と比べて良くなったか悪くなったかを数で見られる台を作る。

台は、手元の dev の道（台帳の入力 → 様式の読み取り → 対応表 → 紙の値の置き場）にそのまま通す。台のために別の道を作らない（作ると、本物の道の不具合が数に出ない）。

## 作る物

1. **回す道具** `tools/eval/forms/`（`npm run eval:forms`）
   - 入力の束（下の 2）と、リポジトリの外の様式の置き場 `C:\Users\choco\dev\care72-eval-corpus\forms\<市町村>\` の原本（`manifest.json` に市町村・URL・ファイル名・頁数。別の作業が入れる）を、手元の dev の道に通す。置き場や市町村の原本が無ければ、その市は飛ばして「原本なし」と数える
   - 既定は偽の client（本物の API を呼ばない）。本物は `--real` と、鍵が環境変数にあるときだけ（鍵のファイルは台の外で人が渡す。台は鍵を探さない）
   - D1 は手元の物だけ（migrations を流した node:sqlite。本番の D1・`--remote` に触らない）
   - 同じ命令で何度も回せる。前の回との差を 1 行で出す
2. **架空の入力の束を作る道具**: 種の 10 人の台帳から、入れ方ごとの入力を作る
   - 自由文（書き方の揺れ: 文章・箇条書き・メモ）、声の書き起こし風（言い淀み・繰り返し、方言は控えめ）、長すぎる書き起こし
   - 手書き風の画像（字の書体と傾き・影）、スマホの写真風（大きい JPEG・傾き・端末の付け足し）、HEIC（変換の扱いを数える）、複数頁の PDF（読む頁の上限を超える物も）
   - 実在の人の名前・住所は使わない。写真・PDF に描いた氏名・電話・町名は、ブラウザの黒塗りの画面と同じ塗り方で塗ってから送る（塗っていない絵は Claude に渡さない）
3. **正解（gold）**: 同梱の様式（松山市の計画書・災害診療記録・様式 9）と、架空の様式 2〜3 つ（T86 の架空の白紙の作り方）について、欄 → 台帳の項目の正しい対応を手で作った表
4. **数える物**（1 回の結果は JSON、比べるのは md）
   - 様式ごとの欄の当たり・外れ・取りこぼし（欄の読み落とし・余分も）
   - 紙の値の置き間違い（値の違い・場所の違い）、枠からはみ出し・別紙の数、未記入の数え方が正しいか
   - 外へ送った中身に架空の名前・電話・住所の文字が 0 か（本物の回でも送る前の中身を記録して調べる。画像は塗った所が黒いか）
   - 入力ごとの失敗（大きさの上限・読めない形式）
   - AI の呼び出しの回数と所要時間、ai_calls から費用の見積もり
5. **細かい記録**（リポジトリの外 `C:\Users\choco\dev\care72-qa\eval\forms\<回>\`、JSON Lines。偽の client の回も同じ形）
   - AI の呼び出し 1 つずつ: 用途・モデルと effort・仮名化したあとに送った中身の全文（画像は大きさとハッシュ、送った画像そのものは同じ所に）・返った中身の全文・所要時間・トークンの数と費用・失敗と再試行
   - 入力ごとの各段（受け取り → 読み取り → 対応表 → 紙の値）の途中の結果と判断の理由
   - 数え方の各項目の根拠（どの欄がなぜ外れか）
6. **埋めた紙**: 入力ごと × 様式ごとに、値を置いた紙を PDF と 1 頁目の PNG で `<回>\filled\<様式>\<入力>.pdf`。未記入の色付けの版も並べる。一覧の `index.html`（様式・入力・当たり外れの数・リンク）も同じ所に。原本の写る紙はリポジトリの外だけ
7. **前の回との差の表**: `docs/progress/eval-forms-<日時>.md` に数だけ（中身の写しや原本は入れない）
8. **テスト**: 偽の client で 1 周、数え方の正しさ

## 守ること

- repo に作者の発言の引用・作業のやり取り・人の名前を書かない。原本の PDF・Excel・その絵、原本の写る紙をリポジトリに入れない
- 外のサイトからファイルを落とさない（様式の束は別の作業で入る）。本物の API・本番の D1 に触らない。鍵を探さない・鍵のファイルを読まない
- 仮名化の門（lib/pseudonym、lib/claude/call.ts の askJson）を迂回しない。台の記録も、送る前の中身（門を通った後）を残す
- 他の worktree に触らない（T108 訓練の評価の台が同時に動く）。Chrome を使うテストは、無い端末で飛ばす
