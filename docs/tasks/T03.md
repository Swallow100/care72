# T03 入れる欄（文字・貼り付け → 項目、問い返し）

## 目的

ケアマネが本人のことを文字で話すか、ケアプランを貼ると、Claude（Sonnet）が台帳の項目に分けて医療依存の印を付け、空欄だけを 1 問ずつ問う。所要 10 分が上限。動画の「計画」の場面の芯。

## 読む物

docs/SPEC.md の「台帳の項目と入れ方」（問い返しの決まり 5 つ）、「画面 3 入れる画面」、「医療の芯」の骨格 8 段。lib/pseudonym、lib/claude（T00）、lib/db/types.ts の台帳の項目。

## 作る物

- 本人のページの右に常に開いている欄（`components/person/Intake.tsx`）。上に入力（文字、貼り付け）、下に「分けた結果」と「次の問い」
- `lib/intake/`:
  - `extract.ts`: 自由文 → 台帳の項目の差分（JSON、項目名は lib/db/types.ts の鍵）。今の台帳（仮名化済み）と自由文を Sonnet に渡し、「埋まっている項目は変えない」「本人の言葉を言い換えない（特記はそのまま）」「値の形が決まっている項目は選択肢の値」を system に書く。医療依存の印は lib/triage の骨格から機械的に付ける（Claude に決めさせない）
  - `ask.ts`: 空欄から次の 1 問を選ぶ。順は 医療依存 → 夜間の支援者 → その他。「分からない」「聞かない」をそのまま記録でき、空欄は「未確認」として残る
  - 差分は画面で見せてから保存（ケアマネが確かめる）。保存は経過に「入力」として残る
- 鍵が無いとき: 欄に「AI 未設定」と出て、手で項目を埋める道（各区分の編集）は残す
- テスト: 差分の適用（埋まっている項目を上書きしない）、問いの順、仮名化を通っていない入力が型で通らない。Claude の応答は固定の JSON で差し替える

## 終わりの形

- 佐藤 キミ（未作成）のページで「88 歳、独居、認知症で民生委員の〇〇さんが週 2 回来る。土砂の区域」と入れると、基本・人・避難・医療の項目に分かれて見え、次の問いが「薬の名前と残り」のような空欄の 1 問になる
- 保存すると担当一覧の「未作成」が「下書き」に変わる

## 触るファイル

components/person/Intake.tsx、lib/intake/、app/api/intake/、lib/db/ledger.ts（差分の適用）、docs/PROGRESS.md

## 守ること

医療依存の印・緊急度を Claude に決めさせない。自由文の町名・名前は lib/pseudonym が伏せる（伏せきれない名前が残る問題は PROGRESS.md に書いてある。設計の答えが要れば docs/DECISIONS.md に案）。
