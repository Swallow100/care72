## 作る物

1. アプリ内の確認・お知らせ: `lib/ui/dialog.ts`（confirm/alert の待ち行列と settle。参照の app-dialog.ts の作り）と `components/ui/DialogHost.tsx`（app/layout.tsx に 1 つ）。OS の `confirm`・`alert` を全部これに置き換える（最初に戻す・外す・平時に戻す・訓練の終了 など）。見た目は面（Panel）に題 16px と本文、ボタンは components/ui の Button（消す操作は dangerFill、取消は quiet）。消す操作は最初の焦点を取消に（Enter だけで消えない）。Escape と外側で閉じる。開いている間は後ろを送らない。ok の言葉は 2〜4 字（削除・戻す・終了）
2. 押したときの灰色を script で: 参照の press-script の作り（pointerdown で `data-pressing="on"`、離しても 120ms は残し `"out"` でふわっと消す、スクロールが始まったら消す、`data-no-press`・`data-press-host`）を app/layout.tsx の先頭の小さな script に。globals.css の `[data-press]` の `:active` に `[data-pressing]` を足す（塗りのボタンの overlay も同じ）。識別子と注は ケア72 の物に
3. ホーム画面に追加（本人・家族のスマホ、/me と /family だけ）: `app/manifest.ts`（name ケア72、display standalone、start_url は `/`、theme と background は globals.css のライトの地、icons は app/icon.svg と、puppeteer-core で描いた 192 と 512 の PNG を public/ に）。Android の Chrome は beforeinstallprompt を先頭の script で受けて「追加」1 回で入る。iPhone は Safari の共有 → ホーム画面に追加 の手順を 2〜3 行（文字と Heroicons）。LINE の中なら `openExternalBrowser=1` で外のブラウザへ。追加済み・PC・判定できないときは出さない。閉じたらその画面（タブ）の間だけ出さない。本人の画面の言葉の決まりで（やさしい日本語、ふりがな、大きく少なく）
4. 読み込みの印（AI の待ち）: `components/ui/Loader72.tsx`。Mark72 と同じ輪が回り続ける（Web Animations。動きを減らす設定では止めて文字だけ）。`role="status"`、文字は呼ぶ側が渡す（「分けています」「考えています」「聞いています」）。使う所: 入れる欄の分ける、訓練の進める・早送り、録音の分類の待ち、講評。SubmitButton の pending の灰色と重ねて出す
5. OS の選択（`<select>`）があれば、components/ui の Menu の作りで一覧から選ぶ部品に置き換える（参照の AppSelect と同じ書き方: value・onChange・中の option）。無ければ飛ばし、記録に「無かった」と書く
6. テスト: dialog の待ち行列（順・settle・danger の焦点）、追加の案内の判定（UA ごと・追加済み・LINE）、Loader の reduced-motion、manifest の形。既存のテストを壊さない
