# T134 自治体の個別避難計画の様式を、地域から選べる一覧にして、選んだら公式の様式をすぐ使える形に

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。続けて T86（元の様式の上に値を置く紙、docs/progress/t86.md）・T101（原本の受け口）・T107（書類の評価の台）・T111・T120・T131 の頼み文と進み、docs/DECISIONS.md「書類」（特に T101 の原本の受け口: 公式の URL から取り、版のハッシュを確かめ、PDF は置かず頁の絵だけを事業所の R2 に）を読む。

## 意図（なぜこの作業か）

ケアマネは、自分の市の個別避難計画の様式を探して取り込むのに手間がかかる（市の頁を探す・どれが様式の本体か見分ける・落として取り込む）。アプリが自治体の様式の一覧を先に持っておき、地域から選べば、その公式の様式で計画書を刷れるようにする。今アプリが持つ公式の様式は 2 つ（松山市の計画書・災害診療記録）だけで、ほかの市は事業所が自分でファイルを入れている。

## 作る物

1. **様式の一覧**（リポジトリに置くのは目録だけ。役所のファイル本体は置かない＝今の決まりのまま）: 都道府県・市町村・様式名・公式の頁の URL・ファイルの URL・形式（PDF・Excel・Word）・版のハッシュ・頁数・利用の条件の要約と印・確かめた日。評価の置き場の 15 自治体の目録（C:\Users\choco\dev\care72-eval-corpus\forms\manifest.json。読むだけ）から作る。
2. **一覧を増やす**: 公式のドメイン（lg.jp・city.・town.・village.・pref. のような自治体のドメイン）にある「個別避難計画の様式（本体）」だけを、政令指定都市（20）と都道府県庁所在地（重なりを除いて 50 前後）を優先に探して足す。Web の検索と公式の頁を読むのは可。ファイルは版のハッシュを取るためだけに作業者の一時のフォルダに落とし、リポジトリに入れない。記載例・手引きは様式本体と分ける。見つからない・公式のドメインに無い・利用の条件で使えない物は理由を一覧に残す。足した数と残りの数を進みに書く。
3. **画面**: 書類の様式を選ぶ所に「地域から選ぶ」（都道府県 → 市町村 → 様式）と検索。選ぶと、T101 の受け口と同じく、サーバーが公式の URL から取り、版のハッシュを確かめ、頁の絵を事業所に置く。版が変わっていたら「版違い」と出し、読み取りからやり直せる形にする。Excel・Word は今の読み取りの道（T119）に乗せる。一覧に無い市は今どおり事業所が自分でファイルを入れる。
4. **対応表（欄の位置と台帳の項目の当て）を様式の版ごとに共有する**: 様式の対応表は人の値を含まないので、版のハッシュが同じなら事業所をまたいで使い回せる形にする（最初の 1 回だけ AI で読み、2 回目からは読まない。費用と待ちが減る）。事業所の確かめ・手直しは事業所ごと。保存の形（D1 の表か R2）は任せる。migration が要るなら番号は今の最大の次（ほかと重なったら取り込みで付け直す。0030 は T125 が使う見込み）。
5. **評価の台**（tools/eval/forms）が一覧の様式を全部回せるようにする。本物の回は別の評価の作業者がする。ここでは偽の答えで動くことだけを確かめる。
6. **テスト**: 一覧の形（全部の行に公式の URL と版）、地域で選ぶ・検索、版違い、共有の対応表の使い回しと事業所ごとの手直し、ほかの URL を取らない（今の決まり）。PC の幅で画面の絵。
