# T42 アンケートの Web 版（Opus、分岐）

## 目的

協力してくれるケアマネに、紙（T34、docs/survey/paper.html）でなく https://care72.app の 1 ページで答えてもらう。相手は忙しく、アプリを触る時間も訓練を回す時間も無い。だから、案内の文で事情を伝え（ハッカソンの作品、医学生、家族がケアマネ、5 分で終わる、アプリを触らなくてよい、訓練はしなくてよい、答えは数字にまとめて動画と README に使うだけ、名前は要らない）、問いは T34 の 7 問のまま。変なボットが答えられないようにする。最悪は Google Forms に逃げるが、まずこれを作る。

## 読む物

docs/survey/QUESTIONS.md（問いの正）、docs/survey/README.md（答えの写し方。tools/survey/summarize.ts が読む形）、docs/survey/paper.html、tools/survey/、docs/progress/t34.md、lib/auth/（役と session）、lib/db/types.ts、migrations/、app/office/（事業所の画面）、components/ui、CLAUDE.md の「画面の決まり」、docs/DECISIONS.md「アンケート」。

## 作る物

1. ログインなしのページ `app/survey/[token]/page.tsx`: 案内の文 → 7 問 → 送る → お礼。本人・家族のスマホと同じく大きな字、縦 1 本、`font-ud`。問いの文は tools/survey/questions.ts を正にして画面に出す（二重に持たない）
2. 招待のリンク: ケアマネ役（yamamoto）と審査員が事業所の画面（/office）で「アンケートのリンクを作る」を押すと、推測できない token（32 文字以上）を D1 に 1 行入れて URL を見せる（コピーのボタン）。1 つの token で答えられるのは 1 回、有効は 14 日。作った人は宛先の控え（ケアマネ A など、本名でない）を付けられる
3. ボットの守り: token が無い・使用済み・期限切れは 404、見えない欄（honeypot）に何か入っていたら捨てる（200 を返して何も残さない）、ページを開いてから 15 秒未満の送信は断る（token の行に開いた時刻）、同じ送信元（CF-Connecting-IP）は 1 時間に 20 回まで、本文の長さの上限。Cloudflare Turnstile は `TURNSTILE_SITE_KEY`・`TURNSTILE_SECRET_KEY` があるときだけ効く（無ければ出さない。鍵はリポジトリに書かない）
4. 答えの保存: D1 の表（migration 0004。token・答え 7 つ・送った時刻・送信元のハッシュ）。事業所の画面に答えの一覧と、docs/survey/README.md の形（answers.md の 1 人分）で写せる文字の出口（コピー）。tools/survey/summarize.ts がそのまま読める
5. 案内の文: `lib/survey/text.ts` に 1 か所。相手への頼み（お手数ですがお時間のあるときに）、事情（Built with Claude: Japan 2026 に出す作品、作者は医学部の学生で家族がケアマネ、11/8 が締切）、アプリも訓練も触らなくてよいこと、5 分で終わること、名前は要らないこと、答えの使い道（数字にまとめて動画と README に出す。文はそのまま出さない）。設計の側が Gemini に通し、作者が読んでから送るので、直しやすく
6. テスト: token の検査（無い・使用済み・期限切れ・honeypot・15 秒・回数）、答えの保存と写しの形、ログインなしで /survey/<token> だけが開くこと（ほかの頁は /login へ）

## 終わりの形

- 手元の dev で、/office でリンクを作り、別のブラウザ（ログインなし）で開いて 7 問に答え、/office に答えが出て、写しの文字が docs/survey/README.md の形になる
- `npm test`・`npm run typecheck` が通る
- docs/progress/t42.md に、何を作ったか・ボットの守りの中身・案内の文の全文・確かめた所・問い
