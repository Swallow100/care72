# T08 様式の読み取り（写真・PDF → 対応表 → 差し込み）

## 目的

松山市以外の市町村の様式を、写真か PDF から Opus が読んで「どの欄にどの項目」の対応表（JSON）を出し、ケアマネが画面で確かめてから、汎用の差し込みが埋める。1 回だけ証明する（相手は内閣府の様式例）。汎用の様式エンジンは作らない。

## 読む物

docs/SPEC.md の「出力物 5 つと様式の対応」の「様式対応の作り方」1〜4、「範囲外」（汎用の様式エンジン）。lib/forms/matsuyama.ts（T05）の欄の一覧の形。lib/claude（T00）。skill `claude-api` の PDF と画像の渡し方。

## 作る物

- `lib/forms/mapping.ts`: 対応表の型（様式の欄 → 台帳の項目、値の形、自信、欄の位置の説明）。台帳の項目の一覧（聞き取りの項目表）を唯一の正として渡す
- `app/api/forms/read`: 写真か PDF を受け取り、Opus に「この様式の欄と、台帳の項目との対応」を JSON で出させる。様式そのものには個人情報が無いので仮名化は要らないが、台帳の値は渡さない（項目名だけ）
- 確かめる画面: 対応表を欄ごとに見せ、ケアマネが直す・外す。確かめた対応表を事業所に保存（同じ様式は次から読まない）
- 汎用の差し込み: 対応表と台帳から、欄の順に値を並べた紙面（A4、表形式でよい。元の様式の見た目は再現しない）
- 内閣府の様式例で 1 回通す。PDF はリンクで読み、リポジトリに入れない。対応表の結果は docs/PROGRESS.md に「欄 N のうち M が自動で対応、K を手で直した」と数で書く
- テスト: 対応表の検査（台帳に無い項目名を弾く）、差し込みの並び。Opus の応答は固定の JSON で差し替える

## 終わりの形

- 内閣府様式例の PDF を入れると対応表が出て、直して保存すると、山田 ハナの値が並んだ紙面が出る

## 触るファイル

lib/forms/mapping.ts、app/api/forms/read/、app/forms/mapping/、components/forms/、docs/PROGRESS.md

## 守ること

役所の PDF をリポジトリに入れない。対応表はケアマネが確かめてから使う（自動で使わない）。
