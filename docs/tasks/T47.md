# T47 書類の正しさと分かりやすさ、様式の選択（Opus、分岐）

## 目的

作者の指示（11/3 11:4x）: 計画書などで勝手に太字になるのは良くない。書類の行や欄が元の様式から勝手に変わっていないか気をつける。書類が何の書類か、詳しく分かるようにする。自治体ごとに様式が違うので、いろいろな様式を選べて対応できるようにする。

## 読む物

docs/SPEC.md の「出力物 5 つと様式の対応」、docs/tasks/T05.md（松山市の様式。市の PDF のリンク）・T06.md・T07.md・T08.md（別の様式の読み取りと対応表）・T36.md、docs/progress/t36.md（紙の決まり）・t37.md・t38.md、components/forms/（MatsuyamaSheet・Form9Paper・Form9Table・MedicalSummarySheet・OwnSheet・MappedSheet・FormCell・paper.css と各 *-paper.css）、lib/forms/（matsuyama・form9・medical-summary・own-sheet・mapped-sheet・mapping・mapping-db・form-read・paper-text・print-pages.test）、app/forms/、components/person/PersonView.tsx（書類の行）、lib/labels.ts、CLAUDE.md。

## 作る物

1. 勝手な太字をやめる: 紙面（画面と印刷）で値を太字にしている所を全部洗い、元の様式に無い強調を外す。太字が残るのは様式の見出し・欄の名前が元から太い所だけ。画面の本人のページの太字（医療の印など）は別（触らない）。洗った結果を表に
2. 欄の照合: 松山市の様式（2026.9.10 版の PDF。docs/tasks/T05.md のリンク。リポジトリに入れない）、様式 9、災害診療記録 2018 の順を、コードの欄の一覧（lib/forms）と 1 つずつ照合して表にする（欄の名前・順・数・言葉）。足した欄・消した欄・順の違い・言葉の違いがあれば直す。元の様式に無い行を作っていたら消すか、様式の外の「補足」として分ける。照合の表はテストで固定する（コードの欄の一覧が表と一致）
3. 書類の説明: lib/forms/catalog.ts に書類の一覧を 1 か所（id・正式な名前・短い名前・何の書類か・誰が誰に出す・いつ使う・出典と版）。本人のページの書類の行と紙面の画面の上にその説明の 1 行（例: 「松山市 個別避難計画 ― 避難行動要支援者名簿登録申込書 兼 個別避難計画（R8.9.10 版）。本人・家族が市へ出す」）。README の書類の節も同じ一覧から
4. 様式の選択: 事業所ごとに「使う様式」を選べる（自治体で違う）。今は松山市の様式が固定。T08 の対応表（form_mappings。別の様式の写真・PDF を Opus が読み、ケアマネが確かめてから使う）を様式の一覧に載せ、事業所の画面で既定の様式を選び、本人のページの書類の行で確かめ済みの様式を選んで紙面にできる。内閣府の様式（lib/forms/cao-form.fixture.ts）も候補に。選んだ様式は D1 に（offices の列か新しい表。migration は新しい番号で、PR の前に origin を見て重なれば進める）
5. テスト: 照合の表、太字の無いこと（lib/forms/paper-text の形で）、書類の一覧の形、様式の選択の保存と差し込み、頁数のテスト（T36）が通ること

## 終わりの形

- 紙面に様式に無い太字が無く、欄の名前・順・数が元の様式と一致する（照合の表が docs/progress/t47.md にあり、テストで固定）
- 本人のページの書類の行に、何の書類かの 1 行がある
- 事業所で様式を選べ、確かめ済みの対応表の様式で紙面が出る
- `npm test`・`npm run typecheck` が通る。docs/progress/t47.md に、照合の表・太字を外した所・書類の一覧・様式の選択の作り・確かめた所（印刷の PDF）・言葉の一覧・問い

## 守ること

市の PDF・学会の様式をリポジトリに入れない（欄の名前と順は自分で起こす）。医療の言葉の決まり（「診断」「判定」「重症」を書かない、助言をしない）。紙の決まり（paper.css、頁数）を壊さない。入れる欄（T45）・地図（T46）・訓練（T22）・アンケート（T42）は触らない。T41 が /office を触っていないか・T42 が /office のアンケートの欄を足していることに注意し、PR の前に origin/integrate/t11-t12 を取り込んで衝突を解く。
