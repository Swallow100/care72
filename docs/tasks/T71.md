# T71 最小のオフライン（Service Worker で最後の写し、通話の記録を貯めて戻ったら送る。migration なし）（Opus、分岐）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md`（何を作っているか・越えない線・地図・進め方）→ `CLAUDE.md` → `docs/tasks/README.md` を読む。元は docs/progress/real-use-audit-20261104.md の 5 と順の 6。この文書は、それ以外に何も知らなくても作業できるように書いてある。

## 意図（なぜこの作業か）


発災の 72 時間は、基地局の停止・輻輳で切れるのが普通。最低限: **担当一覧・本人のページ・本人の 1 枚・本人と家族のスマホの頁の最後の写し**（いつの写しかを出す）と、**通話の記録を貯めて戻ったら送る**。

線: この作業は Claude を呼ばない。色と連絡順（lib/triage）に触れない。写しは端末の中（Cache API）だけで、端末の外に出さない。ログアウトで消す。

## 作る物

1. **Service Worker（先に 1 commit）**: `public/sw.js`（素の JS。束ねない・import しない。OpenNext が .open-next/assets から `/sw.js` として出す。手元の next dev も public/ から出す）。scope は `/`。登録は `components/SwRegister.tsx`（client、`useEffect` で `navigator.serviceWorker.register("/sw.js")`。無い端末は何もしない）を app/layout.tsx の body の終わりに 1 行。
   - **写す物（ナビゲーション = HTML）**: `/`（担当一覧。?open= や絞込の query も同じ鍵で最後の 1 つ）、`/people/<id>`、`/people/<id>/forms/own`（本人の 1 枚。実際の path は app/people/[id]/forms の下を見て決める）、`/me`、`/family`。方針は **network-first**: ネットから 200 の text/html が返ればそれを写して返す。失敗（通信なし・5xx）なら写しを返す。リダイレクト（303・307。ログインへ）と 401・403 は写さず、写しも返さない（その時はネットの応答のまま）。`?_rsc=` 付き（Next の部分の読み込み）は写さない・触らない（Next はそれが落ちると全体の読み込みに落ちる）。POST は触らない。
   - **部品（/_next/static/…）**: cache-first（中身の hash が名前に入っているので古くならない）。写した HTML が参照する部品は、その HTML を写すときに `<script src>`・`<link href>` を読んで先に取っておく（取れなければそのまま。次に開いたときに取る）。
   - **いつの写しか**: 写しを返すときに、SW が `<html` の直後に `data-cached-at="<ISO>"` を入れた HTML を返す（文字列の置き換え。React 19 は根の要素の余分な属性を hydration の違いにしない。違いが出るなら、代わりに `<meta name="care72-cached-at">` を `</head>` の前に入れる。どちらを取ったかと確かめた方法を progress に）。`components/OfflineBand.tsx`（client）が `document.documentElement.dataset.cachedAt` を読み、あれば画面の上に「写し 11/4 09:12」の帯（黄の塗りの印に時刻。黄は文字に使わない決まりのまま）と「読み直す」。無ければ何も出さない。`navigator.onLine` が false のときも「通信なし」の 2 字の印を同じ帯に。
   - **消す**: `/api/auth/logout` と `/api/auth/login` の POST を SW の fetch で見て、応答が返ったら写しを全部消す（別の人のログインで前の人の写しを出さない）。lib/auth の route は触らない。SW の版（`CACHE_VERSION`）を上げたら activate で古い鍵の写しを消す。
   - **守り**: 写すのは同じ origin だけ。/api/ は写さない（信号・録音・通話の記録はいつもネット）。/q/<token>（QR の頁）は写さない（第三者が開く頁）。
2. **通話の記録を貯める**: components/list/CallButtons.tsx の記録（CALL_PATH への POST。電話・不通・通話と聞いた安否）が通信の失敗（fetch が投げる・5xx・429）で落ちたら「記録失敗」で捨てずに端末に残す。`lib/offline/queue.ts`（新しい。lib/signals/outbox.ts と同じ作り: localStorage、順を守る、送り直しても通らない応答〔400・403・404・409〕は捨てる、持ち主は `cm:<accountId>`）。残っている間はボタンの横に「保留 N」（灰の文字）。開いたとき・`online` のとき・20 秒ごとに送り直し、届いたら router.refresh()。**通話で聞いた安否（heard）も同じ**: 送るまで色と順は表に入らない（端末の中で表を動かさない。届いてから表が決める）。審査員（acct-judge）も同じ鍵で動く。信号の outbox（本人・家族）は触らない（SW からも触らない。iPhone に Background Sync が無く、頁が開けば今の outbox が動くので足りる）。
3. **テスト**: SW の中身は純粋な関数（写す path か・部品の URL の抜き出し・cached-at の差し込み・応答を写してよいか）を `lib/offline/sw-core.js` に分け、`public/sw.js` が同じ関数を文字列で含む形（importScripts は使わない。build 時に写す道具を足すか、sw.js の中に同じ関数を置いて「同じであること」をテストで比べる）にして vitest で見る。queue のテスト（lib/signals/outbox.test.ts と同じ形）。通しの確かめは headless Chrome（puppeteer-core は devDependencies にある）: `npm run dev` で担当一覧を開く → SW が入る → `page.setOfflineMode(true)` → 開き直すと写しと「写し HH:MM」の帯 → 電話の記録を押すと「保留 1」→ online に戻すと送られて「保留」が消える。絵を docs/progress/t71/ に。iPhone の Safari の実機は未確認と progress に書く（ホーム画面に追加した PWA でも SW は動く）。
4. **docs**: docs/progress/t71.md（Claude を使う所・使わない所を 1 行。この作業は Claude を呼ばない）。写しに個人情報が入ること・端末の外に出ないこと・ログアウトで消えることを README の本運用の条件に 1 行。仕様と違う決めは docs/DECISIONS.md に案として（先頭の節の上に「### 11/4 HH:MM 案（T71 の Opus）」。時刻は端末の `date` で確かめてから）。
