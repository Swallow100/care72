# T135 実在の様式に埋めた紙の上で、空いた欄を押してその場で入れる（文字の枠と画像も置ける、紙から質問）

このプロジェクトを知らないエージェントは、先に `docs/tasks/CONTEXT.md` → `CLAUDE.md` → `docs/tasks/README.md` を読む。T86・T101・T111・T117・T131 の頼み文と進み、docs/DECISIONS.md「書類」を読む。

## 意図（なぜこの作業か）

元の様式の上に値を置いた紙（T86 の添付の様式、T101 の原本の枠の紙）は、台帳に値の無い欄が空いたまま刷られ、画面の色付けで黄に塗られる。埋めるには今は次のどれかしか無い:

- 計画書（松山市）だけ、欄を押すと入力の窓が開く（T117 の「紙に直接書く」）。窓は欄から離れた所に開き、紙の上にどう刷られるかは保存して読み直すまで分からない
- 添付の様式（T86）と医療要約（災害診療記録2018）には紙から入れる道が無い。本人のページへ戻って入れる
- 様式にしか無い欄（台帳に項目の無い欄）は、どこにも入れられず、刷ってから手で書く
- 地図・写真・図や、様式の欄の外への書き足しは置けない

ケアマネは紙を見ながら埋めたい。空いた欄を押してその場で書き、刷られる字の大きさと位置をその場で見て、台帳に入る物は台帳に、様式だけの物はその人のその様式の手入れとして残したい。足りない欄は、紙から問いを順に聞いて埋めたい。

## 作る物

1. **その場で入れる**: 紙の空いた欄（色付けで塗る欄）を押すと、欄の上で入れられる。
   - 入れた字は、その欄の書体（明朝・ゴシック）と、紙に刷るときと同じ決まり（lib/forms/overlay-sheet.ts の fitText。欄の矩形に合わせて上限から 6pt まで縮める）の大きさで、矩形の中にだけ出る。矩形の外・ほかの欄へは出さない。下限でも収まらなければ下限のまま切り、帯に「別紙」と出す（刷ると別紙の頁へ）
   - □ の欄は押すと印が付く・外れる。選ぶ欄は選択肢の □ を押す
   - 部品つきの欄（元号・年・月・日、電話の − −）は部品ごとに入れる（lib/forms/split-parts.ts の区切り）
   - 欄の元が台帳の 1 つの所に当たらない欄（薬の一覧・連絡先の人・同意など、入れ子の値）は、今の入力の窓（T117）を開く
2. **入れた値の行き先**:
   - 欄が台帳の項目に当たれば台帳に入れる（ほかの様式にも効く）。入れる前に「台帳」と分かる印を欄の脇に出す。保存は本人のページの面の編集と同じ（/api/intake/save の edit。経過に誰がいつ）
   - 台帳に項目の無い欄（様式だけの欄）は、その人のその様式の手入れとして残す。誰がいつ入れたかを持つ
   - 署名・受付印・医師が書く欄（手書きの欄）は押せないまま
   - 紙の上で入れた値と質問で答えた値は、氏名・住所・電話・生年月日も台帳の本当の値で紙に置く。伏字・仮の言い方（（氏名）（町名）（電話）など）を紙に出さない。仮名化は Claude に渡すときだけの守りで、紙の欄を空けない（テストで確かめる）
3. **文字の枠と画像**: 紙の上の好きな所に、文字の枠（大きさと位置を動かせる。字の大きさは欄と同じ決まり）と画像（地図・写真・図。事業所の物から選ぶか取り込む）を置ける。刷る PDF にも同じ位置で出る。画像は紙に置くだけで、Claude に送らない（AI の読み取りの道を通らない）
4. **印と取り消し**: 手で入れた所・置いた枠と画像に、画面だけの印（紙には刷らない）。取消・再実行（直前の操作から順に）
5. **紙から質問**: 紙の画面の「質問」で、その様式の空いた欄のうち台帳に項目のある欄だけを、今の「次の問い」（lib/intake/ask.ts。何を聞くか・なぜ要るか・答えの例、定型）で順に聞く。答えは台帳に入り、紙がその場で埋まる。「不明」「無回答」「次回」は今の決まりのまま残す。本人・家族に問いを送る道が今のアンケートの頁や本人・家族のスマホの頁にあれば、この様式の足りない欄だけを送る形を足す。無ければ作らず、進みに案として書く
6. **テスト**: 押して入れた値が台帳に入る、様式だけの欄は手入れとして残る（誰がいつ）、字が欄の矩形の外に出ない、文字の枠と画像が PDF の同じ位置に出る、取り消し、紙の質問が様式の欄だけを聞く。PC の幅（1920・1280）のライトとダークで画面の絵
