## 決めた所

- migration 0011 は 0002 と同じく「今の表を退けて同じ名前で作る」（T60.md の「新しい表 → RENAME」だと seed/seed.test.ts の消す順の確かめが別の名前の表で落ちる）。DECISIONS 11/3 21:4x 案
- 警戒レベルの欄は大雨・台風・土砂だけ（11/3 21:5x 確定）。地震・津波・その他へ切り替えると NULL、保存で送られても NULL、ヘッダーの印にも出さない（lib/disaster/state.ts の hasAlertLevel、lib/disaster/db.ts）。前の lib/disaster/disaster.test.ts の「大雨 → 地震でレベルはそのまま」をこの形に直した
- 「飛ばし」は変えなかった人の全部（移動先がもう担当・事業所の外・無い・読んだあとに変わった）
- 確認の窓の名前は 6 行まで（5 人と「ほか N 件」）。DECISIONS 11/3 17:0x の T51-2 を「行」で数えた
- 一括変更で 1 回に送れるのは 200 人まで（多すぎる要求は入力不正）
- 担当ごとの選択のボタンは帯の中（担当の名前と人数、人のいない担当は出さない、未割当がいれば「未割当」）。表の中の担当の名前（行ごとの選ぶ部品）の横には置かなかった（10 行に同じボタンが並ぶ）
- 担当ごとのアイコンは Heroicons の UsersIcon を部品の中で読んだ（components/ui の中は変えない決まりのため Icon.tsx に足していない）
