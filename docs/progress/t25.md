## 決めた所

- 「引く行・段」は登録簿に持たず、lib/triage の sourceIds から逆に引く（二重に持たない）
- 登録簿の id は英小文字・数字・ハイフン（GitHub の見出しのアンカーと同じになる）
- 骨格の段の「なぜ」は段ごとに 1 つ（段 4・5 は区分をまとめた 1 文）。区分ごとに分けるのは、本人のページで足りなければ
- QUALIFIERS には付けたが、並び（ORDER）と読み方（READING）には付けていない（ほとんどが作りの決め）
