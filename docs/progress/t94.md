## 決めた所

- 空振りは世界の返事の「確率の前に事実で決まる道」と同じ順で決め、文書の 4 つ（電話 不通・通行止の訪問・職員 0 の訪問依頼・休止の透析施設への透析調整）のほかに、同じ道で決まる物（訪問看護の印のある訪問依頼、不通の手配・受入・報告、通行止の家へ向かう手配）も数える。結果が届いた手は数えない（docs/DECISIONS.md の T94 の案）
- 透析施設の休止は手の前の状態（before）に無いので、手を打った刻みのあとの世界（DrillScreen の ticks の world.facilities）から読む。休止の前に打って手の途中で休止になった手は空振りにしない
- 重複は「その人の新しい事」を着信・その人を指す状況・向かった人の到着の 3 つで見る。応答なしのあとすぐかけ直した電話も、新しい事が無ければ重複に数える（内訳に出すだけで 4 つの数字には入らない）
- 前に残した採点に内訳が無いときは、0 で出さずに訓練の記録から数えて足す（書き戻さない）。内訳は台帳を読まないので、あとで数えても残した時と同じ
- 講評の決まり 7 の例は「訪問でなく見守依頼か連絡先電話」にした。文書の例の「訪問依頼」は、世界の返事では通行止の家に届かない手なので、例に使うと空振りを勧めることになる
- 頼み事の言葉は T93 の画面の言葉と同じ字で score-labels.ts に置いた（T93 の dialogue.ts の ASK_LABELS が入ったら片方を読む形に寄せる）
- 紙面の DrillRecordTable（訓練記録の一覧）は手の行を持たないので触っていない。手の行の列は DrillPaper の対応履歴に足した
