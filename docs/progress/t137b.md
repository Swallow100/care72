Claude を使う所・使わない所:

- 使う所: 前と同じ（会話の次の 1 文を Haiku が 1 往復に 1 回）。T137b で、AI は話題でなく問いの表の id（深く聞く問いを含む）を選び、言い換えるだけになった。声は Gemini TTS（読むだけ）
- 使わない所: 問いの表と深く聞く問いの解き方（取れた答えで深く聞くか）、自分の声の拾いの見分け、話し始めの見分け、相づち、作り置きの声の表、色と連絡順（lib/triage には触れていない）

## できた物

1. 問いのカード（components/phone/PhoneView.tsx・phone.css）: 端の色の帯をやめ、印のある答えの面そのものを塗る（赤・緑は上の 2 つのボタンと同じ phone-fill-urgent・phone-fill-ok、黄は黄の塗りの印と同じ色に濃い文字の phone-fill-check）。印のある答えは高さ 2 倍・字を大きく、印の無い答え（わからない など）は灰の枠で小さく。家族のスマホも同じ部品なので同じ形
2. 声（lib/signals/voice.ts・app/api/signals/voice・lib/signals/media.ts・PhoneDisaster）
   - 会話の決まった文（問いの表の問い 21・ボタンの問い 4・締め 6・相づち 2）を全部 id で頼む形に。赤を押した時に端末が POST /api/signals/voice で作り置きを頼み、サーバーは R2 に無い物だけを 4 つずつ Gemini で作る（応答のあと）。声は最初の定型文と同じ（TTS_MODEL・DEFAULT_VOICE）
   - AI の 1 文は会話の API の中で Gemini で作り、9 秒まで待つ（前は 3 秒で端末の読み上げ）。端末は次の 1 文を 1.5 秒より長く待つときに作り置きの相づちを流す（話したあと「わかりました」、黙ったあと「しょうしょう おまちください」。1 往復 1 回）。サーバーを待つのは 16 秒まで
   - 端末の読み上げは声を作れなかった・鳴らなかった時だけ。声を止めた・あとの声が始まったら、前の声の失敗で止めたり読み上げたりしない（相づちと問いが重なったとき）
3. 「送る」のボタンを会話の画面から外した（答えは声もボタンも自動で送る）。「AI が きいています」はいつも出す
4. 聞き続ける（lib/signals/phone.ts）: 文字起こしは会話の間ずっと 1 本（ブラウザが止めても続きから、失敗が続けば止める）。答えは「その問いを読み始めてから次の問いを読み始めるまで」の言葉。読む間に本人が話し始めたら（自分の声の拾いでなければ）声を止めて聞く。考える間に届いた言葉は前の答えに足して次の手を 1 回だけ決め直す。録音は読む間も止めない。自分の声の拾いは答えから外す（lib/signals/talk.ts の echoLike・stripEcho）
5. 1 段深く聞く問い（lib/signals/talk.ts の TALK_ITEMS、言葉は phrases.ts）: けが ある → どこ・血・動かせるか、動けない → 挟まれ・呼べるか、動ける → 外へ、家 → 家のどこ、家でない → どこ、機器 → 電池・予備、薬 ある → 3 日分、連絡してほしい人 → 家族か。AI は表の id を選んで言い換えるだけ（表の外・元を聞いていない深い問いは決まった問い）。決まった問いの文のまま選んだら決まった問いとして読む。Claude が呼べない時は取れた答えに合う深い問いを、表の 2 問のあと・ほかの話題の前に聞く
