## 決めた所

- 経過の本文に聞いた安否の 1 語を足した: 「家族 娘 通話 無事」「本人 通話 無事でない けが」。足した信号に経過の signal の行が無く、本人のページの経過で安否が見えないため。名前・番号・メモは入れない
- けが・動けないは「選んだ物だけ」を列に入れる（選ばなければ NULL。「けがなし」の 0 は書かない）
- 「聞けず」は安否を書かない通話（経過だけ）。red_injury の人にも残せる
- 上の人数と右の面（地図・内訳）は絞る前の行で数える（絞っても別の色を押せるように）。右の面のリンクは絞込を持ち越さない（lib/map/side.ts は T60 の区画なので触らなかった）
- migration は要らなかった（SIGNAL_SOURCES の care_manager、TIMELINE_KINDS の called、メモは payload）
