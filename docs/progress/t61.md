## 決めた所（docs/DECISIONS.md「アカウントと事業所」。設計の側の答えで案から確定）

- 自分の再発行も断る（self）。自分の行には再発行を出さず、パスワード変更の欄にする
- 自分のパスワードの変更で、今のパスワードの打ち間違いはログインと同じ回数の制限にアカウントの ID で数える
- 赤の操作は CareManagerRow の中だけで白い地のボタンにそろえる。確認の窓の印は既定のまま
- 自分のパスワードの変更の PBKDF2 は 2 回（token は login() を通さず、ログインと同じ形で作る）
- 断りの言葉: 本人不可・唯一管理者・現在 不一致・同一 不可・新規 8〜64字・確認 不一致。事業所の経過の種類の言葉は「ケアマネ変更」
- 停止した人が担当のままの人は、担当の表の選ぶ部品で今の担当を「佐藤 停止」の選べない項目で出す。経過の前の担当の名前は停止した人でも引く
- 停止した人も改名・管理者・再発行はできる
- 事業所の無いアカウントは自分のパスワードを変えても事業所の経過に書かない
- 触るファイルの外を最小で触った: lib/disaster/state.ts（OFFICE_TIMELINE_KIND_LABELS はここにある。db.ts ではない）、seed/people.ts（`SeedAccount` の Omit に disabled_at を足す 1 行）、app/people/new/page.tsx（利用者追加の担当の候補を activeCareManagers に）、components/office/AssignForm.tsx（選べない項目）・AddCareManager.tsx（INPUT を export）
