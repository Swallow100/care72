## 決めた所

- 取り消した手の番号は使い直さない（次の手は `a<手の数 + 1 + 取消の数>`）。声の R2 の鍵 `act-<番号>.wav` と drill_events・signals の id が前の手と重ならないように（使い直すと、取り消した手の声が新しい手で鳴る）
- 取消の写しは刻みを越えなかった手のときだけ置く（越えた手のあとは写し無し＝取消不可）
- 本人・家族が電話に出る表（persona.ts の decideCallPickup）に夜の行は足していない（夜は出にくい、を足すなら表の割合を決める要がある。Claude には決めさせない）
- 「設定」は想定のボタンの並びの先頭に置き、開いた欄は並びの下に出す（文書の「上に」から変えた。並びの上に置くと、閉じたままでも想定のボタンが 1 段下がり、10 分版の位置が変わる）
- 職員の上書きは想定の表の値と同じ数でも options に残す（選んだことを訓練記録に出す）
- 職員の選択の既定は「既定」の言葉（想定の表の数は想定のボタンを押すまで決まらない）
- 上の 3 つ（設定の置き場・番号・職員の既定）は docs/DECISIONS.md の「11/3 22:0x 案」に書いた
- この版より前に始めた進行中の訓練は、最後の手の写しが無いので「取消不可」になる（次の手から取り消せる）
- 写しは手の前の状態をまるごと持つので、drills.world は手を打った直後だけ倍ほどになる（10 人・72 時間なら小さい。進めると消える）
