## 1 回目で何が起きていたか（記録から）

| 迷った所 | 記録で分かったこと |
| --- | --- |
| 計画書の「印刷」で何も変わらない（7 回） | 本人のページの書類の行の「印刷」（?print=1）で開いた時点で印刷見本に入っていた。押していたのは見本の帯の「印刷」で、台は印刷の窓を旗に替えるので、画面は何も変わらない。帯の「閉じる」は見本を閉じるだけで同じ道に残る |
| 様式 9 で上の帯が消えて戻れない（15 手） | 見本の間は上の帯（画面の切替）を隠していた。帯には「印刷見本 印刷 閉じる」だけ |
| 一括印刷で松山市の申込書 | 書類の一覧の右の面は選んでいる書類（既定は計画書〔松山市〕）の一括印刷。ボタンの名前が「一括印刷」だけ。さらに台の達成の印が「どこかで印刷の旗」だったので、様式 9 の目標が一括印刷で「済」になっていた |
| 「表示」が本人のスマホの入口へ | 本人のページの書類の行の「表示」「印刷」は行ごとに同じ名前。1 つ目の「表示」はスマホ入口の行だった |
| 「次まで」で経過 0 時間のまま | 着信の窓（aria-modal）の間は窓の外を押せない。窓を抜けた後の「次まで」は、要求が終わると送信中の印が外れ、読み直しの画面が届く前に次の手を読んでいた（1 回目は変わらず、2 回目で前の分が出た）。進んだ分は「経過 0 時間 1 分」のように小さかった |
| 担当の「担当」「変更」が開かない | 「伊藤 フミ 担当」は押すと一覧が開く選ぶ部品で、開いた一覧は body の直下（台の読みでは押せる物の一番後ろに場所なしで並ぶ）。台は今選んでいる人（山本）を読まず、「選ぶ」の手は OS の select だけで部品に効かなかった。行の「変更」は 64 個同じ名前で、選ぶ前でも押せた |
| 避難先2 を 1 つ目と読んだ | 紙の「事前避難場所」は台帳の避難先2（事前に行く所）。窓の欄の名前が台帳の名前だけだった。保存のあとは窓が閉じて紙が読み直されるだけ |
