## 決めた所

- 止まったまま家にいる間の連絡は赤にする（緑を落とすだけにしなかった）。落とすと連絡が消えて、直したい「長く連絡が無い」に戻る。「色を AI に決めさせない」に沿い、押す色をコードが決める。色と順そのものは今までどおり表（lib/triage）
- 表の行は骨だが、緑の行だけこの決めを優先する。表の行は「まだ動いている」前提で書かれ、時計と重なると食い違う。文は使わない
- 寝たきりでも手元に電話がある人（携帯・スマホを使える）は出る。聞こえ「一部」・認知症は出る（話し方は本人役が演じる）
- **処置や病名の記録からは決めない**。最初は気管切開の記録も条件にしたが、医療の見直し役の指摘で外した。種の該当者は寝たきりで固定電話だけなので、結果は変わらない
- コードの言葉で連絡するのは機器の見える人だけ。遠くの家族は見ていない機器を言い切らない（見直し役の指摘）
- 道の言葉の門は全部の人に効かせた。世界に閉じた道が無いのに「道が通れない」と言う文も落とす。遠くの家族が自分の周りの道を言う文も落ちる（世界に道の持ち主の区別が無い。本物の回で出るかを見る）
- 水の訳の門は、土砂でふさがった事のある人だけ。大雨で道が冠水する話を落とさないため
- 遅れて当たった道の出来事は、次の区切りへ持ち越さず言葉の方を合わせた（engine の順を変えない）

## 直せなかった物・残り

- 本物の API では回していない。審査役の点が 3 に上がるかは r10 で見る
