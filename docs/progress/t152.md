## できた物

1. 受入一覧（/staff）の最初に受入の面。どの幅も表の上（前は 1280px 以上の右の面、狭い幅は表の下）
   - 避難所の欄（3 つに共通、既定は自分がいちばん最近に受け入れた所）と、入り方の 3 つ: QR読取（本人の1枚）・氏名検索（登録済）・新規登録（未登録）。押すとその流れが下に開く。前の「避難所」の切替は 3 つの後ろに小さく「避難所別」で残した
   - QR読取: 端末のカメラ（ブラウザの組み込みの読み取り BarcodeDetector がある端末だけ「カメラ起動」。無い端末は「写すと受入頁」の 1 語）、読んだ URL を貼る欄（URL・頁の道・トークンだけのどれでも、トークンだけを取り出す。lib/custody/entry.ts の qrTokenFrom）、審査員の壁の中だけ見本 QR（デモの人 3 人、カナと「QR表示」「開く」。lib/custody/samples.ts）。どれも QR の頁（/q/<token>?shelter=）へ移り、受入はその頁で（同意の無い人の出し方は QR の頁のまま）。QR の頁は受入一覧の避難所の欄の値を受入の既定にし、医療班・行政には「受入一覧」へ戻るリンク
   - 氏名検索・避難所別: 今の検索のまま（ヒットはカナ・生年月日・年齢）。行の「受入」を流れの最後の 1 押しとして主の操作の色に
   - 新規登録: 今の最低限の項目（氏名・カナ・年齢か生年月日・薬・機器・連絡先）のまま。登録で受入まで
   - 3 つとも受け入れたら受入一覧へ戻る（/staff?received=<受け持ちの id>。前は検索は一覧のまま、新規登録は本人のページ、QR は一覧）。その人の行を表の先頭に「新着」と「開く」。並びの番号・CSV の行の順はルールの表のまま（lib/custody/entry.ts の pinReceived は画面だけ）
   - 受入一覧が空のときの「受入」は、入り方の最初のボタンへ送る
2. 受け入れた人の画面（医療班・行政の役で /people/[id] を開いた時。components/staff/ReceivedPerson.tsx）
   - 上: 氏名・カナ・年齢・介護度・受入（避難所・時刻・入り方）、状態（発災時はルールの表の色と理由、平時は骨格の段）と医療の印（時計のいちばん短い残り）
   - 要約: 薬・機器・アレルギー・連絡先の 4 つ（PC は 4 列、タブレットは 2 列）。医療要約の書類を開ける人（医療班への提供に同意あり）は「全文」「印刷」
   - 経過: 書き足しの欄（安否確認・診察・配薬・搬送・到着・記録。今の部品 components/person/TimelineComposer のまま）と行
   - 残りの区分（医療の残り・関係者・避難・書類）。要約に出した行は残りに出さない
   - 中身は本人のページの組み立て（見る人の範囲を通した物）を並べ替えるだけ（lib/custody/received.ts の receivedLayout）。医療が範囲の外の人（同意なし・未確認）は要約の所に同意の状態だけ
3. 審査員が医療班の役で試せる形: 見本 QR の「開く」で QR の頁 → 受入 → 受入一覧の「新着」→ 開く → 受け入れた人の画面。見本 QR は審査員の壁の中（審査員・審査員が足したアカウント・役を替えた見本のケアマネ）だけで、人は壁の中の人が受け入れられる種の事業所の人（T144 の wallOffice: 審査員はデモ事業所、役を替えた山本は確認用の事業所）。ほかのアカウントには出さない
4. 壁は変えていない: 医療班が見られる範囲（lib/consent/scope.ts）、同意の無い人の扱い、受け入れの前に本人のページを開けないこと、検索のヒット、審査員の壁。lib/auth と lib/custody の壁の所（actor・board・search・store・takeover）は使うだけ

## 画面に出した言葉（校正に通す物）

## 決めた所

- 11/7 の決め（T172）: 医療班の役の経過の書き足しは今はなし（欄も API も。lib/consent/relay.ts の定数で戻せる）。この記録の「経過: 書き足しの欄」は行政の役だけに残る

- 入り方の 3 つは QR読取・氏名検索・新規登録。SPEC の 3 つ目（避難所の名前で絞った一覧）は既に誰かが受け入れた人を探す道なので、3 つの後ろに「避難所別」で残した（docs/DECISIONS.md「画面」の案 T152）
- 受け入れた後の行き先は 3 つとも受入一覧（受け入れた人の画面へは行の「開く」で 1 押し）。頼みの「受け入れた人は受入一覧の上に出る」に合わせた
- QR を読む依存は足さない（ブラウザの組み込みの読み取りが無い端末は、端末のカメラのアプリで QR の頁を開く道と URL の貼り付け）
- 見本 QR は 3 人まで、種の id の順、自分が受け入れ中の人と期限の切れた人は除く
- 受け入れた人の画面は本人のページの部品の中身（lib/person.ts・components/person の PersonView・TimelineComposer・Timeline）を変えずに、医療班・行政の役の時だけ別の並びにした（同時に動く T143 と重ならないように）
