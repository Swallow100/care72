## 決めた所

- 返事の状態は記録済（noted）だけ足した。着くのが後の手配は今の「手配済」（dispatched）を使う（scheduled は足していない。言葉が同じで、採点は arriveAt と reach で着いた時刻を読める）
- 聞いた安否（heard）は今までの 3 つの手（本人電話・連絡先電話・訪問）だけ。119勧奨・見守依頼は家族や本人が電話に出ても安否にしない（表の効き目の行のとおり。左の表に届く道を増やさない）。出た人の言う事（本人役の吹き出し）は今までどおり出る
- 応援依頼の職員の空き +1 は、world.arrivals に person 空（BACKUP_PERSON）・役 staff・着く時刻＝戻る時刻の 1 件を積み、settleWorld の戻りの動き（職員 +1）で効かせた。WorldChange に職員の増減が無く、scheduled に積んでも今の刻みの道では当たらないため。本人ごとに読む所（本人役・採点・被害状況）は person で引くので拾わない
- 相手の要る手で台帳に相手が無ければ押せない。移送手配・電源手配は相手の区分に市役所を含むので、行政報告と同じく選ばなければ固定の相手（市役所）にした（見本の 10 人に市役所・介護事業所・電力会社の連絡先が無く、灰ばかりにならないように）。薬手配は薬局・かかりつけが無ければ灰のまま（見本の 10 人には無い）
- 透析調整は家へ向かわない手なので、家の前の道が通行止でも調整できる。病院受入は受入型（電話と時間の確率）で、移送の通行止は見ない
- 自由対応の Claude の 1 文は「何をしたか」で、結果は書かせない。記録に落ちたとき（Claude の答えが表の外など）は Claude の 1 文を使わない
- 自由対応の文は、鍵があれば伏せた文を氏名に戻した物を、鍵が無ければ打った文のまま手の記録に置く（どちらもサーバーと訓練記録の中だけ）
- 本人役・世界は a.kind で言い方を引くので、自由対応は「そのほかの対応をした」と読む（読み替えた手の言い方は action-catalog.ts の actionWords が as で引く。T93・T94 が使う）

## 問い

- 本人役（persona.ts の tickText）と世界（world-oneshot.ts の actionLines）が、自由対応を読み替えた手の言い方で読むようにするか（`ACTION_WORDS[a.kind]` を `actionWords(a)` に替える 1 行ずつ。persona.ts は T93、world-oneshot.ts は T89 の後の持ち主の所なので触っていない）
- 講評（review.ts の RESULT_WORDS）に記録済（noted）が無く、今は英字のまま出る。採点（score.ts の PERSON_ACTIONS・reachedAt）も新しい手をまだ数えない。どちらも T94 で表の towardPerson・reach・arriveAt を読む形に
- 自由対応の文（record.text）を履歴と訓練記録に出すか（メモと同じ扱い）。ActionLog・紙面は T93・T94 の持ち物なので触っていない
- T92 の介護休止（helperAway）の印を訪問依頼の決め方で読む 1 行は、印の型が入ってから world-reply.ts の dispatch の所に足す
- 自由対応の口（drillFreeHook）は手の route で作っている。hooks.ts の drillHooks に寄せるか（同じ AskJsonContext の作りが 2 か所ある）
- world.checks の確認済は、あとで同じ人の透析施設が休止しても上書きされない（drillClocks は checks を最後に当てる）。透析施設そのものに振り替えたあとに、その施設が休止した場合を「未確認」に戻すかは T92 の出来事（病院休止・薬局休止が checks に unconfirmed を書く）と合わせて決める
- 手配型（薬・透析・移送・電源・業者）は、台帳に番号の無い相手でも番号なしにせず確率で決める（電話型の手だけが番号なしを見る。画面は相手の横に「番号なし」を出すが押せる）。番号なしにするなら今までの 7 つの手は変えずに、手配型だけに足す
- 119 に当たる文の線（119・救急車・救急隊）は仮。「救急」だけの文は Claude の読み替えに任せている
- counts.free は手を打った世界に数え、保存した物からの作り直し（replayState）では数え直さない（T90 の counts と同じ扱いになる見込み）
