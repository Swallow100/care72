- AI の呼び出しの記録（ai_calls）は「最初に戻す」と毎日 4 時では消さない（手元の db:reset は今までどおり全部消す）。ボタンで戻すたびに 1 日の上限の数えが 0 に戻ると上限が効かないため。日は JST で数えるので 0 時に戻る。前の案（4 時に数えも戻る）と違う
- 分類の列は Claude を呼ばずに入れた固定の値（本番で Claude が返す形と同じ）。画面には AI の印が付く。種の分類であることは画面に出していない
