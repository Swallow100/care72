## 決めた所

- 数字の空白を外したのは答えの頁に出る物だけ。tools/survey/questions.ts の `heading`（summary.md の見出し）・`column`（写しの列の名前）・COMBINED の言い方は中の物なので「問 4　…（いくつでも）」のまま。/office の画面の「回答 0/30・期限 11/5 23:59」などの言葉も変えていない（アプリのほかの画面の決まり）。
- 選択肢の言葉（「5年未満」「2〜4時間」など）は頁と /office の答えの一覧と summary.md の表で同じ物を使うので、/office の一覧と summary.md の表の選択肢も空白なしになる。記号（a・b…）・表・API は変えていない（T42・T65 の答えの行はそのまま読める）。
- docs/survey/QUESTIONS.md（頁の問いの写し）と README.md の記号の表を同じ言葉に合わせた（answers.test.ts が一致を見る）。QUESTIONS.md は問 4・問 6 を「**…どこですか**（複数可）」、記入欄を「（記入）」にした。「作者の控え」と README の本文は文書の書き方のまま。paper.html は使わない紙なので触っていない。
- 作った直後に一覧の行そのものへ印を付ける形（作成済の行を開く・枠で囲む）は取らなかった。一覧は新しい順で先頭の行がそれで、控えの名前で見分けられる。印を付けるには server の一覧の行と client の作成の部品で token を受け渡す作りが要り、今夜の直しには重い。
