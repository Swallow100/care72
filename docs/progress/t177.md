頼み文は docs/tasks/T177.md。worktree care72-t177、branch task/t177（origin/integrate/t11-t12 から）。Claude は呼んでいない（偽の client と手で組んだ入力だけ）。評価の 10 回目の記録（drill の r10）は再現のために読んだ。下は数と形だけで、記録の言葉は写していない。

## 原因（r10 の記録で確かめた事）

### 1. 切れた時刻

帳面は経過の数（予備も N 時間に切れた）を渡し、時計は別の行だった。本人役が自分で換算していて、形が 3 つ出た: 時計に直して正しい、経過の数をそのまま時刻に、計算が違う。同じ人の中でも変わった。今の様子の「（N 時間から）」と前の連絡の「N 時間に」も同じ経過の数で、通話と訪問の文には昼の訓練の時計の行が無かった。

### 2. 手なしの移動

| 形 | 原因 |
| --- | --- |
| 寝たきりの人が手も到着も無く病院へ移ったと答え、後で移送の車で出る | 同居で車のある人がいれば、答えの 1 回でいる所が変わった（T141 の carer）。手も記録も要らなかった |
| 移ったと言った直後に家にいると言う | いる所は前の連絡 1 つからしか引かず、移った事がどこにも残らなかった。表の行の「家」が上書きし、いる所を言わない連絡で分からなくなった |
| 移すと言ったあとに手伝いを待つ | 向かう言い方の形に「移します」「送ります」が無く、記録にならなかった。移れない人でも言葉は落ちなかった。通話の「移ります」は何にも残らなかった |
| 来ていない移送の車が来たと言う | 門に無かった |
| 薬や電源が届いただけで家の外へ | helpedFlip がふだん動ける人なら何が届いても通した |

## 自力で移れる人の扱い（決めた所）

docs/DECISIONS.md の「11/7 案（T177）」。種の 10 人では次のとおり（道が通れている時）。

| 人の形 | 移れるか |
| --- | --- |
| 歩行に問題なし・避難先あり（2 人） | 移ると言えば 1 時間後に移る |
| 歩行困難で同居の車（1 人） | 同じ |
| 一部介助で手段の家族の車（3 人） | 同じ。帰宅困難の印があれば移れない |
| 寝たきり（2 人。同居の車の有無によらない） | 運べる人か乗り物が来てから |
| 避難先が計画に無い（3 人。寝たきりの 1 人と重なる） | 移らない |

- 「もう移りました」という答えも、移れる人なら移り始めの記録にする（いる所は 1 時間後）。移れない人なら言葉も答えも通らない
- 移り始められるのは刻みの連絡だけ。通話で「移ります」と言わせると、記録に結べず移らないまま残るので落とす
- 表の行が家の外と言うのは世界の出来事として記録にする。表の行の「家」は移った人では移った先に直す

## どこに Claude を使い、どこに使わないか

使わない: 移れるかの決め、移った記録、切れた時刻の数、いる所の問いの答え、誰を相乗りにするか。使う: 連絡と電話の言葉、移ると言うかどうか（本人役 Haiku）。

## 問い

1. 「寝たきりの人は同居の車があっても移らない」は訓練の役の決めで、実際の移送の可否ではない。画面や動画で移動の話に触れるときは「訓練の決め」と添えるか
2. 「どこにいますか」の答えは、本人役の答えが門を通って記録になった物（by turn）でも AI の印なしで出る。記録はコードの物なので印なしにしたが、これでよいか
