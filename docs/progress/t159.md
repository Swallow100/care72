# T159 普通の言い方が（氏名）に伏せられる件

頼み文は docs/tasks/T159.md。worktree care72-t159、branch task/t159（origin/integrate/t11-t12 から）。Claude は呼ばない。

## 原因

lib/pseudonym/forms.ts の名前の形の見張り（かなの名前の 2〜4 字、`kanaNameEnd`）が、続柄の「の」の後ろ・行頭・見出しの後ろのかなの並びを、語尾ごと 1 つの名前と見ていた。「母のことです」は「ことです」の 4 字が一般の語の表に無いので名前になり、「母の（氏名）」で画面に出た。同じ形で、行頭の述語（「そうです、」「いきます！」「いいよ、」）・続柄の後ろの物の名前（「母のめがね」「父のつえ」）・時の言葉（「けさ、」「ゆうべ、」）も伏せていた。敬称の道（`nameStart`）は、ペット・役所・続柄・物の呼び名（「ねこちゃん」「民生さん」「ご両親様」「お日様」）を除く語に持っていなかった。

この見張りは Claude の返事の伏せ（maskReply）と、Claude に送る前の門（pseudonymizeText・findLeaks）の両方が使うので、直しは両方に効く（全部の訓練・様式・入れる欄）。

## 残り・確かめていない物

- 「妻のことよ」（一般の語＋よ）は今も伏せる。「ことよ」「はなよ」のような古い名前と見分けられないので、伏せ漏れを作らない方を取った。台の check では伏せ過ぎに数える（次の回で出れば数に出る）
- 一般の語の表にある「なお」「みな」は、続柄の「の」の後ろでも前から名前にしていない（「孫のなおが」）。この作業では広げも直しもしていない
- 「つえ」は古い名前にもあるが、続柄の後ろでは杖の方がずっと多いので一般の語に入れた。台帳の家族の名前は置き換えの表で伏せるので、緩むのは台帳に無い名前だけ
- 台の check の「名前でない」は台が持つ目安。かなだけで 2〜4 字・語尾の無い物（「孫の（氏名）が」の元が「ゆう」）は名前として数え、伏せ過ぎに入れない（数は少なめに出る）
- 本物の回（7 回目）で数が 0 になるかは、次の本物の回で見る
