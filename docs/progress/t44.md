## 移さなかった物と理由

- 参照の読み込みの印の絵（的と矢、その寸法と震え）: 絵は移さない決まり。動かし方（Web Animations、動きを減らす設定で止める）だけを Mark72 の輪に当てた
- 参照の install の判定の「前のアドレスから移ってきた」目印（#moved と localStorage）: ケア72 には前のアドレスが無い
- 参照の押したときの CSS の `@property` で透明度を動かす作り: ケア72 の `--press` はテーマごとの色そのものなので、transition で元の地に戻す方が短い。`touch-action: manipulation`・`-webkit-tap-highlight-color`・`active:scale` を消す決まりは globals.css の data-pressing の範囲の外なので入れていない（問い 3）
- 参照の選択の一覧の「下から出る面」と内側の `max-h` の送り: ケア72 は Menu と同じ下に開く一覧で、画面の中にスクロールの箱を作らない決まりなので内側で送らない
- 参照の窓・選択の見た目（角・テーマ色の薄い下地・lucide のアイコン）: ケア72 の Panel・Button・Heroicons で描いた
- 録音の分類の PC 側の「未分類」（`components/list/Classification.tsx`）: 分類が終わらずに止まった行にも出るので、回る印を付けると待っているように見え続ける。本人のスマホの録る間にだけ付けた

## 作者への問い

1. 追加の案内は平時の画面だけに出した（災害モードの本人の画面は「無事」「無事じゃない」の 2 つだけ、の決まりのため）。種の事業所が災害モードで始まるので、審査員が本人スマホを開いても平時に戻すまで案内は見えない。災害モードでも答えたあとの画面（とどきました）に出すか、このままか
2. 追加の案内の「追加」「ブラウザで開く」は操作の色（青）の塗り。本人・家族の画面で面を塗るのは赤緑の 2 ボタンだけ、の決まりとぶつかる。主の操作は操作の色、の決まりを取ったが、白の面にするか
3. 押したときの灰色を速くする周りの決まり（iPhone の二度押しの拡大で遅れないよう `touch-action: manipulation`、タップの青い光を消す `-webkit-tap-highlight-color: transparent`）は、T44 の globals.css の範囲（data-pressing の分だけ）の外なので入れていない。入れるか
4. 窓の決める方のボタンにアイコンが無い（取消は×付き）。窓の部品は文字だけでよいか、操作ごとにアイコンを渡すか
5. 「中断確定」「取消」の訓練の言葉（`lib/drill/labels.ts` の confirmAbandon・cancel）は使われなくなった。T22 の範囲なので消していない
6. 待ちの印の文字「分けています」「考えています」は依頼どおりにしたが、状態の言葉の 2〜4 字の漢語（分類中・思考中）に寄せるか
7. 長い一覧（様式の対応表の「台帳の項目」）は内側で送らず、画面全体が伸びる。画面の下の方で開くと一覧が下にはみ出し、画面を送って選ぶ形になる。上に開く切り替えを足すか
8. manifest は全部の画面に付くので、PC の Chrome でもアドレス欄に入れる印が出る。ケアマネの PC で入れても困らないと考えたが、よいか

## 設計の答え（11/3、PR #35 を読んで）と直した所

- 問い 1: 平時だけでよい（災害モードでは出さない）。そのまま
- 問い 2: 本人・家族の画面で面を塗るのは赤緑のボタンだけ、が正。追加の案内の「追加」「ブラウザで開く」を無色（面の中の灰色、`bg-panel2`）にした（`install-android.png`・`install-line.png` を撮り直した）
- 問い 3: 入れる。`app/globals.css` の `[data-press]` に `touch-action: manipulation` と `-webkit-tap-highlight-color: transparent` を当てた（本人・家族の画面の押す物は全部 `data-press` を持つ）
- 問い 4: 窓の決める方のボタンもアイコン＋文字。`DialogOptions.icon`（`components/ui/Icon` の `DialogIconName`）で渡し、無ければ消す操作は RemoveIcon・ほかは SaveIcon・お知らせは CloseIcon。最初に戻す・平時は RestoreIcon、一覧除外は UnlistIcon、訓練中断は RemoveIcon（`dialog-*.png` を撮り直した）
- 問い 5: 「中断確定」の未使用の言葉は T40 で消す
- 問い 6: 待ちの文字は文のまま（AI の印つきの一時の状態なので 2〜4 字にしない）
- 問い 8: PC で manifest の入れる印が出るのはそのまま
