## 決めた所

- D1 は migrations を流した node:sqlite（lib/db/test-d1.ts。wrangler の --local の表と同じ SQL）を回ごとに新しく作る。同じ命令で同じ入力から始まり、手元の dev の D1 も汚さない。R2 はメモリの偽物
- 正解の側も同じ道（偽の gold の client → 差分 → 保存 → 紙）を通し、AI の側と比べる。道そのものの限り（PDF の 4 頁目・AI の分け方に無い欄）は AI の外れに数えず「道で運べない値」に分けて数える
- 入れる欄の前の台帳は、人が手で入れる物（住所・位置・経路地図・連絡先の名前と電話と順と距離・同意・時計）だけを持つ。AI の分け方で埋まる物（介護・医療・避難・特記・連絡先の夜間と備考）は空。差分の「追加」だけを保存（画面の既定と同じ）
- 1 つの入力の中の呼び出しは直列（askJson は reserve → create → finish の順なので、記録を順に結ぶ）。入力も直列に回す
- 絵の入力は、作った HTML で伏せる所の場所を測り、ブラウザの段で塗ってから送る。塗った所の明るさを読み直して測り、黒くない頁は送らない（記録に「塗った所が黒くない」）
- 正解の表の無い置き場の様式は、読めた欄の数だけ（当たり外れは数えない）。紙は既定で台帳そのままの 1 人だけ刷る（置き場の様式は数が多く、全部の入力で刷ると数千枚になる）。`--paper-all-forms` で全部
- 偽の回の数は台の確かめ用で AI の力ではない（md と index.html に「偽」と出す）
- 既定の置き場 ../care72-qa は同じ repo の別の worktree。原本の写る紙と送った画像が履歴に入らないよう、.gitignore に /eval/ を足した（その worktree が新しい .gitignore を取り込むまでは、そこで git add -A をしない）。台の守り（assertOutside）は自分の worktree の中を指すと止まる

## 見えた事（偽の回でも本物の道が動く所。AI の力と関係ない）

偽の client は送られた中身を見ないので、次の数は道そのものの振る舞い（本物の回でも同じ）。数は下の「回の記録」の回。

- 送った文の氏名・カナ・電話・町名は 0。生年月日は、自由文・書き起こしに和暦（「昭和 NN 年 N 月 N 日」の形）で書くと仮名化の門を通っても残る（自由文・書き起こしの 20 呼び出しの全部）。年齢は前から渡している
- 写真・PDF の読み取りでは、避難先の町名の伏せ字（「（町名）小学校」）が台帳に戻らない。文の道は入れた文から戻す（sourceRestorer）が、写真の道は元の文が無い。差分には伏せ字の印が付き、人が直す前提（「伏せ字の残り」に数える）
- スマホの写真（4032×3024、5 MB 超）は、ブラウザの段で長い辺 2000 に縮めて送れる。生のまま送れば上限を超える
- HEIC はブラウザの段（中身の頭で JPEG・PNG・PDF だけ）で開けず「形式外」
- 4,000 字を超える書き起こしは入れる欄が断る（invalid）。分けて入れる道は無い
- 4 頁の PDF は 3 頁まで読む（PDF_PAGES_MAX）。4 頁目の連絡先・特記は台帳に入らない（「道で運べない値」）
- 置き場の様式本体のうち Word・Excel（.docx・.doc・.xlsx）は「形式外」で読めない。PDF だけが読める
