## 決めた所

- D1 は migrations を流した node:sqlite（lib/db/test-d1.ts。wrangler の --local の表と同じ SQL）を回ごとに新しく作る。同じ命令で同じ入力から始まり、手元の dev の D1 も汚さない。R2 はメモリの偽物
- 正解の側も同じ道（偽の gold の client → 差分 → 保存 → 紙）を通し、AI の側と比べる。道そのものの限り（PDF の 4 頁目・AI の分け方に無い欄）は AI の外れに数えず「道で運べない値」に分けて数える
- 入れる欄の前の台帳は、人が手で入れる物（住所・位置・経路地図・連絡先の名前と電話と順と距離・同意・時計）だけを持つ。AI の分け方で埋まる物（介護・医療・避難・特記・連絡先の夜間と備考）は空。差分の「追加」だけを保存（画面の既定と同じ）
- 1 つの入力の中の呼び出しは直列（askJson は reserve → create → finish の順なので、記録を順に結ぶ）。入力も直列に回す
- 絵の入力は、作った HTML で伏せる所の場所を測り、ブラウザの段で塗ってから送る。塗った所の明るさを読み直して測り、黒くない頁は送らない（記録に「塗った所が黒くない」）
- 正解の表の無い置き場の様式は、読めた欄の数だけ（当たり外れは数えない）。紙は既定で台帳そのままの 1 人だけ刷る（置き場の様式は数が多く、全部の入力で刷ると数千枚になる）。`--paper-all-forms` で全部
- 偽の回の数は台の確かめ用で AI の力ではない（md と index.html に「偽」と出す）
