# T167 訓練の呼び出しの数と、人ごとの筋の残り

頼み文は docs/tasks/T167.md。worktree care72-t167、branch task/t167（origin/integrate/t11-t12 から）。Claude は呼んでいない（偽の client と手で組んだ入力だけ）。評価の 8 回目の記録（drill の r8）は再現のために読んだ。下は数と形だけで、記録の言葉は写していない。

## 原因（r8 の記録で確かめた事）

### 1. 呼び出し（91.4/回、最大 90.7%）

上限の数えの差はほとんど本人役の通話。r8 の 136 往復を、ケアマネの言葉で分けた数:

| 言葉 | 往復 | この作業で |
| --- | ---: | --- |
| 相づち・待って・聞こえますか・何でしたっけ・曜日（台の乱れた文） | 40 | コードの短い返事 |
| また後で電話します・待機の指示（決まった問いと文） | 12 | コードの短い返事。台はそこで切る |
| 中身のある文（機械の音・毛布・いる所の確かめ）と初めての問い | 残り | 本人役のまま |

`--talk-rounds 8` は全部の通話を 8 往復まで回すので、通話の多い回（run-01 は 9 通話）だけ呼び出しが跳ねる。r7 との差（+1.8/回）は通話の数の違いで、上限との比の跳ね方は前からあった。

### 2. 守り drill-left-remain-none（run-04 の 2 件）

門でなく**台の物差しのずれ**。栄養剤の持ち出し忘れの印は、ケアマネの訪問で消える（lib/drill/action-catalog.ts の訪問の clearMarks、T20 からの決まりで actions.test.ts が確かめている）。r8 の人も 24 時間すぎの訪問で印が消え、本人役の文の栄養剤の残りは手元にある物として計算された。門（世界の印を見る）は正しく通し、台の検査だけが世界の到着しか見ずに「まだ置いたまま」と数えた。帳面と言葉の食い違い 2（factWords）はこの同じ 2 件で、他に無い。

訪問で印を消す決まりは変えなかった（ケアマネの手が効く所なので、変えると手の効き目と採点が変わる）。

### 3. 人ごとの筋（審査役の指摘を流れに並べ直した）

| 指摘の形 | 回 | 原因 |
| --- | ---: | --- |
| 避難所へ移ったあと、する事が家で応対している形 | 1 | 赤で家にいるかに答えない連絡は、門のいる所が空で、いる所の言葉を見ていなかった（台の検査と刻みの表の行の道には帳面のいる所の戻りがあった）。家にいる言い方も動詞の一覧の外だった |
| 病院へ移ったと言ったあと、家で業者と電源を迎えた話 | 1 | 家にいる人が病院へ移ったと言う形を見る門が無かった。業者の到着が「手」に数えられ、家の外 → 家の入れ替わりが通った。業者の巡回が家の外の人にも出た |
| 避難所の人への訪問で本人が家にいない様子と、会えた話が続く・避難所の人が家への訪問の礼を言う | 2 | 訪問の指示が「家に着いた」の決め打ちで、門もいる所を家に固定し、手の言い方も「家に向かった」だった。訪問のあと、計画で移った人のいる所を家に戻してもいた |
| 避難所へ移ったあとに迎えの車が着く | 1 | ケアマネの手（台の手の選び方）で移送が来た時に、もう避難所にいる事が帳面に無かった |

| 停電の復旧は 48 時間なのに 21 時間から電気で動く | 1 | 業者が届けた電源を、帳面が「電源が届き、今は電気で動いている」と書き、本人役が電気が戻ったと言った |

### 4. 仮想の回の出来事の無い人（8/10）

世界の種類（WORLD_KINDS）は街と物の事で、人を指す種類は業者の巡回くらいしか無い。T165 の「まだ出来事の無い人」の 1 行があっても、世界には出せる種類が無かった。町の浸水・断水の印は 5 人に付いていたが、それは町の出来事で、その人の筋ではない（数え方は変えていない）。

## 決めた所

- 家の外 → 家の入れ替わりは、来た人や届いた物があっても認めない（helpedFlip）。戻るのは戻った・帰ったの言葉のときだけで、家族の車で帰った人もそう言う形になる。門と台が同じに見る
- 訪問は帳面のいる所へ行く。行き先の分からない人だけ家に着く。訪問で印を消す決まりは変えない
- 審査役の流れから、コードの短い返事と固定の言葉を外した。T165 に続いて入力が変わるので、r9 の審査役の点は r8 と並べて比べない

## 残り・確かめていない物

- 本物の API では回していない（評価の作業者が回す）。呼び出しの数は r8 の並びに当てた見込み
