## 決めた所

- 確認用の事業所は kind demo（offices.kind は CHECK で 3 つに限られ、足すと表の作り直しが要るため）。審査員の入口（demoOffice）は id で引くので、kind demo の事業所が 2 つあっても審査員は確認用に入らない
- 「最初に戻す」は押した人の事業所だけ。毎朝 4 時は両方
- AI の 1 日の上限: 確認用の事業所も kind demo なので同じ上限（AI_DAILY_LIMIT）で、数えはデモ事業所と別。山本の確認で審査員の上限が減らない。代わりに 1 日に呼べる回数の合計は最大で倍になる
- 審査員の名前を「審査員」から「審査員 1」に（経過・撤回・QR の閲覧記録の書き手）
- acct-yamamoto の行のハッシュは消さない（ロールバックで前のコードに戻しても山本が入れるように。今のコードはログインなしのアカウントを断る）
