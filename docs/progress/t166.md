## 頼み事の印（追加の頼み）

- 灰の文字で押せなかった印（「頼み事 移送」）を、進行中の訓練では押せるボタンに（components/drill/AskPick.tsx。アイコン＋文字、押したときは灰色）。全部の種類に同じ部品
- 押すと対応の欄でその本人を選ぶ。手は lib/drill/action-hints.ts の askActions から引く（askPick）: 手が 1 つならその手を選ぶ。2 つ以上はどれにも決めず、候補の欄のその行へ送って枠で示す。手が 1 つでも押せないときは理由の読める候補の行へ。済んだ頼み事で候補に行が無いときは「移送 対応済」の 1 行
- 口は本人の詳細と同じ act-pick の pickAct（ActPick に本人と頼み事の形を足した）。決めるのは対応の欄だけ
- 切り替えの並び（1536px 未満）で経過の面にいるときは、対応の面に替える（DrillPanes。詳細の候補・連絡先の行にも効く）

| 印の出る所 | 形 | 理由 |

| 行の詳細の未対応 | 押せる（進行中） | |
