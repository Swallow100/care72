## 作り

### セッションの形

審査員のセッション（lib/auth/session.ts の judge）に 2 つ足した。どちらも署名の中で、無いのは前と同じ形（古い cookie はそのまま通る）。

| 欄 | 中身 |
| --- | --- |
| sr | 新規事業所の中の役（ケアマネ・医療班・本人・家族）。r が sandbox のときだけ読む。無いのは管理者（b）の役で、T115 と同じ |
| st | その相手の id。ケアマネはアカウント、本人は people、家族は contacts。医療班は持たない |

- デモの 4 つの役に替える（chooseJudgeRole）・「新規事業所」を選ぶ（chooseSandbox）と sr・st を外す。b は残す（前と同じ）
- 役の一覧のフォームの値は `sandbox:care_manager:<id>`・`sandbox:medical`・`sandbox:self:<id>`・`sandbox:family:<id>`（lib/auth/roles.ts の sandboxChoiceValue・parseSandboxChoice）。id は英数字と `-_.` だけ、128 字まで
- Principal に sandboxAdmin（b）を足した。役の一覧に新規事業所の中の役を並べるため、デモの役のときも付く（デモの役のときは確かめていない id なので、使う所の roleChoicesFor が loadSandboxAdmin を通す）

### 壁の確かめ

- 替えるとき（lib/auth/principal.ts の chooseSandboxRole、app/api/auth/role）と、毎回の要求（principalOf → sandboxPrincipal）の両方で、D1 に次を確かめる。外れれば替えるときは 403、毎回の要求では役選択（unselected）へ
  - b が生きている試用事業所の管理者（loadSandboxAdmin。前と同じ）
  - ケアマネ: `office_id` が b の事業所・`role` がケアマネ・`judge_made = 1`・停止していない
  - 本人: `office_id` が b の事業所・一覧から外していない
  - 家族: 連絡先の本人が b の事業所・一覧にいる・連絡先の種類が家族の画面を出せる物（lib/signals/labels.ts の SIGNAL_WRITER_KINDS。家族・支援者・民生委員）。本人の id は行から取る（フォームから受けない）
  - sr と st の形が合わない（医療班に st・本人に st なし・st だけ）も役選択へ
- 試用事業所は審査員のセッションの b からしか入れないので、人と連絡先は事業所が合えば審査員が作った物
- 書き手: ケアマネはそのアカウント。医療班・本人・家族は試用事業所の管理者のアカウント（受け持ち・経過・信号・第三者提供の記録が試用事業所のアカウントに付き、毎朝の掃除で消える）
- 壁の中身（lib/auth/wall.ts の wallOfficeOf）: principal に sandbox が付いていれば、その試用事業所。医療班の検索・受入一覧・受入依頼・QR の見本・受け持ちの一覧・本人のページが試用事業所の人と、試用事業所のアカウントがその場で登録した人だけになる。デモの医療班（wallOffice はデモ事業所）には試用事業所の人は出ない
- 所属なしの引受（lib/custody/takeover.ts）: 試用事業所は試用事業所のアカウントの登録だけ（前はデモの登録）。本物の事業所には試用事業所の登録を出さない・引き受けさせない（wall.ts の sandboxRegisteredSql）
- 毎朝 4 時の掃除（lib/seed/sandbox.ts）: 先に、試用事業所のアカウントがその場で登録した所属なしの人を試用事業所へ移す（SANDBOX_ADOPT_UNAFFILIATED。デモの戻しの adoptUnaffiliated と同じ形）。受け持ちを消すと登録した事業所が分からなくなるので、消す前に流す。足した表は無い
- 医療班の入口（ヘッダーの「医療班」T173、依頼中の面の「受入一覧」T166）は、新規事業所の中では新規事業所の医療班へ（lib/auth/roles.ts の medicalChoiceOf）。デモの医療班へ飛ぶと新規事業所の依頼が見えないため

### 役の一覧

- 役変更（components/ui/RoleMenu.tsx）と役選択の画面（app/login/role）で同じ形。行のまとめ方は lib/auth/role-rows.ts、中身は lib/auth/choices.ts の sandboxChoices
- デモの 4 つ → 「新規事業所」（右に事業所の名前。b が生きていればデモの役のときも）→ その下に地の色を 1 段変えた面で 1 行ずつ
  - ケアマネ: 管理者のほかの、足したケアマネ（停止していない）。管理者は上の「新規事業所」の行
  - 医療班: 受入一覧
  - 利用者ごとに 1 行: 左に名前、右に「本人」と続柄（娘 など）のボタン。同じ続柄が 2 人いれば名前を添える
- 利用者は 20 人まで並べ、越えた分は「ほか N人」（押せない 1 行）
- 今の役は今と同じ枠と太字（下地なし）
