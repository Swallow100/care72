## 決めた所（docs/DECISIONS.md「書類」に案）

- 原本の頁は配信に入れない（計画書・医療要約）。事業所が公式の URL から一度取り込み、版のハッシュが枠を起こした版と同じときだけ使う。様式9 はひな形の寸法で描く（公共データ利用規約）
- 下に敷く頁は 400dpi の PNG（画像にする。PDF のまま敷く道は pdf-lib と日本語の書体を配信に持たせることになるので取らない）
- 医療要約は災害診療記録2018 の 1 頁目だけを敷く。2〜4 頁目は医師の診療の記録で、ケア72 の値の置き場が無い。既往症・予防接種（原本は 2 頁目）・薬の用量と残り・持出品・住まい・関係先は別紙
- 避難先は計画の値なので、災害診療記録の避難先の □ に印を付けず、避難所名の（ ）に「計画」を添えて書く（発災後の居場所と取り違えない）
- 同意の記録の日と人（ケア72 の添え）、選ぶ欄の「なし」（□ が空いていることで分かる）、特記事項の別紙の中身（医療要約）は原本の紙に書かない
- 様式9 のケア72 の欄はひな形に足さず別紙の表に（ひな形の枠を動かさない）
- T85 で頁に収めるために詰めた所（計画書の署名の空き・地域の支援者の欄の名前の列、医療要約の段の間・医師が書く欄の空き、様式9 の列幅）は、原本の枠の紙では原本の頁そのもので、様式9 はひな形の列幅に戻した。原本を取り込む前に出す前からの紙面（T85）は詰めたまま（頁数を原本どおりに保つため）
- 未記入の色付けは帯の未確認と同じ欄（医療要約の原本の枠の紙は、紙が空ける欄を数える medicalUnconfirmed。前からの紙面の帯は台帳の pending のまま）
