## できた物

1. 役を選べる人（lib/auth/wall.ts の canChooseRole）: 審査員と、デモ事業所（kind が demo）の見本のケアマネ（lib/auth/demo.ts の ROLE_SWITCH_ACCOUNT_IDS。山本だけ）。ヘッダーの役変更（components/AppHeader.tsx）と /login/role（app/login/role/page.tsx）がここを見る。選べる役は審査員と同じ 4 つ（ケアマネ・医療班・本人スマホ・家族スマホ）
2. 役の持ち方（lib/auth/session.ts・lib/auth/principal.ts）: 山本のセッション（k が account）に役の印 r を足す（ケアマネの役では付けない。前の cookie と同じ形）。審査員のセッションには替えないので、パスワードの指紋・書き手（accountId）・名前は山本のまま。chooseRole（app/api/auth/role が呼ぶ）は審査員なら chooseJudgeRole と同じ、山本なら印だけ替える。印が付いた cookie は、役を選べるアカウントでデモ事業所が demo のときだけ通す
3. 役を替えた山本の形（principal.ts の switchedPrincipal）: 医療班は書き手の山本のまま（受け持ちは山本のアカウント）、本人・家族は審査員と同じ山田 ハナ・山田の娘（審査員と同じ形を作る所 demoRolePrincipal を共有）。管理者・担当一覧は外す。Principal.switched の印
4. 壁（lib/auth/wall.ts の isWalled）: switched の印があれば審査員と同じ壁。医療班の検索・避難所・受入・受け持ちの一覧・本人のページはデモの人だけ（T81 の所がそのまま効く）。ケアマネの役の山本には印が付かず、今までどおり壁の外（本物のアンケートが見える・事業所の地域を書ける）
5. 本人・家族の頁の送り先（lib/auth/phone-gate.ts・lib/qr/phone-open.ts）: 審査員と同じに。役が違えば役選択、本人の行が読めなければ役選択、山本の本人・家族の役のセッションが切れたら「無効」の頁、本人・家族のリンクを開くと「ログイン中」の 1 枚

変えていない物: 審査員の流れ（chooseJudgeRole はそのまま、審査員の印 JUDGE_LABEL も審査員だけ）、毎朝 4 時の戻し（lib/seed/reset.ts）、固定のアカウントの守り（パスワード変更・改名などは今までどおり断る）、最初に戻す（ケアマネの役の山本だけ）。

戻しを変えなくてよい理由: 役を替えた山本は壁の中なので、受け持てるのはデモ事業所の人（戻しで person_id の範囲ごと消える）と、山本がその場で登録した所属なしの人（登録したアカウントの事業所がデモなので ADOPT_UNAFFILIATED でデモへ移して消える）だけ。テストで戻したあとに山本の開いた受け持ちが 0 件になるのを見た。

テスト: lib/auth/t95.test.ts（16 件）。山本が役を替えられる・入口と中身・次の要求でも同じ役・ケアマネに戻るとログインしたときと同じ形、替えた役で協力事業所の人に届かない（検索・受入・受け持ちの一覧・本人のページ）、ケアマネに戻ると本物のアンケートが見える、ほかのケアマネ（協力事業所・デモ事業所で足した人）と医療班は役を替えられない・役の印を付けた cookie も通らない、審査員は今までどおり、戻しのあと山本の受け持ちが残らない。isWalled から switched を外すと 4 件が落ちるのを見た。

## 問い
