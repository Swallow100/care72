## 監督と本人役を同じ刻みで並べられるか

並べない。固定の筋（大雨・地震・10 分版）の step は 監督 → 本人役 の順で、本人役の入力は監督の差し込みを足した「この刻みの状況」と、差し込みを当てたあとの世界（lib/drill/engine.ts の step、lib/drill/persona.ts の ownIncidents・worldWords）。並べると本人役は差し込み（道路の寸断・透析施設の浸水など）を知らずにその刻みを演じ、反応が次の刻みにずれる。10 分版は 0・3・12・72 時間の 4 刻みなので、12 時間の差し込みに 72 時間で初めて反応することになり、訓練の見せ場が崩れる。差し込みの無かった人だけ先に呼ぶ形も、監督が全域の出来事（停電など）を差し込むことがあり、前もって分からないので取らなかった。仮想モードも 世界 → 本人役 の順で、結末を迎えた人は本人役を呼ばない（世界の返事を待つ必要がある）。
