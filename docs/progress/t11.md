## 決めた所（見直してほしい）

- 家族は 1 回押すだけ。緑の 1 問（どこに いますか）・赤の 4 問・20 秒の音声・録音は聞かない。本人の代わりに答える人はその場にいないことが多く、分からない問いに答えさせない。赤は「家族が「無事じゃない」」で至急の組 1（けが・動けないの組 0 ではない）
- 「分からない（連絡が つかない）」は未知の信号として残す（ケアマネが「つながらない」と入れた物と同じ読み方）。ほかに信号の無い人は灰のまま
- 出どころは連絡先の行の種類から（家族→家族、支援者・民生委員→支援者）。種の山田の隣人（支援者 2）は「支援者が「無事」」
- 経過の payload に答えた連絡先の id を残す（家族の画面で「あなた」と出すため。名前は持たない）
- 経過は決まった言葉だけ。経過の本文はケアマネ・医療班の自由文で、名前・医療の中身が入ることがあるので出さない。診察・配薬・搬送は「医療班が みました」「薬を わたしました」「病院へ 運びました」の言葉だけ
- 家族の画面の経過は新しい順（スマホで最新を上に）
- ケアマネの電話は台帳に欄が無い（T06 の問い 3 と同じ）。番号を作らず、名前と事業所だけ出す。番号が入れば tel: の大きなボタンになる作り
- 平時の画面は本人の 1 枚の 逃げるところ・来てくれる人・持っていく物・電話 だけ（大きく少なく）。逃げるとき・本人の言葉は出さない
- 録音の添付は本人の信号だけにした（`s.source = 'self'` を足した）。家族の信号に本人の録音が付かない
- lib/auth（役・Principal）・lib/triage・migration は変えていない。家族の連絡先の行と本人は T01 の Principal（personId・contactId）のまま
