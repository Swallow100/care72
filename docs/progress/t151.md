## 見つけた事（直す前）

- 地図を使う画面は 5 つ: 担当一覧の右の面と全画面（components/map/CaseMap.tsx の CaseMap・FullMap）、訓練の画面の地図（同じ CaseMap）、事業所の画面の地域の中心と本人のページの位置（components/person/LocationPick.tsx）、本人のページの避難経路の窓（components/map/RouteMap.tsx の RouteEditor）。本人のページの避難の面の経路地図の小さな絵（RouteSceneSvg）は紙に刷る範囲の見本で、押すと窓が開く
- 位置を置く地図（事業所の地域・本人の位置）と避難経路の窓は、作りとしてドラッグを持っていなかった（LocationPick の頭の注に「拡大・縮小は＋−のボタンだけ（引いて動かすは作らない）」、経路の窓は上下左右のボタンだけ）。本番の PC で動かせなかった事業所の地図はこれ
- 担当一覧の右の面は T66 からマウスのドラッグで動く（手元の dev の headless Chrome で直す前のコードを確かめ、80・40px 引いて地図が同じだけ動いた）。指は 1 本だと画面の送りに渡して地図を動かさなかった（2 本のピンチだけ）
- 雨雲（旗 JMA_NOWCAST）の凡例は、気象庁の凡例の画像（max-h-24）・「HH:MM 時点」・出典の長い 1 文（雨雲：気象庁ホームページ（URL）／背景：地理院タイル）を max-w-[60%] の白い四角に入れていた。出典の文が 60% の幅で何行にも折れ、小さな地図の右下の半分ほどを隠す

## 決めた所（案、docs/DECISIONS.md「地図と災害の情報」に書いた）

1. 全部の地図をマウスのドラッグと指で動かし、動かし方は 1 か所（lib/map/drag.ts と components/map/useMapDrag.ts）
2. 画面の送りの中の地図は、ホイールは Ctrl（⌘）＋ホイールか地図を押した後だけ、指は押す前は縦の送りを画面に渡す（横のなぞりは地図）。全画面はいつも地図
3. 位置を置く地図の拡大・縮小のボタンは、ピンが見えていればピンの所を据える
4. 避難経路の窓のズームは段（整数）のまま、ホイールと 2 本の指は量を溜めて 1 段ずつ
5. 雨の凡例は本物の雨雲と訓練の雨で同じ小さな横の帯。雨雲の出典は地図の下の出典の行。気象庁の凡例の画像は使わない
