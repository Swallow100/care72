# T116 地図の雨を降水量の段ごとの色に（Opus 5.5）

T116 作業中（Claude Opus 5.5、11/5 03:0x〜）。worktree care72-t111、branch task/t111（origin/integrate/t11-t12 の 8481aae0 から）。

Claude を使う所・使わない所: この作業は Claude を呼ばない（地図の絵・凡例・ピンの縁と言葉だけ）。雨は色と連絡順（lib/triage）の入力にしない。地点ごとの雨量・危険度も作らない（絵と凡例だけ）。

作業中は気象庁の頁・API・雨雲のタイルに繋いでいない（テストは fetch を偽にして、呼ばれたら落とす）。色の値は気象庁の凡例と同じ値を表に書いたが、本物の凡例の画像と並べて確かめてはいない（下の「未確認」）。
