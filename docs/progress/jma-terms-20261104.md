# 気象庁の情報の利用条件（11/4 01:2x、相談のセッションの調べ）

決め（雨雲・震度の絵も本物の情報に。利用条件を先に読み、だめな物は作らない。災害モードは自動で切り替えず人に押させる。docs/DECISIONS.md「地図と災害の情報」）のための下調べ。公式の一次資料を読んだ結果の要約（引用は短く、言い換え）。

## 結論

- 気象庁の情報は、**加工せず出典を付けて出す**なら、事業所向けの商用まで含めて使える（公共データ利用規約 第1.0版、気象庁「ご利用上の留意事項」で商用可）。加工したら「気象庁「名称」（URL）を加工して作成」と書く。国が作ったように見せない。
- 警報と地震情報の**正式な取り方は防災情報 XML の PULL 型フィード**（登録不要）。
  - 警報: `extra.xml`。2026-05-29 から新しい体系（「レベル3大雨警報」など）。電文は VPWW55〜61、時系列は VPWP50。VPWW53・54 は経過措置（令和10年度に廃止予定）で、11/3 のフィードには新旧両方が載っていた。
  - 地震: `eqvol.xml`。VXSE51 震度速報、VXSE52 震源、VXSE53 震源・震度（観測点ごとの震度）。
  - 高頻度（毎分更新・直近 10 分）と長期（`_l`、毎時更新・数日分）。1 日 10GB 以上の取得は遮断の対象（PULL 型のページ）。
- 雨雲（ナウキャスト）のタイル・`bosai/` の JSON は、気象庁が名指しした文書が無い。一般の条件（二次利用可・出典・加工の明記）が掛かると読めるが、仕様は非公開で予告なく変わりうる。時刻の一覧 `targetTimes_N1.json` は実際に読めた（basetime・validtime は UTC、要素 hrpns）。
- 推計震度分布は原則 最大震度5弱以上で約 15 分後、250m メッシュ。`bosai/estimated_intensity_map/data/list.json` があるが仕様は非公開。値は 1 階級ほど違いうる、メッシュの境界は震度の境界ではない（気象庁の注意）。

## ケア72 でやってよい形

- 警報を、発表された市町村・正式な名前・発表時刻のまま出す。利用者の住所の市町村と突き合わせて「該当の利用者」を並べる（区域をそのまま使う範囲と読む。気象庁が明言した文は無い）。
- ナウキャストと推計震度の画像は加工せずに重ね、凡例も気象庁と同じに。観測点の震度は点で出す。
- **Workers が 1 か所で数分おきに取り、キャッシュして各事業所に配る**（各ブラウザから気象庁を頻繁に読まない）。
- ハザードマップ（静的な想定）と重ねて「浸水想定区域の利用者」を出す（予報ではない）。
- 災害モードの切替は人が押す（警報が出たら「切替」を勧めるまで）。

## やってはいけない形（気象業務法の予報業務・23 条の警報）

- 「○○さんの家は危険」「○時に浸水」のような、特定の地点への読み替え。
- 推計震度を「利用者の家の震度」と断定する。
- ナウキャストの時刻の補間・延長、雨量から独自の危険度を作る、地点ごとの予報（GPV の内挿）を出す。
- 警報の名前や色を借りたケア72 独自の「警報」。
- 各事業所のブラウザから気象庁を直接・頻繁に読む。
- 土砂・洪水・高潮などの予報（特定予報業務。許可を受けても公開サイトに出せない）。

## 出典の書き方の例

- 地図の右下: 「雨雲・推計震度：気象庁ホームページ（https://www.jma.go.jp/bosai/nowc/）／背景：地理院タイル」。色を変えたら「…を加工して作成」。
- 警報の一覧の下: 「出典：気象庁ホームページ（https://www.jma.go.jp/bosai/warning/）、気象庁防災情報XML」
- 設定の「データの出典」: 「気象庁の情報をもとにケア72が編集して表示しています。編集の責任はケア72にあります。最新の情報は気象庁ホームページで確認してください。」

## 代わり

- 国土地理院: 雨雲・震度の実況は無い。背景地図は「地理院タイル」の出典とリンクで使える。
- J-SHIS: 長期の揺れの確率で、今の震度の代わりにならない。
- RainViewer: 2026-01 から無料版はズーム 7 まで・帰属表示必須。市区町村を見るには粗い。

## 分からない所

公共データ利用規約の原文（デジタル庁のサイトから取れなかった）、`bosai/` の JSON について気象庁が言うこと、nowc のページの個別の注記と `bosai/`・jmatile の取得の上限、5/29 以降の `bosai/warning` の JSON の形、観測点の位置の公式な資料。
