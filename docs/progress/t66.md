## 決めた所（案）

1. 0 人の印は「色の無い地の箱」（面の上は面の中の灰 bg-panel2、面の中の上は白）に薄い本文色の言葉。不明の塗りの灰（--state-unknown-fill）は使わない: 0 人の至急が不明に見えないように。箱の大きさは塗りの印と同じで、0 と 1 で並びが動かない
2. 避難計画の内訳（未作成・下書き・同意済・訓練済）も人数の帯と同じ部品なので、同じ形（1 人以上は塗り、0 は灰）になった。前は下書きだけ塗りで、ほかは数に色だった（同じ「そろっていない」の形）。2 番目の状態は色の文字にする決まり（components/ui/Tag の頭の注）とは少し違うが、人数の組は 1 つの形にそろえた
3. 残りの列の印の中の言葉は「超過 1.2 時間」のまま（状態の言葉〔至急・要確認〕を足さない）。行の頭に状態の印があるので
4. 受入一覧の状態の切替に人数を添えた（人数の帯と同じ形にするため、0 の灰が「その状態の人がいない」と読めるように）
5. 小さな地図の全画面の入口を、層の切替の行から、縮小・拡大・全体と同じ行の右端に移した（地図の操作を 1 行にまとめ、どこを押せば広く見られるかを分かる形に）
6. ホイールの知らせ「Ctrl＋ホイールで拡大」は、Ctrl なしで回したときだけ 1.5 秒出す（常設の説明文にはしない）
7. ログインの上は小さな「ケア72」と見出し「ログイン」（印は右のまま）。ヘッダーにも「ケア72」があるので 2 回出るが、T66 の文の「名前は残す」に合わせた
