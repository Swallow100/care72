## T18〜T20 への引き継ぎ（engine の呼び口）

- `step(state, hooks)`（lib/drill/engine.ts）の hooks は `{ persona?: PersonaHook; director?: DirectorHook }`。保存の `advanceDrill(db, scope, id, expected, now, hooks)` と開始の `startDrill(db, scope, scenario, now, hooks)`、API の `stepPost(…, hooks)`・`startPost(…, hooks)` が同じ hooks を受けて step に渡す。route（app/api/drill/[id]/step・app/api/drill）で env から hooks を作って渡す（鍵が無ければ渡さない → 表の固定の安否）
- T18 ペルソナ: `PersonaHook = (input: PersonaInput) => Promise<DrillTurn[]>`。input は 刻み・時刻・本人の id・この刻みのあとの世界・この刻みの状況・前の様子・直前のこの本人へのケアマネの手・想定の表のこの本人の行（fixed、起きること）。返すのは `DrillTurn`（color・source・whereNow・4 問・saying・doing・ai: true・at）。空の配列は連絡なし、投げたら連絡なし（engine が受け止める）。本人 1 人ずつ並べて呼ぶ（Promise.all）。Claude に渡す前に lib/pseudonym を通す（input は id だけで氏名は無い。世界の道路・施設の label も一般の言い方で町名なし）
- T19 監督: `DirectorHook = (input: DirectorInput) => Promise<DrillIncident[]>`。表の出来事を当てたあとに 1 回。返した物のうち 2 つまでを世界に当て（kind は WorldChange の kind）、actor は director、ai: true、reason（判断の理由）は drill_events の payload に残る。出ない本人を指す物は外す。差し込みの kind を表の 6 つに絞る検査は T19 で（今は WorldChange の形だけ）
- T20 対応: `DrillState.actions`（ActionRecord: kind・person・target・at・step）は drills.world の JSON にある。手を打つ API は drill_events に actor care_manager・kind action を足し、drills.world の actions を更新する（読んだ刻みのときだけ。advanceDrill と同じ守り方）。真ん中の「対応」の面（app/drill/[id]/page.tsx の Panel id="actions"）に部品を置く。再生の作り直し（lib/drill/db.ts の loadTicks・replayState）は今 incident と persona_turn しか読まないので、action・result も読むように足す
- T21 着信: 安否の言う事は signals.transcript（drill_id 付き）。録音の再現は同じ行の recording_key に。本番の読み方は drill_id IS NULL で外れる
- T22 採点: 終わった訓練は drills.status = finished。drills.score は空のまま。再生の中身は loadDrillScreen（Claude を呼ばない）。右の列の地図の上に採点の面を足す
- T26 種: 終わった訓練の種は、startDrill と advanceDrill を hooks なしで最後まで回して作れる（同じ形の drills・drill_events・signals になる）
