## 安全とプライバシー（HEAD 5028da1）

### 高
1. **審査員が医療班の役で、ほかの事業所の人を開ける**: lib/custody/search.ts:60,89 は事業所で絞らない、lib/custody/store.ts:37 の受入はどの personId でも受ける、lib/custody/actor.ts:22 は審査員も通す。医療班の役 → /staff でカナ 2 字か生年月日で検索 → 全事業所の人 → 受入 → /people/<id> を同意の範囲で読める・経過を書ける。lib/seed/reset.ts:64-65 はデモの人の受け持ちだけ消すので翌朝も残る。直し: 審査員のときは検索・避難所・受入・QR 受入をデモ事業所の人に限る、毎朝の戻しで審査員の受け持ちを閉じる
2. **審査員が足したケアマネで入り直すと本物のアンケートが見える**: lib/office/scope.ts:33（admin: p.admin || p.judge）で審査員はケアマネを足せ初期パスワードを受け取れる。そのアカウントは judge が外れ lib/survey/store.ts:96 の絞りも外れ、山本の本物の共有リンクと自由記述の答えが見える。作るリンクは本物に混ざる（lib/survey/links.ts:37）。直し: 審査員が作ったアカウントに印を持たせ審査員として扱う、本物のアンケートは作った本人と審査員でない管理者だけ

### 中
3. 所属なしの人の引受（lib/custody/takeover.ts:64-78）: どの事業所のケアマネ（審査員も）も引き受けられ、審査員が引き受けると翌朝の戻しで消える。一覧（:30）はどの事業所にもカナ・年齢・避難所を出す。直し: 審査員はデモのアカウントが登録した人だけ
4. Service Worker の写し（public/sw.js:248-286,306）がログインの終わりを知らない。期限切れ・停止・再発行のあとも通信なしか 4 秒超なら写しを出す。直し: 応答が /login・/s/invalid への転送か 401・403 なら写しを全部消す、写しに期限
5. 写真・PDF は仮名化の門の外（lib/claude/call.ts:61 の添付は検査なし）。台帳の写真は EXIF の無い JPEG なら通す（lib/intake/read-check.ts:15）、隠した数は端末の申告で 0 でも通る（read-form.ts:39）。様式の読み取り（app/api/forms/read/route.ts:29）は塗っていない PDF・PNG をそのまま Opus に。直し: 隠した数 0 は確かめを挟む、様式の読み取りも塗りの画面を通す
6. アンケートの書き込みに上限が無い（リンクの本数 lib/survey/links.ts:258、開いた時刻の印は期限なし lib/survey/token.ts:220、Turnstile の鍵は本番に無い）。直し: 事業所ごとの 1 日の本数、印は 2 時間で切る
7. docs/survey/README.md の 3 節 6 が答えの写しを公開リポジトリへ commit する手順。直し: 自由記述の列を外した写しだけ
