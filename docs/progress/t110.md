## 評価の台（T108）が読む形

- lib/drill/db.ts の `loadJudgeLog(db, officeId, drillId): Promise<JudgeLogRow[]>`。1 行は `{ drillId, action（手の番号）, atMinute, endMinute, as（表の手か null）, judge: FreeJudge }`。打った順。取り消した手は入らない
- `FreeJudge`（lib/drill/action-types.ts）: `{ v: 1, input（伏せた文）, facts（伏せた事実の文）, output: { kind, callee, way, minutes, can, whyNot, text, outcome, reason } | null（鍵なし・失敗・上限）, decided: { as, way, minutes, block }, called }`。名前・住所・電話は入らない（伏せた側だけ）。理由（reason）だけは AI の文を仮名から氏名に戻さずに残す
- HTTP は GET /api/drill/[id]/log?judge=1（ケアマネの役・事業所の中。`{ ok, drill, judges }`）
- エンジンの入口: `act(state, { kind: "free", text, person, contacts }, { free })` は前と同じ形で動く（確かめが無ければその場で 1 回読み替える）。打つ前に読み替えだけ欲しいときは lib/drill/free-action.ts の `planFree(state, input, hook)`

## 決めた所

docs/DECISIONS.md の「訓練」に案（11/5 03 時台）。要点:

- 手は打った時に返事が決まる形のまま（重ねて予約して後でまとめて結果を出す形にしない）。手の分は「手に使った時間を AI も動かして閉じる」進め
- 押せなくするのは世界の返事が事実で外れと決める道と同じ物だけ、元は公表の事実だけ。決まりは開始で選んだ訓練だけ（10 分版と前からある訓練は表の分のまま）
- そのままの手は世界を変えず、本人役が次の区切りで読む。採点は順番に数え、届いたには数えない
- 文の長さ 200 字。自由対応の文は訓練記録に出す（T91 の「紙に出さない」を変える）
- 夜の電話の出る割合を下げた（T59 の「夜の行は足さない」を変える。頼み文の「夜は電話に出にくい」のため）

## 問い

1. 夜の電話の出る割合 ×0.6 と所要の足し分（夜・浸水・出勤遅れ +20、混雑 +5、電池 +10）は訓練の目安で、出典が無い。数字を出典のある物に替えるか、夜の出る割合は外すか（DARK_PICKUP を 1 に）
2. 押せない手（通行止の訪問など）は、決まりを選んだ訓練では空振り（T94）に数える道が無くなる。採点の空振りは前からの記録と、手の途中で事実が変わった手だけになる
3. 10 分版にも決まりを当てるか（今は当てない。審査員の流れと前からのテストを変えないため）
4. 自由対応で読み替えたあと打たずにやめた分も counts.free に数える（10 回の上限）。数えないと読み替えだけを繰り返せる
