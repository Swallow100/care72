## 決めた所（見直してほしい）

- **時計**: ケアマネの時計を分で drills.world に持つ（minute。表の列は変えていない）。刻みに着くと刻みの時刻、手を打つと所要時間だけ進む。左の表のルールの表の「今」はこの時計なので、手に時間を使うと時計の残りが減る（電池・酸素が超過に近づく）。被害状況の停電の経過は刻みの時刻のまま
- **割り込み**: 次の刻みの時刻を越えた手は、その刻みを同じ取引で進める（監督・本人役も走る）。刻みは 0・1・3 時間が近く、そのあとは 3〜12 時間あくので、割り込みは始めの 3 時間に起きやすい。「待つ」の手は足していない（7 つから増やさない。待つのは「進める」）
- **返事の時刻**: 手の終わりの世界で決める。刻みを越えた手は、越えた刻みの表の出来事のあと・監督の前の世界（3 時間に通行止になる伊藤の道は、2:30 に出た訪問なら通行止）。監督がその刻みに差し込んだ物（Opus）は、その手の返事には効かない
- **言い換え**: 刻みを越えた手の返事だけ、その刻みの監督の 1 回で言い換える。越えていない手は固定の文（AI の印なし）。保存した返事はあとから書き換えない（採点が読む物が変わらないように）
- **出る・出ない**: 本人・家族・支援者・民生委員への電話は線（家の電話の不通の印も）→ 出るかの順。「本人が話せない」は「背景の音だけ」と同じ「無言」にまとめた。台帳に番号の無い連絡先への電話は「番号なし」（台帳の穴として採点が拾える）
- **鍵なしの言葉**: 出た人の言う事は、相手と同じ出どころ（本人 ↔ 本人役、家族 ↔ 家族、支援者・民生委員 ↔ 支援者）の最後の安否の言う事、無ければ「はい、もしもし」
- **印を消す表**: 訪問で着いた・受入依頼が受けられた・訪問依頼の人が着いた で、栄養剤の持ち出し忘れと帰宅希望の 2 つだけ消す。家の電話の不通・訪問看護が来られない・透析施設の休止は消さない（人が行っても直らない）。受入依頼は本人のいる所（whereNow）を変えない
- **職員の空き**: 訪問看護への訪問依頼は事業所の職員を使わない（T19 の decideWorldReply と同じ。介護事業所と事業所の職員は使う）。着くまで 40 分、戻るまで 120 分
- **手は安否を作らない**: 通話・訪問で分かったことは signals に書かない（左の表の色は本人役の安否と世界の印だけで動く）。本番の本人の経過（timeline_entries の called）にも書かない
- **行政報告**: 対象を選んでいればその人について、選んでいなければ全体（person null）。退避（自分の避難）は記録だけで、世界も以後の手も変えない（削る順の 2 番目。出向いた先の出来事〔削る順の 1 番目〕は作っていない）
- **手の前の左の表**: 手を打つ要求で、画面と同じ道（loadDrillScreen）でその時の色・順位・理由と優先の並びを作り、action の before に残す（採点の「対応の順番」用。1 要求で drills を 2 回読む）
- **競合**: 手の要求は読んだ刻みと手の数を送り、サーバーは drills.world の写しが読んだときと同じときだけ書く。進めるも同じ（今までの刻みの比べに world の写しを足した）
- **画面**: 対応を状況の上に置いた（押した結果と着信がすぐ下に出る）。対象・手・相手は「選ぶ → 実行」の 2 段（40 分かかる訪問を 1 押しで打たない）。選んだ印は枠と太字、下地は変えない。返事の色: 通話・到着・手配済・受入・報告済・避難済は緑の文字、つながらない・着けない・断られたは黄の文字（次の手が要る）。正解・不正解は出さない
- アイコン: 本人電話は共通の電話、連絡先電話はかける矢印の電話、訪問は地図のピン、訪問依頼はトラック、受入依頼は家、行政報告は役所の建物、退避は盾、着信は受ける矢印の電話（@heroicons/react の 20px の塗り）

## T21 への引き継ぎ（着信の画面と声）

- 手の途中で進んだ刻みの安否は drill_events に kind call_in（actor persona、person_id、step は越えた刻み）で残る。payload は { signal: 安否の signals の id, during: 手の番号 a3, source, color, saying, ai }。言う事は安否の文字起こし（signals.transcript）と同じ
- 画面の今の出し方: 結果（components/drill/ActionLog の LatestResult）の下に「着信」の行、状況の欄の刻みに「対応中 …」と着信の印（CallInMark）。着信の画面に替えるならこの 2 か所
- 電話に出た人の言う事は手の返事（ActionResult の speech・speechAi・pickup。drill_events の result）。声にするのはこの speech（名前は入っていない。仮名は「本人」に置き換え済み）。相手の言い方は ActionRecord の calleeLabel（「家族 娘」）
- 着信を「刻みを越えた手の間の安否」だけにした。進めるで来た安否は今までどおり状況の欄の安否（着信にしない）。どの安否を電話の形にするかは T21 で（本人・家族のスマホを持つかは T18 の persona.reporters）

## T22 への引き継ぎ（採点）

- 手は drill_events の kind action（actor care_manager）と result（actor world か persona）。どちらも payload の id（a1・a2…）でつなぐ。drills.world の actions にも返事つきで全部ある。再生の GET（/api/drill/<id>?step=）にも actions と minute
- action の payload: id・kind・person・target（連絡先の id）・callee（区分）・calleeLabel・at（時間、小数）・atMinute・endMinute・minutes・step・before { person（本人の様子）・marks・staff・phone・roadClosed・triage { color, rank, reason }・ranking（その時の優先の並び、台帳の id） }
- result の payload: id・ok・status（ACTION_STATUS_LABELS の 16）・because・text・ai（監督の言い換え）・speech・speechAi・pickup・cleared（消えた印）・staff（職員の空きの増減）・crossed（越えた刻み）・atMinute
- 「対応の順番」は before.ranking と手の順で比べられる。「市役所への報告の遅れ」は kind report_city の最初の atMinute
- 記録に名前・番号は無い（連絡先の id と区分・続柄だけ）。Claude に渡すときは参加者全員を lib/pseudonym で伏せ直す（calleeLabel の続柄はそのままでよいが、役割名に揃えるなら contactRoles）
