# T125 訓練の想定に合わない物を、どの道でも出さない

T125 済み（Claude Opus 5.5、11/5 13 時台〜15 時台）。worktree care72-t125、branch task/t125（origin/integrate/t11-t12 の 83ac1f77 から）。migration 0030（offices.hazards。足すだけ）。

頼み文は docs/tasks/T125.md。

Claude を使う所・使わない所:

- 使う所: 前と同じ（監督・世界・本人役・自由文の読み替え）。監督と世界の指示の入力に、想定に効くハザード・起きない事・差し込まない種類の行を足しただけ（WORLD_SYSTEM と DIRECTOR_SYSTEM は変えない）
- 使わない所: 想定ごとの表、AI の出力の門（想定と世界の状態に照らして捨てる・直す）、通信の段、連絡の経路、区域の出来事の対象、上の帯の印。色と連絡の順（lib/triage）には触れていない

## ほかの作業が読む名前と形

### 想定ごとの表（lib/drill/fit.ts）

- `FIT_PROFILES: Record<DrillKind, FitProfile>`（大雨・地震。Record の型で網羅）、`SCENARIO_FIT: Record<DrillScenario, DrillKind | "scale">`（仮想は規模）
- `fitKindOf({ scenario, options: { scale } }, world) → DrillKind | null`（仮想は規模 → 世界の出来事 → 未決 null）、`profileOf(kind)`
- `FitProfile`: `hazards`（river_flood・tsunami_flood・landslide・shaking・collapse）、`active`（ハザードが効く条件。大雨の河川の浸水は氾濫か警戒レベル 4 以上、地震の津波の浸水は津波警報の間）、`situations`、`injects.banned`・`injects.words`、`worldKinds.banned`・`worldKinds.only`、`changes`（起きない世界の変化。条件つき）、`words`（起きてはいけない言葉）、`layers`（地図の既定の層）、`radio`（電波不通の時間と区域）
- `changeMisfit`・`wordMisfit`・`injectFits`・`worldKindFits`・`zoneFits`・`fitLedgerHazards`・`zoneActive`・`waterActive`・`fitText`・`forbiddenFor`（評価の台）

### 手の可否と所要（lib/drill/action-terms.ts。T126 が読む）

返す形 `ActionTerm`（minutes・block・targets・adds・pickup）は変えていない。変わったのは中身:

- `TermFacts` に `selfLine`（ok・noCall・noRadio）・`selfMobile`（ok・down・none）・`radioAll`・`officeEvac` を足した。`flood` は「本人の家の区域の浸水が今効いている」に（想定の表の条件。前は津波警報・警戒レベル 4 で全員）
- `TermSource` に `scenario`・`homes`・`officeZones`・`options.scale` を足した（DrillState がそのまま渡る）
- 押せない理由の言葉に `電波不通`・`携帯なし`・`避難中`、所要の理由に `規制` を足した（TERM_LABELS）。電話の `通話不可` は家の固定電話が使えないときだけ（世界の電話の規制では止めない）
- 手の表に `message`（伝言。相手は本人・家族・支援者・民生委員。所要 2 分。返信・既読・未読）を足した（DrillAction・ACTION_CATALOG・ACTION_WAYS の `data`）

### 通信の状態（lib/drill/comms.ts。帯・被害状況〔T128〕・手の可否・着信〔T127〕・本人役が同じ物を読む）

- 通話（音声）: `world.phone`（ok 通常・busy 不安定・down 規制）。規制は全部を止めない（返事の確率と所要で効かせる。PHONE_LABELS.down は「規制」）
- 固定電話: 停電の範囲の家と家の電話の印（lineDown）の家では使えない
- データ（メッセージ・安否のボタン）: 電波不通になるまで届く
- 電波不通: `world.radio`（"down" は監督の差し込み mobile_down の全域の不通。WorldChange `{ kind: "radio"; state }`）か、停電が想定の表の `radio.hours`（24 時間）続いた、表の区域（大雨は洪水・土砂、地震は津波・土砂）の家
- `Home`（区域・町名・固定電話・携帯）は開始の時に台帳から写す（`DrillState.homes`、drills.world の JSON）。`homeOf(ledger)`
- `homeComms(world, profile, person, home, minute) → { landline: ok|out|none; mobile: ok|down|none }`、`selfLineOf`、`dataOk`、`radioDownAt`
- `commsOf(world, profile, homes, minute) → { voice: PhoneState; radio: "ok" | "area" | "all" }`（帯と被害状況の 1 行の元。RADIO_LABELS）
- 72 時間の棒の帯: `Band.kind` に `radio`（view.ts の bandsOf。監督の不通の出来事と、区域の不通〔停電の始まり + 24 時間から停電の終わり〕）

### 連絡の経路（T127 が読む）

- `DrillTurn.via?: Via`（`"call"` 着信・`"button"` 安否のボタン・`"message"` 伝言）。engine が通信の状態から付ける（lib/drill/comms.ts の `routeTurns`・`viaOfTurn`・`viaOf`）。drill_events の persona_turn の payload に入り、読み直しでも残る（db.ts の asTurn）
- 決まり: 本人はボタン（家の電波不通なら届かない）。家族・支援者は言う事があれば着信、通話が規制の間は伝言、言う事が無ければボタン。全域の電波不通なら届かない。届かない AI の安否は外し、世界の gated の `persona:comms:radio`・`persona:comms:none` に数える。表の固定の行は外さない
- `lib/drill/calls.ts` の `isPhoneTurn` は via があれば `call` のときだけ電話の形（1 行）。上限・並び・画面は変えていない
- 経路の無い前からの安否は前の見分け方のまま

### 区域の出来事の対象（T128 が読む）

- `lib/drill/targets.ts` の `targetsOf(incident, { participants, homes?, officeZones?, world? }) → { persons: string[]; office: boolean }`
- 津波は津波の区域、警戒レベルは洪水・土砂の区域、氾濫は洪水の区域、土砂の警戒は土砂の区域（と差し込みの指した人）、地震・電話・電波・断水・天候は全員と事業所、停電は範囲の家（全域なら事業所も）、町の出来事は町の人、本人の出来事はその人
- 事業所の区域は `offices.hazards`（migration 0030、JSON の配列 `[{"kind":"tsunami"}]`）を開始の時に `DrillState.officeZones` に写す。デモ事業所は架空の街の高台で区域なし（NULL のまま。種の行に列を足すと 0030 の前の D1 に種を入れられなくなるため）

### AI の出力の 1 つの門（lib/drill/gate.ts・state-rules.ts）

- 出来事: `screenIncidents(world, incidents, { ..., fit })`。表の外（AI・予定）の出来事の合わない変化・合わない言葉・内部の名前が残る文を捨て、`ruled` に `fit:…`・`internal_id` を残す。engine の監督・世界・刻みの道の仮想の世界の全部で
- 言葉: `gateWords`（文ごとに想定と内部の名前で見る。手の id・相手の区分の英字は画面の名前に置き換え、置き換えられない英字の id が残る文は落とす）、`gateTurns`（本人役の言う事・する事）。通話・往復・訪問の言葉、監督の言い換え、自由対応の 1 文・起きたこと・理由・AI のできない理由も通す
- 捨てた数: `WorldState.gated: Record<"出どころ:決まり", number>`（director・world・persona・free）。drills.world の JSON。評価の台が数える

## 問い

1. 見守依頼の対面の道（相手が同じ町の近所・民生委員なら電話なしで頼む）は作っていない。今は通話の規制の間も見守依頼は電話で打て（所要が伸びる）、全域の電波不通の間だけ家族・支援者・民生委員に頼めない。対面の道を作るか（相手の住所の町と本人の町を比べる）
2. 停電の家の固定電話を全部使えないとした（台帳に固定電話の種類が無いため）。停電でも使える固定電話（電源の要らない電話機）を台帳に持つか
3. 電波不通の区域（大雨は洪水・土砂、地震は津波・土砂）と時間（24 時間）は目安。出典は基地局の停電対策（少なくとも 24 時間）と北海道の地震の止まった基地局の数で、区域の選び方は出典が無い
4. 担当一覧のハザードの「その他」は想定によらず出している（中身が書き足しで種類が分からない）。想定ごとに出し分けるか
5. 事業所のハザードを直す画面は作っていない（デモ事業所は種で区域なし、ほかの事業所は NULL）。事業所の画面の「地域」に足すか
6. 想定の表は訓練の災害の種類（大雨・地震）の 2 行。事業所の災害の種類の台風・土砂・津波は訓練の想定に無いので行を持たない（地図の場面の写し DISASTER_SCENE で大雨か地震の行に写る）。訓練に台風・津波の想定を足すときは表に行が要る（型で落ちる）
