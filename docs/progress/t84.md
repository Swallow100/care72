## 決めた所

- 保存の時でなく、左の表に渡す所（読む所）で当てる。訓練の電話の保存（lib/drill/db.ts の actDrill・heardStatements）は T82 の区画で、手の途中で刻みを越えたときは越えた刻みの本人役の安否も同じ取引で書くので、通話の時点の表を正しく作れるのは読む所だけ。手の前の表の写し（actionPost の before.triage）は越えた刻みの安否を含まず、actDrill を直に呼ぶ道（テスト）も通らない。再生・取消・採点の before も同じ道（loadDrillScreen）を通る
- 断った聞いた安否も signals の行としては残る（本番の電話は信号を書かない。違いはここだけ）。drill_id の付いた信号を読むのは訓練の画面（view.ts）と声（voice.ts。文字起こしの無いケアマネの行は使わない）だけで、本番の表・様式 9・受入（drill_id IS NULL）には届かない。表の規則が変われば再生の判断も一緒に動く（表全体と同じ性質）
- 手（電話）・返事・本人役の言う事・時間はそのまま残す（訓練の電話はかけて時間を使った事実。採点の「届いた手」にも数える）。本番も T82（取り込んだ fbe7df2）から、至急維持の通話は電話の経過を書き、聞いた安否の信号だけ作らない形（uncounted injury、押した時刻までの信号で当てる）になったので、訓練と同じ形。最後の連絡（lastContact）には数えない（本番で信号が無いのと同じ）
- 言葉は本番の injuryRefusal をそのまま使う（「無事 不可（家族が「けが」）」「無事でない 不可（本人が「けが」）」）。色は本番の断りと同じ赤の太字
- 聞いた安否の決め方（heardOf）と本人役に渡す「伝える様子」（tell）は変えない。本人役は「無事」と言い、表は至急のまま、が訓練の中身
