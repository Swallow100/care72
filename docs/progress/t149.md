2. 本人・家族の ID とパスワード（lib/phone/account.ts、app/api/phone/account、migration 0035 の phone_accounts）
   - スマホ入口のリンクで開いたセッションからだけ作れる（作り直せる。1 本人・1 連絡先に 1 つ）。審査員と山本の本人・家族の役、ID で入ったセッション、ケアマネなどは forbidden、同意の決まりに合わない人は consent
   - ID はケアマネの ID と同じ形（英小文字・数字・. _ -、3〜32 字、小文字にそろえる）で、ケアマネの ID・ほかの本人と家族の ID と重ならない（ケアマネを足す時も本人・家族の ID を断る。lib/office/staff.ts に 1 句）
   - パスワードはケアマネと同じ決まり（lib/auth/password-rule.ts: 10 字以上・64 字まで・大文字・小文字・記号）と 2 回の一致。足りない物を並べて返す
   - ログインの欄は同じ（ケアマネの表に無い ID を本人・家族の表で引く。PBKDF2 は 1 回）。セッションは 4 つ目の形 phone（a・pv、180 日。cookie も 180 日）。役は本人スマホ・家族スマホのまま（accountId null、壁は今のまま）
   - 通るのは作った時のリンクの版と時刻が本人の行と同じ間だけ（リンクの期限が過ぎても通る、再発行・一覧から外すと通らない。再発行の確認の窓は「前のリンクと ID は全部無効」）。通らなくなったセッションはログインの欄へ（lib/auth/phone-gate.ts）。「無効」の頁に「ID で ログイン」
3. 準備の欄（components/phone/PhoneSetup.tsx・lib/phone/setup.ts・lib/phone/setup-props.ts、app/me・app/family）
   - ID → ホーム画面に追加 → 通知の許可、の順に 1 つずつ。済むまで出し続け、閉じるはその表示の間だけ。ID の段は「後で」でその表示の間だけ後に回せる
   - ホーム画面の段は前の案内（T44・T51）の言葉と手順をそのまま（iPhone は共有の手順の絵、Android は「追加」か手順、LINE は外のブラウザへ）。入れた印は localStorage にも残し、ブラウザのタブでも済みに。前の部品 components/phone/InstallHint.tsx は外した
   - 通知の段は「通知を 許可」→ 端末の許可の窓 → 購読（サーバーが渡す公開鍵）→ サーバーへ。許可済みの端末は開くたびに送り直す（毎朝の戻しで消えた購読・鍵を替えた配信のあと）。鍵の無い配信は「通知 未設定」、iPhone の Safari の中は「ホーム画面から 開いて」、断った端末は「設定で 許可」
   - 災害モードは安否のボタンの上に 1 行と押せるボタン 1 つ（ID の段は出さない）。安否のボタンはいつも押せる
4. 「大丈夫ですか」の通知（lib/push/、app/api/push、app/api/people/[id]/push、app/office/mode/route.ts、components/list/SafetyPush.tsx、public/sw.js）
   - 依存なし。VAPID の ES256 の JWT（WebCrypto の ECDSA の r‖s をそのまま）と、RFC 8291 の aes128gcm（使い捨ての ECDH・HKDF・AES-128-GCM）。送り先は Web Push の事業者の https の宛先だけ（Google・Mozilla・Apple・Microsoft の名前。端末から来た URL へサーバーが POST するので）。6 つずつ並べて送り、404・410 の購読は消す
   - 鍵は env の VAPID_PUBLIC_KEY・VAPID_PRIVATE_KEY・VAPID_SUBJECT。どれかが無い・形が違う・組でない（試しに署名して公開鍵で確かめる）と送らず「通知 未設定」
   - 送る時: 事業所が平時から災害モードに入った時（lib/disaster/http.ts の modePostEntered。route が応答のあとに waitUntil で事業所の全員へ）と、担当一覧の行の詳細の「安否確認」（ケアマネの役・壁の中・災害モードの間だけ・同じ人へ 1 分に 1 回。結果は「送信 N」「通知先なし」「通知 未設定」「送信済 待機」「平時 不可」。本人の経過に「安否確認 通知」）
   - 通知の文は固定（題「ケア72」、本人「大丈夫ですか」、家族「ご本人は 大丈夫ですか」）。押すと /me か /family（SW でも決まった道だけ。開いている窓があれば移して前へ）
   - 購読は端末ごとに 1 行（同じ端末は後勝ち）。リンク・ID の端末はリンクの版と時刻を持ち、再発行・一覧から外すと届かない。審査員・山本の本人・家族の役は版を持たない（毎朝 4 時に消え、開き直すと送り直す）
   - Service Worker の版を 3 に（写しの決まりは変えていない。SW の中身を変えたら上げる決まり）
5. 種の戻し: 新しい 2 表を消す順（seed/sql.ts の CLEAR_ORDER）・毎朝の戻し（lib/seed/reset.ts）・試用事業所の掃除（lib/seed/sandbox.ts）に
