## ボットの守り

上から順に見る（lib/survey/submit.ts）。

1. 回数: 同じ送信元は 1 時間に 20 回まで（429）。断った送信も数える。送信元は `CF-Connecting-IP` を `SESSION_SECRET` を鍵にした HMAC-SHA-256 にして 32 文字に切った物。生の IP はどこにも残さない（IP は数が少なく素の SHA-256 は総当りで戻せるので鍵を付けた）。1 時間より古い数えは送信のたびに消す。手元の dev は `CF-Connecting-IP` が無いので全部 "local" の 1 つ。
2. 形: Content-Type が `application/json` でなければ 415、本文が 8 KB を超えれば 413（route は Content-Length で先に断る）、JSON でなければ 400。同じ所からの要求か（Sec-Fetch-Site・Origin）も見る（403）。
3. token: 推測できない乱数（crypto の 32 バイト、base64url で 43 文字）。無い・形が違う・使用済み・期限切れ（作ってから 14 日）は 404（頁も API も）。形の違う物は D1 を読まない。
4. 見えない欄（honeypot、名前は `website`）: 画面の外に置き（`absolute -left-[10000px]`）、`aria-hidden`、`tabIndex=-1`、`autocomplete=off`。何か入っていれば 200 を返し、答えも token の状態も残さない（ボットに断られたと気づかせない）。
5. 時間: 頁を最初に開いた時刻を token の行に残し（2 度目は変えない）、そこから 15 秒未満の送信は断る（400「少し待って再送信」）。頁を開かずに API だけを叩いた物も断る。
6. Turnstile: `TURNSTILE_SITE_KEY` と `TURNSTILE_SECRET_KEY` の両方があるときだけ、頁に部品を出し、送信で Cloudflare の siteverify に確かめる（通らなければ 400）。無ければ何も出さない。鍵はリポジトリに書いていない（cloudflare-env.d.ts に名前だけ）。
7. 答えの形: 知らない記号・単一選択に 2 つ・400 字を超える文・文字でない文は 400。どの問いにも答えていなければ 400（未回答）。答えたくない問いは空けてよい。
8. 保存: 1 つの取引で、token がまだ使えるときだけ答えを入れ、入ったら使用済みに。同じ token の 2 度目は 404（答えは 1 行のまま）。

頁は `robots: noindex`、`referrer: no-referrer`（token を Referer で漏らさない）、`dynamic = force-dynamic`。
