## 決めた所（案、docs/DECISIONS.md の「画面」と「地図」に書いた）

1. 雨雲は淡い青灰の面と短い雨の筋。色はライトとダークで同じ 1 組（面 oklch 0.72 0.05 245、筋 oklch 0.50 0.10 252）。気象庁の雨雲の色の段（水色・青・紺・黄・橙・赤・紫）とは別の色で、デモの印と「想定値」はそのまま
2. 帯の縁の破線は外した（雲の形に見せるため、面の縁をぼかす）。帯の境は面の濃さと筋の密度の差で分かる
3. 「未確認 N」は言葉ごと黄の塗りの印（components/ui/Tag の StateTag tone="check"）。components/ui/Tag.tsx の頭の注は前「未確認の数は色の文字（StateText）」だったが、黄の色の文字は細い帯になり、数の前の帯が伝わらなかったので、T87 の紙面の帯と同じ塗りの印にそろえた。表の行の塗りの印は、発災時に「状態」「残り」と合わせて 3 つ並ぶ人がいる
4. 見直しの行の計画の状態（どれも下書き）は色を付けない小さな言葉にした（1 行の黄は「未確認 N」の 1 つだけに）
5. 人数・件数の数そのものには帯も色も付けない（本文色、0 は薄い本文色）

## 問い

2. 訓練の被害状況（components/drill/DamagePanel.tsx）の「警戒レベル ▍4」「職員 ▍0」は数の前の黄の細い帯だが、訓練の作業（T90〜T94）が触っている所なので触っていない
3. 右の面の小さな地図の雨雲の筋を、枠の伸びに合わせて細く短くするか（今は基準の枠の座標で描くので、2 列の 1280 で少し太い）
