## 様式の照らし方

厚労省の頁の通知の別添（docs/SOURCES.md の saigai-kiroku-2018。PDF はリポジトリに入れない）を WebFetch で取り、手元の pdftotext で文字の層を読んだ（抜き出した文字は scratchpad だけ）。1 頁の順は 初診日・医師 → 患者氏名（カタカナ。最初の 7 字をメディカル ID に）→ 漢字等 → 生年月日・年齢・性別 → 保険証 → 電話番号・状態（□健存 □半壊 □全壊）→ 住所 → 避難先１・２（□避難所名 □知人宅 □テント □車内 □その他）→ 連絡先（□家族 □知人 □その他 □連絡先なし）→ 職業 →【禁忌事項等】□アレルギー □禁忌食物 →【特記事項（常用薬等）】□抗血小板薬 □抗凝固薬 □ワーファリン □糖尿病治療薬 □インスリン □経口薬 □ステロイド □抗てんかん薬 □その他 □透析 □在宅酸素療法（HOT）→ □災害時要配慮者（□高齢者 □障害者 □乳幼児 □妊婦 □日本語が不自由 □その他）→【要保護者】□支援者のいない要配慮者等（該当状況 □身体的 □精神的 □社会的 □その他）→ 傷病名 → トリアージタグ → メディカル ID。既往症（□高血圧 □糖尿病 □喘息 □その他）と予防接種（□麻疹 □破傷風 □今期インフルエンザ □肺炎球菌 □風疹 □その他）は 2 頁。

要約はこの順に台帳の値を置く。医療班が書く欄（初診日・医師・保険証・職業・傷病名・トリアージ）は出さない。既往症・予防接種は依頼の順（メディカル ID の前）に置いた。

## メディカル ID のカナの揃え方

様式の決まりは「西暦生年月日 8 桁＋性別＋氏名カタカナ上位 7 桁」で、例は「１９５００９０８M トヨトミヒデヨ」（姓と名の間の空白を詰めて 7 字）。要約では:

1. 生年月日は people.birth_date（YYYY-MM-DD）の数字を 8 桁に（半角の数字。様式の例の全角は字の形の話と見た）
2. 性別は台帳の sex が男なら M、女なら F。その他・未設定なら ID を作らない
3. カナは NFKC（半角カナ → 全角、全角の空白 → 空白）→ 空白と中黒（・）を除く → ひらがなをカタカナに。濁点・半濁点のついた字（ガ・パ）、長音（ー）、小書きの字（ャ・ッ）はそのまま 1 字に数える。上から 7 字を取り、7 字に満たない名前は足さない（ヤマダハナは 5 字のまま）。カタカナと長音のほかの字（漢字・英字）が残れば作らない
4. 3 つのどれかが欠ければ ID は「未確認」と欠けた物（生年月日・性別・カナ）を出す。区切りは入れない（19420418Fヤマダハナ）。紙面は様式の枠に写せるよう、8 桁・M か F（丸で囲む）・7 字の枠でも出す

## 決めた所（案。作者の確認待ち）

- **同意**: 医療班提供が「同意」の人だけ要約を作る。未確認（保留）も作らない（同意のない範囲は出力から落とす、docs/SPEC.md「個人情報」）。発災後に同意なしで渡す道（個人情報保護法 27 条 1 項 2 号）は T16・T23 で、要約はいまは同意だけを見る。同意の期限（expires_at）は見ていない
- **連絡先**: 医療班提供の同意で出す物なので、支援者提供に同意していない 7 加藤 の実施者・緊急連絡先も載せる（支援者提供は「本人の情報を支援者へ渡す」同意で、医療班へ渡す要約には効かないと読んだ）
- **中断注意の印**: 骨格の段 4（インスリン）と段 5（抗凝固薬・ステロイド・抗てんかん薬）の薬に付ける。段 4 の根拠は「手元の分が切れると続けられない」で「急にやめると危ない」の段 5 と言い方が違うが、難病の指針（nanbyo-shishin-2017）がインスリンを中断できない薬に入れているので含めた。台帳の印（interruptionRisk）だけの薬にも印を出すが出典は付けない。種の 5 つの薬は機械の印と台帳の印が一致する（テストで確かめる）
- **家の状態**（健存・半壊・全壊）: 発災後の値で台帳に無いので 3 つとも □ で未確認。横に住まい（構造・階数・住む階）とハザードを小さく
- **避難先**: 計画の避難先 1・2 の名前をそのまま。様式の □避難所名・□知人宅 などの印は付けない（台帳の名前からは種類を決められない。発災後にいる所は医療班が書く）
- **要配慮者**: □高齢者は 65 歳以上、□障害者は手帳があるとき、□その他は 65 歳未満の要介護・要支援と難病。□日本語が不自由は台帳に項目が無いので印を付けない（T03 の問いの候補）。横に要介護度・世帯・認知症・寝たきり・歩行・手帳を事実として添える。認知症と寝たきりは表（lib/triage の toTriagePerson）と同じ定義
- **要保護者**: □支援者のいない要配慮者等は、要配慮者で避難支援等実施者のいない人（5 伊藤）。該当状況（身体的・精神的・社会的）は医療班が見て付ける欄なので印を付けない（認知症 → 精神的 と機械で付けると判定に寄る）。横に実施者の名前か「なし」
- **既往症・予防接種**: 台帳の言葉のまま。様式の選択肢と同じ言葉（高血圧・糖尿病・喘息、麻疹・破傷風・今期インフルエンザ・肺炎球菌・風疹）だけ □ に印、ほかは「その他（ ）」に。「インフルエンザ」だけでは今期かどうか分からないので「その他」。降圧薬から高血圧を立てない（推定しない）
- **様式に欄の無い物**（足した欄）: 機器（人工呼吸器・吸引・経管栄養と時計）、常用薬の表（名前・回数・用量・残り・保管・中断注意）、持出品、特記（本人の言葉・ほかの時計）、関係先（かかりつけ・薬局・訪問看護など。かかりつけが無ければ「かかりつけ 未確認」）、住まい
- **載せない物**: 本人の状態の時計（4 佐藤の「認知症 本人の信号が当てにならない」）。安否の信号の読み方の印で医療の値ではない。認知症は要配慮者の欄に出る
- **未確認**: 台帳の pending は全部、紙面の下の「未確認（台帳）」に理由つきで並べる（主治医・本人に確かめる項目）。薬の残り・避難先・アレルギー・既往症などは、その欄にも「未確認（不明）」と出す
- **根拠の脇**: 1 行目は「欄の順」（災害診療記録 2018）。あとは出てくる行の骨格の段ごとに 1 行（同じ段はまとめる）。新しい文は書かず、TIERS の why と登録簿の題名・発行元・確認の印（いまは全部「未確認」）だけ。医療班・行政の画面には出さない（T23 で受け持ちが広がったときも出ない形）
