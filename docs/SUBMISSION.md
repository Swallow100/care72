## 概要文（下書き）

個別避難計画の作成率は全国 15.1%。能登半島地震では関連死が 527 人に上り、輪島の避難所では薬の情報が手書きのメモで用法用量が欠けていました。

在宅の要介護高齢者を受け持つケアマネは、利用者の薬・機器・家族・避難先を全部知っています。足りないのは、それを市の様式に起こす時間と、災害の最初の 72 時間に医療班の手元へ届ける道です。作者は医学部で学ぶ学生で、家族がケアマネの仕事をしているのを近くで見てきて、この 2 つに気づきました。

ケア72 は、ケアマネの手元の道具です。

- 計画: 話した文・貼った文・写真から Claude が台帳の項目に分け、松山市の計画書・本人の 1 枚・医療班向けの要約・BCP の様式 9 が同じ台帳から出ます
- 訓練: 発災から 72 時間を早送りで回します。架空の 10 人を Claude が演じて赤緑のボタンを押し、電話をかけてきます。終わると機械が穴を数え、Claude が講評を書きます
- 発災時: 本人・家族のスマホに「無事」「無事じゃない」の 2 つのボタン。担当一覧が色と連絡順に並び替わります

安否の色と連絡の順番はコードに書いたルールの表で出し、AI は決めません。この道具は診断・用量・医療助言をしません。Claude には仮名だけを渡し、電話をかけるのはケアマネです。利用者は全員架空です。

コードと文書は Claude Code が書き、作者は決めることを受け持ちました（README の「Claude Code で何が可能になったか」）。
