安否の色と連絡の順番はこの表で出す。Claude は決めない（録音と自由文を 6 つに分けるだけ。分類は理由の 1 行に AI の印つきで添えるだけで、順を動かさない）。
条件は事実（機器・停電・時計の残り・連絡の有無・本人と家族の答え）だけで、症状を点数にしない（問診票を内容を変えずに電子化する側にとどめる。厚生労働省の医療機器プログラムの事例）。
元が「案」の行は docs/DECISIONS.md「色と連絡順」の案で、作者の確認待ち。案のままでは本運用に使わない。
10 人に大雨の筋を流した結果は lib/triage/heavy-rain.test.ts。
「なぜ」はその行がある理由の 1 文で、ケアマネと主治医が見る（本人・家族の 1 枚には出さない）。「出典」は docs/SOURCES.md の登録簿の id で、押すとその出典に飛ぶ。「未確認」は作者がまだ本文を確かめていない出典。

## 読み方

| 読み方 | 元 |
| --- | --- |
| 信号は時刻のいちばん新しい物を使う。今より後の時刻の信号は使わない。信号が無ければ不明 | 決めた所 |
| 本人の報告を当てにしない印（人が台帳で付ける）がある人は、本人（訓練の本人役を含む）の緑を使わない。家族・支援者・ケアマネの緑は使う。赤はそのまま赤 | 案 4 |
| 医療班・行政が避難所で受け入れた知らせは緑の信号と同じに時刻で並べる。いちばん新しければ理由は「到着 避難所の名前」。受け入れより後の赤は赤 | 仕様書（画面 6）・T23 |
| 受入一覧から搬送で外した知らせも緑の信号と同じに搬送の時刻で並べる。いちばん新しければ理由は「搬送 行き先」（行き先が無ければ「搬送」）。退所は「到着」のまま。搬送より後の赤は赤 | T24 |
| 受け入れ・搬送の知らせで緑（行「緑」）になった人の状態の言葉は「無事」でなく「受入」「搬送」。本人がけが・動けないと答えたまま受け入れられることがあるため。色・並び・理由は同じ（言葉だけ）。受け入れの前の本人の答えは経過と受入一覧の行に出す | 案（T78） |
| 受け入れ・搬送の知らせが緑の黄・赤の行（時計・頼り先）に当たったときも、理由で「無事」「無事の報告」と言わず「受入」「搬送」と言う（「受入のあとも 酸素 内蔵電池 2 時間を超過」「受入のあとに電池が切れた、…」「受入・インスリン 残り 24 時間」）。受け入れは本人の報告ではないため。色・行・並びは同じ（言葉だけ） | 案（T80） |
| 時計は停電か発災から走る。停電していなければ停電で走る時計は止まったまま | 仕様書 |
| 「超えた」「過ぎた」はちょうどを含まない。仕様書の「12 時間までは灰」に合わせた | 決めた所 |
| 機器の時計は種類が機器（A）の時計。機器以外の時計は物（B）・薬（C）。本人の状態（D）は走らない | 決めた所 |
| 外の物に頼る時計は頼り先（透析先・配達）のある時計。確認（確認済・未確認）は人が台帳で付け、Claude は付けない | 案 1 |
| 保管（暑さ・冷蔵）と冷蔵の頼り先は時計の「確認」の欄の項目で、表の入力に使わない。インスリンの時計は手元の残りの日数（物の時計）で、冷蔵が切れても走らせない（未開封ならしばらく使える） | 決めた所 |
| けが・動けないが 4 問の答え（ボタン）から来たら理由は「本人が「動けない」」、ケアマネが直した分類から来たら「分類（ケアマネ）: 動けない」（AI の印なし）で、この 2 つだけが赤の最上位の行に当たる。録音・自由文の分類（Claude）から来たら色も順も動かさず、赤の行の理由に「録音の分類（AI）: 動けない」と AI の印つきで続ける。分類が Claude か人かは信号の classified_by で見る。答えにある言葉は分類から、人の分類にある言葉は Claude の分類から重ねない。いくつかあれば「、」でつなぐ | 案・T12・案 10 |

元の「決めた所」は、表と案から読み方を決めた所。docs/PROGRESS.md に書いてある。

## ケアマネの上書き

- 上げる・下げるで手で直せる。理由が要り、経過に残す
- 上書きしたあとに表の色が悪くなったら、上書きは切れて表の色に戻る。上げてあった色より下げはしない
