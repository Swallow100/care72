安否の色と連絡の順位はこの表で出す。Claude は決めない（録音と自由文を 5 つに分けるだけ）。
元が「案」の行は docs/DECISIONS.md の案で、作者の確認待ち。案のままでは本運用に使わない。
10 人に大雨の筋を流した結果は lib/triage/heavy-rain.test.ts。
「なぜ」はその行がある理由の 1 文で、ケアマネと主治医が見る（本人・家族の 1 枚には出さない）。「出典」は docs/SOURCES.md の登録簿の id で、押すとその出典に飛ぶ。「未確認」は作者がまだ本文を確かめていない出典。

## 読み方

| 読み方 | 元 |
| --- | --- |
| 信号は時刻のいちばん新しい物を使う。今より後の時刻の信号は使わない。信号が無ければ未知 | 決めた所 |
| 本人の報告を当てにしない印（人が台帳で付ける）がある人は、本人（訓練の本人役を含む）の緑を使わない。家族・支援者・ケアマネの緑は使う。赤はそのまま赤 | 案 4 |
| 時計は停電か発災から走る。停電していなければ停電で走る時計は止まったまま | 仕様書 |
| 「超えた」「過ぎた」はちょうどを含まない。仕様書の「12 時間までは灰」に合わせた | 決めた所 |
| 機器の時計は種類が機器（A）の時計。機器以外の時計は物（B）・薬（C）。本人の状態（D）は走らない | 決めた所 |
| 外の物に頼る時計は頼り先（透析先・冷蔵・配達）のある時計。確認（確認済・未確認）は人が台帳で付け、Claude は付けない | 案 1 |

元の「決めた所」は、表と案から読み方を決めた所。docs/PROGRESS.md に書いてある。

## ケアマネの上書き

- 上げる・下げるで手で直せる。理由が要り、経過に残す
- 上書きしたあとに表の色が悪くなったら、上書きは切れて表の色に戻る。上げてあった色より下げはしない
