# 動画の素材の一覧と作り方

[PLAN.md](PLAN.md) の場面に要る物。録画の番号（R01…）と図の番号（F1…・G1…）は PLAN.md と同じ。撮り方の手順は [SHOOTING.md](SHOOTING.md)。

決まり:

- 権利のある物だけ。期間中（11/2 12:30 以降）に作った物か、ライセンスを確かめた物。確かめた物は下の表に出典・ライセンス・確かめた日を書く
- 画面の利用者は全員架空（デモ事業所の 10 人と松本 ミツ）。実在の人・事業所・同僚の名前を、画面にも音にも入れない
- 素材のファイル（録画・声・音楽・生成画像）はリポジトリに入れない（`video/.gitignore`）。置き場所は `video/public/` の下で、別にリポジトリの外へ写しを取る。リポジトリに入るのは、この一覧と編集の枠のコードだけ

## 置き場所

置き場（素材を置く所）と読み場（Remotion が読む所）を分けた（T43）。置き場に置いて `npm run scan` を流すと読み場へ写る（同じドライブなら hard link）。

```
video/assets/rec/R10-1/00001.jpg …    録画の連番（番号-何回目。同じ番号は一番大きい回を使う）と markers.json
video/assets/voice/N01.wav …          作者の声（あればこちらを使う）
video/assets/voice-tts/N01.wav …      仮の声（tts-placeholder.ps1 が作る）
video/public/footage/R02/00001.jpg …  （読み場）録画の連番
video/public/audio/narration/N01.wav …（読み場）ナレーション
video/public/audio/app/              アプリの音を録画から抜いた物
video/public/audio/music/            音楽
video/public/images/                 作者の素材・生成画像
```

全部 `video/.gitignore` で外してある。元の録画（.mkv・.mp4）は `video/raw/`（同じく外す）か、リポジトリの外に置く。
