# 3 分動画の絵コンテ

提出の 3 分動画（YouTube）の構成。最終審査はこの動画だけが流れる。台本の正は [SCRIPT.md](SCRIPT.md)、素材は [MATERIALS.md](MATERIALS.md)、撮り方は [SHOOTING.md](SHOOTING.md)、編集の枠は `video/`。

- 長さ 3:00 ちょうど（180 秒）、1920×1080、30fps、音は -14 LUFS。受賞作の動画は 3 本とも 176〜182 秒だった（[REFERENCES.md](REFERENCES.md)）
- 構成の順: 自己紹介（軽く）→ 3 本立てを一言ずつ → 作った経緯（数字・自分・家族のケアマネ）→ 道具の中身（計画 → 訓練 → 発災時。ここが本体）。そのあとに Claude の使い方・数字・締め。docs/SPEC.md の「3 分動画の筋」（自己紹介 → 経緯 → 計画 → 訓練 → 発災時 → 数字）を土台に、この順に並べ替えた
- 出し方はテーマ 1（その世界に身を置いてきた人だからこそ見えた足りないもの）。冒頭はテーマ 1 の 1 案だけ書く
- N04 は使わない。N08（能登の関連死）と N09（輪島の手書きのメモ）は冒頭の組み替えで外した。どちらも ID は振り直さない（欠番）。作者について言うのは docs/SPEC.md の「立ち位置」にあることだけ（内側にいるのは協力してくれるケアマネージャーで、作者ではない）
- 通しの主役は架空の利用者の山田 ハナ（84 歳、要介護 3、在宅酸素）。計画で台帳を作り、訓練で娘から電話が来て、発災時に一覧の一番上に上がる。3 つの段が同じ人と同じ台帳でつながることを、1 人で見せる
- ナレーションの文の ID（N01〜N30）は SCRIPT.md と `video/src/timeline.ts` と同じ。文を直すときは 3 か所とも直し、`video/` で `npm run check` を流す（食い違いと、秒あたりの字数の多すぎを見る）

## 守ること（動画の全部に）

- アプリの画面は本物の録画だけ。編集で画面を描き直したり、動きを作り物で足したりしない（捏造にしない）。画面に無い物は、アプリの枠の外に「図」として描き、図だと分かる形にする。README の画面も本物のスクリーンショットだけ。
- 映すのは期間中（11/2 12:30 以降）に作った物だけ。ケア72 の画面（care72.app か手元の dev）、このリポジトリの端末の画面、編集で描く図と文字。キックオフ前の画面の見本、他のアプリ、他のプロジェクトの画面は映さない
- 画面の利用者は全員架空（デモ事業所の 10 人と松本 ミツ）。アプリの画面が映る間は、画面の隅に小さく「利用者は架空」を出す（数字の画面には出さない。出典のある数字まで架空に見えるため）
- 審査員の ID とパスワード、ログインの画面、ブラウザの保存したパスワードの欄を映さない。ログインは撮影の前に済ませる
- 「診断」「判定」「重症」「病気がわかる」を、声にも字幕にも図にも出さない。赤は「至急」（連絡の順の言葉）。灰は「不明」
- Claude の出力（台帳の欄の分け方、問い返し、本人役・家族役、監督、講評、録音の分類）は、画面の「AI」の印が映る形で見せる
- 言い過ぎない。「高齢者の災害医療を変える」とは言わない。言うのは 2 つの数字（計画 1 件にかかるケアマネの時間、避難所に着いた最初の 72 時間に医療班の手元に情報がある割合）で、測った物だけを測った範囲で出す。測っていない物は「まだ測れていない」と言う
- 編集で足す図・時計・枠は、アプリの画面と見分けが付く形（アプリの枠の外に置く、線と色の付け方を変える）にする。アプリに無い機能をアプリの画面のように見せない
- 編集の見た目は下の「色の決まり」（青と白）。形は CLAUDE.md の「画面の決まり」に合わせる（グラデーション・光る影・ピル型・字間・絵文字・斜体・番号のラベル・等幅のラベルを使わない）

## 色の決まり

青と白のコントラスト。白地に濃い青の字と面、青地に白の字と面、の 2 つを場面で切り替える。話の段（S1〜S3・S8・S9）は青地、道具の段（S4〜S7）は白地。使う色は澄んだ青 2 段（濃い青 #1453c8、1 段明るい青 #5a8ee8）と白、白に青を少し混ぜた面（#e7effc）だけ。強調には意味色の赤（至急 #c0292b）と緑（無事 #1d7a45、どちらもアプリと同じ値）だけを使い、ほかの意味（要確認・不明）は青の字で書く。グラデーション、光る影、黒を混ぜた濁った青は使わない。字幕・数字・見出しもこの 2 色: 青地では帯を敷かずに白い字、白地（録画の上）では濃い青の帯に白い字（半透明にしない）。書体はアプリと同じ（英数字は Inter、日本語は端末の書体）。アプリの画面の録画はアプリの色のまま（編集で色を変えない）。見本は [sample-white.png](sample-white.png) と [sample-blue.png](sample-blue.png)（`video/` の雛形から書き出した 1 コマ。素材が無い所は仮の面）。色の値は `video/src/theme.ts`。

## 演出

豪華にするが、画面の中身を隠さない。豪華さは効果でなく、間の取り方・枠・字の大きさの段・細かな部品で出す。

- 置き場所: 上から 見出しの帯（道具の段 S4〜S7 だけ。段の名前・72 時間の線・利用者は架空）→ 舞台（1680×840。録画・図・文字は全部この中で真ん中にそろえる）→ 字幕の帯。出典は舞台の左下、「イメージ」は右下
- 枠: パソコンの画面の録画は「窓」（上に画面の名前の帯。薄い青の地では青の帯、青地では白の帯）、本人・家族のスマホは「スマホ」（青い縁）。モデルの名前は窓の帯の右に。URL の欄やボタンのような、アプリに無い物は描かない
- 切り替え: 絵と絵は 10 コマ重ねる。地の色が変わる所は地も 10 コマで混ぜる
- 出る動き: 下から 18px 上がりながら 14 コマで濃くなる。並ぶ物（表の行・紙面・言葉）は 4 コマずつずらす。数字は数え上げ、棒は伸びる、線は引かれる。跳ねる動き・回る動きは使わない
- 囲み: 録画の上に細い線（4px）と、囲みに付けた短い名前（2〜4 字。至急の行だけ赤）。位置は撮った録画のコマで測る（撮り直したら測り直す）。画面が動いている間は出さない
- 押した所: 撮るときに押した所を覚え（record-lib.mjs の taps）、編集で 0.6 秒の輪を出す
- 字幕の行: 28 字を超える文は、真ん中に近い「。」（無ければ「、」）の後で 2 行に分ける（語の途中で折らない）。文の中に「／」を書けばそこで分ける

- 寄り: 録画は 2560×1440 か 1920×1080 で撮り、編集で読ませたい所に寄る（縮めて全体を見せるより、寄って 1.5 秒止める）。寄る前後に 0.4 秒の動き
- 強調の 3 つの瞬間（電話が鳴る、一覧が並び替わる、録音）は、音楽を引いて、動きを 0.5 倍に落とし、前後 1 秒の間を取る
- 囲み: 見せたい所は細い線で囲む。色は青（至急の行を指すときだけ赤）。光らせない、影を付けない（上の「囲み」）
- 通しの印: 画面の上に細い 72 時間の線を編集で置く（S4 は空、S5 は早送りで進む、S6 は発災からの時間）。アプリの 72 時間の棒と取り違えないよう、アプリの枠の外に置く
- 字幕: 日本語は字幕の帯に大きく、帯の面は敷かず地の逆の色の字（青地に白、薄い青の地に青）。英語はその下に小さく
- 話の段の文字（11/4）: 文字を主役にし、声が強く言う 2〜4 句だけを、声がその言葉を言う所で 1 つずつ出す（文の全部は字幕の帯にあるので、舞台に同じ文を 2 回書かない）。強弱は字の大きさの段（176・96・64・44px）と行の置き方で付ける。新しい行が出るとかたまりは上下の真ん中を保って上へ滑り、前の行は小さな字の色に下がる（残す言葉は下げない）。強調する行は左に 6px の帯。動きは「出る動き」と同じ物だけで、1 字ずつ打つ動き・跳ねる動き・行ごとに書体を変えることはしない。時刻は声から決める（`video/scripts/scan.mjs` が声の区切りを測り、`video/src/voice.ts` が文の「、」「。」の区切りに当てる）。作者の声に替えたら `npm run scan` で合わせ直す。言葉は `video/src/timeline.ts` の cues に書き、文に無い言葉は `npm run check` が止める
- 書体: アプリと同じ（英数字は Inter、日本語は端末の書体。書き出す Windows では Yu Gothic UI）。本人・家族のスマホの文字を引用するときは BIZ UDPGothic
- 生成画像（使うなら）: 図・象徴的な絵・背景だけ。人の写真風は使わない。MATERIALS.md の「生成画像・生成動画」に書いた物だけ
- 背景の生成動画: S1・S3・S8・S9 の背景だけ。物・風景と人の手元・後ろ姿まで、顔なし。強くぼかして色を抜き、隅に「イメージ（AI 生成）」。一覧と指示文は BACKGROUND.md
- 音: 音楽は自作か、ライセンスを確かめた物（MATERIALS.md）。効果音は控えめに。アプリの音（着信・問いかけ・録音）が鳴る所は音楽を下げる
