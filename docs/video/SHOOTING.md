## 画面の設定

| 物 | 設定 |
| --- | --- |
| 解像度 | 画面が 2560×1440 なら 2560×1440 で撮り、編集で 1920×1080 に寄る（寄っても字がぼけない）。1920×1080 しか無ければ 1920×1080 で撮る |
| Windows の表示の拡大 | 100%（125% だとアプリの密な表が折り返し、見本と違う形になる） |
| ブラウザ | Chrome の撮影用の新しいプロフィール（ブックマークの帯・拡張・保存したパスワード・履歴の無い物）。F11 の全画面で撮る。PC の画面は拡大率 110%（YouTube で表の字が読める大きさ。崩れたら 100%） |
| ライトとダーク | 全部ライトで撮る（OS をライトに）。場面ごとに変えない |
| スマホの画面 | 実機（本人のスマホ・家族のスマホ）の画面の録画が一番。無理なら PC の Chrome を幅 390・高さ 844 の別の窓で開く（デベロッパーツールの枠は映さない） |
| カーソル | Windows の「マウス ポインター」の大きさを 2 に。押す所は編集で丸の印を足す。使わないときは画面の隅へ |
| 知らせ | Windows の集中モード、スマホのおやすみモード。ほかのアプリを閉じる |
| 録画の道具 | OBS Studio。出力 30fps（スクロールが多い所は 60fps で撮って編集で 30fps）、画質は CQP 18 前後、形式は mkv（撮ったあと mp4 に remux）。音はデスクトップの音とマイクを別の音の線に |
| 名前・パスワード | ログインは撮影の前に別に済ませる。ログインの画面・審査員の ID・パスワードの欄が映る録画は使わない（撮れてしまったら消す） |

## 各場面の手順

### S6 発災時（R10・R11・R12、3 つの画面を同時に）

始まりの状態: デモ事業所の種は大雨の最中で、山田にはもう赤の安否がある。ライブで「不明 → 至急」に上がる所を撮るため、いったん平時にしてから大雨に切り替える（安否は発災から今までの物だけを読むので、切り替えた時刻より前の種の赤は数えない。lib/disaster/triage.ts）。この動きは 11/4〜11/6 の試し撮りで手元で確かめる。

1. 撮影の前: 事業所の画面で「最初に戻す」→「平時に戻す」。3 つの窓でログインと役の選択を済ませる（ケアマネ・家族スマホ・本人スマホ）
2. 録画を始める（3 つとも）。手を叩くか画面を 1 回押して、編集で 3 つの頭を合わせる印にする
3. ケアマネ: 事業所の画面で「大雨」を押す → 確認の窓（災害モードへの切替。T79）で「切替」→ 警戒レベル 4、停電は地区「かわなぎ町」と停電開始（地区のときは停電開始が要る。空だと「停電開始 未入力」で保存されない）→ 保存。事業所の画面の右の列に「ID yamamoto」（ケアマネのログインの ID）が出るので、画面の左だけを映すか、編集で左に寄る
4. ケアマネ: 担当一覧へ。発災時の表と上の人数が出るのを 3 秒待つ。山田は不明
5. 家族スマホ: 「お母さん（山田 ハナ）は 無事ですか」→ 赤
6. ケアマネ: 一覧で山田が一番上に上がるのを待つ。発災時の一覧は 1 分ごとに読み直す（ヘッダーの AutoRefresh）ので、赤を押してから最長 1 分かかる。手元の試し撮りでは、田中（要確認）の下の 2 番目から一番上へ上がった。上がったら 3 秒そのまま
7. 本人スマホ: 赤（無事じゃない）→ 1 画面に 1 問で、押すたびに答えが送られる（lib/signals/phone.ts）。「けがは ありますか」で「ある」を押すと、「動けますか」だけを聞いて定型文と録音に進む（T69b）。答えを 1 つでも押した人には声の問いかけが出ない（T77）ので、**声の問いかけを撮るときは、赤のあと何も押さずに 20 秒待つ**（問いと選択肢を読み上げ、10 秒ずつ聞く）。手元の R12-2（11/4）は「けが ある → 動けない」を押した形
8. 本人スマホ: 声の問いかけが流れたら、スマホに向かって作者が「いたい……うごけない」と言う（周りの音が入ってよい）。30 秒で送られるのを待つ
9. ケアマネ: 山田の行の左の開くボタン（▼）で行の詳細を開く（名前を押すと右に本人のページが開く）。理由の 1 行、録音の再生、文字起こし、分類の AI の印と「分類修正」、「順番変更」の欄（詳細の右）を順にゆっくり見せる
10. ケアマネ: 電話を押す → 番号の画面 → 戻って「不通」か「通話」の記録
11. 録画を止める

失敗しやすい所:

- 一覧の並び替わりが自動で来ないとき: 画面の更新の仕組みを試し撮りで確かめ、来ないなら再読み込みの前後を撮り、編集で 0.5 秒の動きでつなぐ（アプリに無い動きを足したように見せない。並び替わる前と後は本物の画面）
- 分類が「不明」になったとき（確信が低い）: そのまま使ってよい（赤 ＋ 不明は赤）。N24 は変えない
- 録音にほかの人の声やテレビの音が入ったら撮り直す（実在の人の声を入れない）

### S4 計画（R02〜R06）

1. R02: 担当一覧で山田の行 → 本人のページが右に開く。上の段で 2 秒止める（84 歳、要介護 3、酸素、残り時間）
2. R02: 入れる欄の「話す」を押して、架空の内容を話す（例: 「ワーファリンはあと 10 日分あります。夜は娘さんが車で来られます。2 つ目の避難先は娘さんの家です。」）。山田の未確認の 3 つ（ワーファリンの残り・夜の支援者・避難先 2）を埋める文にする。実在の人・場所の名前を言わない
3. R02: 欄が埋まり AI の印が付くのを待つ。問い返しが出たら答える。変更点を確かめて保存
4. R03: 書類から松山市の様式 → 2 頁をゆっくり下へ
5. R04: 本人の 1 枚 → 表と裏
6. R05: 医療班の要約 → 特記事項（常用薬等）・中断注意・メディカル ID・根拠の行で止める
7. R06: 様式の読み取り → 内閣府の様式例の写真を上げる → 対応表が出るのを待つ（数十秒。待つ所は編集で詰める）→ 欄の AI の印と自信 → 差し込んだ紙面

失敗しやすい所: Web Speech が止まる（長い無音）。止まったら言い直す。話した文は字幕にそのまま出るので、言い間違えたら撮り直す。
