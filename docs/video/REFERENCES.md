# 過去の受賞作の動画の形

Anthropic と Cerebral Valley のハッカソン（Built with Opus 4.6・4.7、2026 年）の受賞作の 3 分動画を見て、長さ・構成・最初の 10 秒の作りを取った。ケア72 の絵コンテ（[PLAN.md](PLAN.md)）はこれに合わせた。

調べた日: 2026-11-03。受賞作の一覧は公式の記事（[Built with Opus 4.6 の受賞作](https://claude.com/blog/meet-the-winners-of-our-built-with-opus-4-6-claude-code-hackathon)、[Built with Opus 4.7 の受賞作](https://claude.com/blog/meet-the-winners-of-built-with-opus-4-7-claude-code-hackathon)）から。

## 調べ方と限り

- 長さは YouTube の動画の頁の値（lengthSeconds）。
- 構成は、動画の決まった時刻（0.5・3・6・9・12・16・20・26・35・50・70・95・120・145・160・170・175 秒前後）の 1 コマずつを並べて見た。声と字幕の中身は取れていない（字幕の取得は断られた）。だから下の「構成」は画面の移り変わりから読んだ物で、何を話しているかは確かめていない。
- 作者は撮影の前（11/4〜11/6）に、下の 3 本を音つきで通して見て、この表を直す。

## 構成（3 本）

### CrossBeam（4.6 の 1 位。弁護士が作った、住宅の許可の手直しの道具）

| 秒 | 画面 |
| --- | --- |
| 0〜12 | 建築の現場の絵（描いた絵、色の付いた地）。同じ絵が続く |
| 16〜26 | 道具の画面が出始め、作者の姿 |
| 35〜50 | 書類（手直しの通知の文書に印を付けた物） |
| 70〜145 | 道具の画面（表、文書） |
| 145〜160 | 冒頭の絵に戻り、名前の画面 |
| 170〜179 | 作者が話す |

形: 描いた絵で課題の場面を先に見せ、道具の操作は真ん中、最後に作者。

### PostVisit.ai（4.6 の 3 位。循環器の医師が作った、診察のあとの患者の道具）

| 秒 | 画面 |
| --- | --- |
| 0〜6 | 白衣の作者が診察の場にいる |
| 9〜20 | 検査室・病棟の場面 |
| 26〜70 | 作者が机で話す、道具の画面が混ざる |
| 95〜145 | 道具の画面（PC とスマホ） |
| 160〜178 | 作者と道具 |

形: 作者が自分の仕事の場にいる姿から入り、「その世界の人が作った」を最初の 10 秒で見せる。道具は後ろの半分。

### TARA（4.6 の Keep Thinking 賞。道路の技術者が作った、道路の投資の評価の道具）

| 秒 | 画面 |
| --- | --- |
| 0〜9 | 大きな数字 1 つ（不足の額）と、下に小さな数字 3 つ。濃い地 |
| 12〜16 | 「足りないのはお金でなく、準備」の言い直し |
| 20〜26 | 誰の得になるか |
| 35 | 道具の名前と一行 |
| 50〜145 | 道具の画面（地図、車載の映像、表） |
| 160〜170 | 出てきた報告書 |
| 175〜180 | 前と後の時間（数週間 → 数時間）の大きな数字 |

形: 最初の 10 秒は大きな数字で課題の大きさ、最後は前と後の時間の数字で締める。

## 受賞作に共通していたこと（公式の記事から）

- 作った人が、その仕事の現場の人（弁護士、医師、道路の技術者、電子機器の修理、大工の見習い、教員）。課題は自分の仕事から出ている
- 人が最後に判断する作り（医師の監督の下、法的な文書を人が確かめる）
- 3 分動画は思ったより時間がかかる。4.7 の受賞者の 1 人は「It takes way longer than you think to produce a 3-minute video」と言い、次は丸 1 日を動画に取ると話している（[Built with Opus 4.7 の受賞作](https://claude.com/blog/meet-the-winners-of-built-with-opus-4-7-claude-code-hackathon)）
