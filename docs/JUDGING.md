# 審査基準と作品の対応（11/3 作成、提出まで更新）

運営がキックオフで共有した審査基準の全項目を、作品のどこで満たすか・何が足りないかで並べる。満点を取るつもりで、足りない物は作業（docs/tasks）に落とす。「どこで」は 作品（動く物）・README・動画・提出書類 の 4 つ。

## 提出の形（11/8 20:00）

- 提出書類: プロジェクト概要（テーマ 1）、動画の URL、リポジトリ、公開デモの URL（https://care72.app）と審査員のログイン（ID とパスワードはここにだけ）
- README の先頭 5 行: 何か、入口、役の選び方、できること、ログインは提出書類に
- 動画: 期間中に作った画面だけ。架空の 10 人。審査員のログインを映さない
