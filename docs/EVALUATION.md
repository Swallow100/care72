# 評価の数字

数字は 3 つ（docs/SPEC.md「評価」）。人が数える 2 つ（転記の欠け・訓練の穴）を主にし、機械が数える 1 つ（順番の一致）は弱い数字として添える。比率より件数で書き、母数を隠さない。

**11/3 18:2x の時点で、3 つとも未測定。11/4 05:4x（T75）の時点でも未測定。** 下の「結果」の欄は測ってから埋める。README には測った物だけを件数で写し、測っていない物は「測定中」と書く。数字を作らない・丸めない・見込みを書かない。

## 1. 医療班の様式への転記の欠け（主）

| 項目 | 中身 |
| --- | --- |
| 何を数えるか | 医療要約（lib/forms/medical-summary.ts。台帳の値を災害診療記録 2018 の順に並べただけの 1 枚）から、災害診療記録 2018（一般診療版）の欄を埋めたときに、埋まらなかった欄の数 |
| 見る欄 | 常用薬・要配慮者・禁忌の欄を主に（docs/SPEC.md「評価」）、基本情報の欄の全部。医師が書く欄（初診日・医師・傷病名・トリアージ）は空欄の決まりなので数えない |
| 人 | 架空の 10 人（デモ事業所）。医療班への提供に同意していない人は要約が出ないので、出た人だけを母数にし、出なかった人の数も書く |
| 誰が | 作者。できれば地域医療の教員 1 人。2 人なら別々に数えて、食い違った欄も書く |
| 比べる物 | 同じ 10 人を、要約なしで台帳の画面だけから写したときの欠け（できれば） |
| いつ | 11/4〜11/7（訓練とは別の作業） |
| 母数 | 10 人以下 × 欄の数。小さい |
| 結果 | 未測定 |

## 2. 訓練 1 回目 → 2 回目の穴（主）

| 項目 | 中身 |
| --- | --- |
| 何を数えるか | 協力事業所のケアマネが ケア72 の訓練を回したときの穴の数。穴は 3 種類で、どれも訓練の終わりに機械が数える（lib/drill/score.ts） |
| 穴 1 条件に達した人 | 走り出した時計（酸素の内蔵電池・透析まで・薬の残りなど、ルールの表と同じ時計）が訓練の終わりまでに切れ、切れる時刻までにその人へ届いた手（通話・到着・手配済・受入）が 1 つも無かった人の数 |
| 穴 2 様式 9 の空欄 | 平時の様式 9 の参加者の行で、計画に要る欄の空き |
| 穴 3 市役所への報告の遅れ | 行政報告が届いた最初の時刻（期限は決めていないので時間だけ）。届かなければ未報告 |
| 1 回目と 2 回目の間 | 1 回目の講評と穴を見て、台帳・様式 9 を直す。直した所を書く |
| 誰が | 協力事業所の職員（ケアマネ）と 作者。架空の 10 人だけで、実在の利用者の記録は使わない |
| いつ | 11/6・11/7 |
| 想定 | 1 回目と 2 回目で同じ想定（10 分版か大雨の想定）と同じ設定（訓練の「設定」の参加者・職員の数・夜間発災。11/3 夜に足した）。違えたら書く。取り消した手の数は訓練記録の紙面に「取消 N 件」で出るので、結果に添える |
| 母数 | 事業所 1・ケアマネ 1〜数人・訓練 2 回。小さい |
| 結果 | 未測定 |

## 3. 対応の順番の一致（弱い数字）

| 項目 | 中身 |
| --- | --- |
| 何を数えるか | 訓練でケアマネが本人に向けた手（本人電話・連絡先電話・訪問・訪問依頼・受入依頼）を打った順。その人への最初の手が、手を打つ前の左の表（ルールの表 lib/triage の連絡順）で、まだ手を打っていない人の一番上なら一致。手の無かった人と、赤の着信に出なかった人は一致にしない。分母は参加者の全員（「7/10」の形） |
| 誰が | 機械（lib/drill/score.ts の scoreOrder）。Claude は数えない。講評の言葉（Opus 1 回）は数を変えない |
| 弱い理由 | 比べる先がこの道具のルールの表そのもの。表が医学的に妥当かは別に確かめる（表の監修。docs/KNOWN_UNKNOWN.md）。一致が高いことは「表どおりに動いた」までで、「正しく動いた」ではない |
| いつ | 11/6・11/7 の訓練（2 と同じ回） |
| 母数 | 2 と同じ |
| 結果 | 未測定 |

## 書き方

- 結果は「1 回目 N 件 → 2 回目 M 件」「欠け N 欄 / 母数 M 欄」の形。割合は件数の横に添えるだけ
- 誰が・いつ・何回・どの想定かを結果の行に添える
- 測れなかった物は「未測定」のまま残し、理由を書く
- README の「数字」の節と動画は、ここに書いた結果だけを写す
